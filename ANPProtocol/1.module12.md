Lesson 12: Dynamic Agent Selection & Routing

In Lesson 11 we built a Discovery Server.

It could answer:

Who can provide weather_lookup?


But now a new problem appears.

The Problem

Discovery returns:

[
    WeatherAgentA,
    WeatherAgentB,
    WeatherAgentC
]


All support:

weather_lookup


Question:

Which one should we use?

This is where ANP moves beyond simple discovery into routing.

ANP's discovery layer enables finding candidate agents, but real agent networks still need logic to select the most appropriate agent among multiple capable providers.

Real World Analogy

Imagine searching for:

Problem:

May be slow

May be unreliable

Why Trust Matters

Would you rather use:

Agent with 95% reliability


or

Agent with 40% reliability

Trust becomes critical in large agent networks.

Composite Scoring

Production systems rarely use one metric.

Instead:

Trust
+
Latency
+
Cost


Combined.

Example Formula
def score(agent):

    return (

        agent["trust_score"]

        - agent["cost"]

        - agent["latency"] / 10
    )

Sample Data

    "trust_score": 95,

    "cost": 5,

    "latency": 50
}


Calculation:

95 - 5 - 5


Result:

85

Building a Router
class Router:

    def select(self, agents):

        return min(

            agents,

            key=lambda a:
            a["latency"]
        )


Usage:

router = Router()

best = router.select(
    weather_agents
)
