Now we'll learn the real power of agent networks:

Multiple agents working together to solve a problem.

This is one of the core motivations behind Agent Network Protocol (ANP): enabling interoperable agents to discover, communicate, and collaborate across organizational boundaries.

The Problem

Suppose a user asks:

Plan my trip to Bangalore


Can a single agent do everything?

Maybe not.

We may need:

Weather Agent
Hotel Agent
Flight Agent
Budget Agent


Each specializes in one area.

Python Coordinator Example
class TravelAgent:

    def plan_trip(self):

        weather = {
            "weather":
            "Sunny"
        }

        hotel = {
            "hotel":
            "Taj Bangalore"
        }

        flight = {
            "flight":
            "AI101"
        }

        return {

            "weather":
            weather["weather"],

            "hotel":
            hotel["hotel"],

            "flight":
            flight["flight"]
        }

Parallel Collaboration

Sequential:

Weather
   ↓

Hotel
   ↓

Flight


Slow.

Better:

weather_task()

hotel_task()

flight_task()


Run together.

Weather
Hotel
Flight

simultaneously

Async Example
import asyncio

results = await asyncio.gather(

    get_weather(),

    get_hotel(),

    get_flight()
)


This pattern is very common in multi-agent systems.
