Signing Is Not Encryption

A very common beginner mistake:

I signed the message.

Therefore it is secure.


No.

Signing provides:

Authenticity
Integrity


It does NOT provide:

Confidentiality

Example

Signed message:

Balance = ₹500,000


Still readable.

Signing only answers:

Did the message come
from the sender?


not:

Can someone read it?

ANP Solution

Use encryption.

Before:

Hello Weather Agent


After encryption:

a7f9c2e81bb412...


Now interception becomes useless.

Real World Analogy

Think about a letter.

Without encryption:

Postman can read it.


With encryption:

Envelope is locked.


Only the recipient can open it.

First Python Example

We'll use the Fernet implementation from the cryptography library.

from cryptography.fernet import Fernet


Generate key:

key = Fernet.generate_key()


Create cipher:

cipher = Fernet(key)

Encrypt

Original:

message = b"Weather in Mumbai"


Encrypt:

encrypted = cipher.encrypt(
    message
)

print(encrypted)


Output:

b'gAAAAAB...'


Unreadable.

Decrypt
decrypted = cipher.decrypt(
    encrypted
)

print(
    decrypted.decode()
)


Output:

Weather in Mumbai

Building an Encrypted ANP Message

Before:

message = {

    "from":
    "did:wba:travel.company.com",

    "to":
    "did:wba:weather.company.com",

    "payload": {
        "city": "Mumbai"
    }
}

Encrypt Payload
payload = b'{"city":"Mumbai"}'

encrypted_payload = (
    cipher.encrypt(payload)
)


Message becomes:

message = {

    "from":
    "did:wba:travel.company.com",

    "to":
    "did:wba:weather.company.com",

    "payload":
    encrypted_payload
}

Recipient Flow

Recipient receives:

encrypted_payload


Decrypt:

payload = cipher.decrypt(
    encrypted_payload
)


Retrieve:

{
    "city": "Mumbai"
}

Combining Signing + Encryption

Production systems typically use BOTH.

Step 1

Create message.

Signature

Encrypted Package

Why Both?

Encryption answers:

Can others read this?


Signature answers:

Did this sender
really send it?


They solve different problems.
