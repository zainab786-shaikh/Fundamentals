Lesson 6: Agent Description Protocol (What Can You Do?)

In the previous lessons, we solved:

Who are you?
    ↓
DID

Can you prove it?
    ↓
Authentication


Now we arrive at the next ANP question:

What can this agent actually do?

ANP includes an Agent Description layer that allows agents to publish their capabilities, endpoints, supported protocols, and metadata so other agents can discover and interact with them.

The Problem

Suppose we authenticate an agent:

did:wba:weather.company.com


Great.

Now what?

Questions:

Can it provide weather?

Can it forecast?

Can it translate text?

Can it accept messages?

How do I contact it?


Identity alone isn't enough.

Real World Analogy

Imagine meeting someone at a conference.

First:

Who are you?


Answer:

Arif Shaikh


Then:

What do you do?


Answer:

Software Architect


ANP works the same way.

ANP Solution

Every agent publishes an:

Agent Description


Think:

DID
    ↓
Identity

Agent Description
    ↓
Capabilities

First Agent Description
agent_description = {

    "did":
    "did:wba:weather.company.com",

    "name":
    "WeatherAgent",

    "description":
    "Provides weather information",

    "capabilities": [

        "weather_lookup",

        "forecast"
    ]
}

What Just Happened?

We now know:

Who the agent is

AND

What the agent can do

Capability-Based Thinking

ANP encourages capability discovery.

Don't ask:

Find WeatherAgent


Ask:

Find an agent
that supports weather_lookup


This should sound familiar from A2A.

Adding Endpoints

How does another agent contact us?

Add endpoints.

agent_description = {

    "did":
    "did:wba:weather.company.com",

    "capabilities": [
        "weather_lookup"
    ],

    "endpoints": [

        {
            "type":
            "message",

            "url":
            "https://weather.company.com/message"
        }
    ]
}

Why Endpoints Matter

Without endpoints:

I know who you are.

I know what you do.

But I can't reach you.


Endpoints solve that.

Building a Tiny Registry

Imagine three agents.

agents = [

    {
        "did":
        "did:wba:weather.company.com",

        "capabilities":
        ["weather_lookup"]
    },

    {
        "did":
        "did:wba:finance.company.com",

        "capabilities":
        ["stock_price"]
    },

    {
        "did":
        "did:wba:research.company.com",

        "capabilities":
        ["research_topic"]
    }
]

Discovery by Capability
def find_agents(capability):

    return [

        agent

        for agent in agents

        if capability in
           agent["capabilities"]
    ]


Usage:

print(
    find_agents(
        "weather_lookup"
    )
)


Output:

[
    {
        "did":
        "did:wba:weather.company.com",

        "capabilities":
        ["weather_lookup"]
    }
]

Endpoints

Metadata
