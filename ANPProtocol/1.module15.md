Lesson 15: ANP Meta-Protocol & Protocol Negotiation

Welcome to one of the most unique parts of ANP.

Up until now we've assumed:

Travel Agent
      ↓
Weather Agent


can communicate immediately.

But in a real open agent network, that's often not true.

ANP includes concepts around meta-protocols and protocol negotiation to support interoperability across agents that may support different communication capabilities, versions, or interaction models.

The Problem

Suppose two agents meet for the first time.

Agent A

Supports:

Messaging v1
JSON
Compression

Agent B

Supports:

Messaging v2
JSON
Encryption


Question:

How do they communicate?

Real-World Analogy

Think about humans.

Before collaborating, we often establish:

Language
Meeting format
Communication channel


Example:

English?

Zoom?

Email?


Only after agreement do we start work.

Why Discovery Isn't Enough

Discovery tells us:

Who are you?

What capabilities do you have?


But it doesn't tell us:

How should we talk?

ANP Solution

Before exchanging business messages, agents negotiate.

Workflow:

Discover Agent
        ↓

Exchange Capabilities
        ↓

Negotiate Protocol
        ↓

Agree
        ↓

Communicate

First Negotiation Example

Agent A publishes:

agent_a = {

    "did":
    "did:wba:travel.company.com",

    "supported_protocols": [

        "json-v1",

        "encrypted-v1"
    ]
}


Agent B publishes:

agent_b = {

    "did":
    "did:wba:weather.company.com",

    "supported_protocols": [

        "json-v1",

        "compressed-v1"
    ]
}

Finding Common Ground

Question:

What protocol do both support?


Python:

common = (
    set(agent_a["supported_protocols"])
    &
    set(agent_b["supported_protocols"])
)

print(common)


Output:

{"json-v1"}


Both can use:

json-v1

Shared capability:

json-v1

Protocol Selection

Now choose one.

selected = common.pop()

print(selected)


Output:

json-v1

Simple Negotiation Function
def negotiate(a, b):

    return list(

        set(a)
        &
        set(b)

    )


Usage:

negotiate(

    ["json", "xml"],

    ["json", "protobuf"]
)


Output:

["json"]
