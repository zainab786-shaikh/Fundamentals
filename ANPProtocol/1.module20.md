ANP-02: DID Authentication
Problem

Suppose an agent says:

I am WeatherAgent


Why should we believe it?

Anyone can send:

{
  "did":"did:wba:weather.company.com"
}


Identity claims alone are useless.

ANP-02 Solution

ANP-02 defines DID-based authentication.

High-level flow:

Agent A
    ↓

Challenge

    ↓

Agent B

    ↓

Signs Challenge

    ↓

Agent A

    ↓

Verifies Signature

    ↓

Authenticated


This authentication model is based on DID ownership proven through cryptographic signatures rather than passwords.

Python Example

Generate challenge:

import secrets

challenge = secrets.token_hex(16)


Sign challenge:

signature = private_key.sign(
    challenge.encode()
)


Verify:

public_key.verify(
    signature,
    challenge.encode()
)


Authentication succeeds only if the private key owner signed the challenge.

    ↓

ANP-06: Agent Communication Meta Protocol
Problem

Two agents discover each other.

Question:

How do they agree on
how to communicate?


Maybe:

Agent A supports:

json-v1
json-v2


Agent B supports:

json-v2


What protocol should they use?

ANP-06 Solution

ANP-06 defines a communication meta-protocol.

Before exchanging business data, agents negotiate communication parameters and capabilities.

Negotiation Flow
Agent A
   ↓
Supported Protocols
   ↓

Agent B
   ↓
Supported Protocols
   ↓

Intersection
   ↓

Agreement

Python Example
agent_a = {
    "protocols": [
        "json-v1",
        "json-v2"
    ]
}

agent_b = {
    "protocols": [
        "json-v2"
    ]
}

common = (
    set(agent_a["protocols"])
    &
    set(agent_b["protocols"])
)

print(common)


Output:

{'json-v2'}

ANP-07 Solution

Description Contents

ANP-08: Agent Discovery Protocol
Problem

Agents publish descriptions.

How do we find them?

ANP-08 Solution

ANP-08 defines how agents become discoverable and how searches are performed.

Discovery Flow
Need Capability
       ↓

Discovery Query
       ↓

Matching Agents

Example

Registry:

registry = [

    {
        "did":
        "did:wba:weather.com",

        "capabilities":
        ["weather_lookup"]
    },

    {
        "did":
        "did:wba:finance.com",

        "capabilities":
        ["stock_price"]
    }
]


Search:

def discover(capability):

    return [

        agent

        for agent in registry

        if capability in
           agent["capabilities"]
    ]


Usage:

discover("weather_lookup")

Result
[
    {
        "did":
        "did:wba:weather.com"
    }
]

ANP-07

ANP-08
Finds Information

Problem

Messaging Profiles

ANP separates messaging into focused profiles covering direct messaging, groups, encryption, attachments, and federation. The ANP 1.2 documentation describes direct messaging, group messaging, end-to-end encryption, attachments, and federation-oriented messaging capabilities.

Core Message Structure
message = {

    "message_id":
    "MSG-001",

    "from":
    "did:wba:travel.com",

    "to":
    "did:wba:weather.com",

    "payload": {

        "city":
        "Mumbai"
    }
}

Request
{
    "message_id":
    "MSG-001",

    "payload": {

        "action":
        "weather_lookup",

        "city":
        "Mumbai"
    }
}

Response
{
    "message_id":
    "MSG-002",

    "correlation_id":
    "MSG-001",

    "payload": {

        "weather":
        "Sunny"
    }
}
