Now comes the most important question in ANP:

How does an agent prove it actually owns its DID?

ANP's identity and authentication model is built on decentralized identifiers and cryptographic verification. A DID Document contains verification methods (public keys), while the DID owner possesses the corresponding private key.

The Problem

Suppose an agent claims:

I am:

did:wba:weather.company.com


How do we know it's not lying?

Anyone can send:

{
    "did": "did:wba:weather.company.com"
}


Identity claims alone are worthless.

We need proof.

First Python Example

We'll use Ed25519, a common modern signature algorithm.

from cryptography.hazmat.primitives.asymmetric import ed25519

Generate Keys
from cryptography.hazmat.primitives.asymmetric import ed25519

private_key = ed25519.Ed25519PrivateKey.generate()

public_key = private_key.public_key()


Now we have:

Private Key ✅

Public Key ✅

Sign a Message

Message:

message = b"Weather in Mumbai"


Sign it:

signature = private_key.sign(message)


Result:

Binary Signature

Verify Signature
public_key.verify(
    signature,
    message
)


If valid:

No exception


Meaning:

Signature is authentic ✅

Complete Example
from cryptography.hazmat.primitives.asymmetric import ed25519

private_key = ed25519.Ed25519PrivateKey.generate()

public_key = private_key.public_key()

message = b"Weather in Mumbai"

signature = private_key.sign(message)

public_key.verify(
    signature,
    message
)

print("Valid Signature")


Output:

Valid Signature
