Why Use DIDs?

Notice:

"from":
"did:wba:travel.company.com"


instead of:

"name": "Travel Agent"


Names are ambiguous.

DIDs are unique.

Adding Message IDs

Every message should have an identifier.

message = {

    "id":
    "MSG-001",

    "from":
    "did:wba:travel.company.com",

    "to":
    "did:wba:weather.company.com",

    "payload": {
        "city": "Mumbai"
    }
}

Why IDs Matter

Imagine:

1000 messages


Without IDs:

Which reply belongs
to which request?


Hard to know.

Building a Message Class
from dataclasses import dataclass

@dataclass
class Message:

    message_id: str

    sender: str

    recipient: str

    payload: dict


Usage:

msg = Message(

    message_id="MSG-001",

    sender=
    "did:wba:travel.company.com",

    recipient=
    "did:wba:weather.company.com",

    payload={
        "city": "Mumbai"
    }
)

Tiny Messaging Service
class MessagingService:

    def send(
        self,
        sender,
        recipient,
        payload
    ):

        return {

            "from": sender,

            "to": recipient,

            "payload": payload
        }


Usage:

service = MessagingService()

message = service.send(

    "did:wba:a.com",

    "did:wba:b.com",

    {
        "hello": "world"
    }
)
