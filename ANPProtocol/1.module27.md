MCP (Model Context Protocol)

MCP was introduced by Anthropic as an open standard to connect AI assistants and agents to tools, resources, and external systems.

Problem MCP Solves

Suppose an agent wants:

Read Database

Call GitHub

Read Files

Access Jira


Without MCP:

Custom Integration
for every tool

MCP Solution

Expose tools uniformly.

Example:

{
  "tool":
  "get_weather",

  "parameters": {
      "city":"Mumbai"
  }
}


Agent executes tool.

MCP Mental Model
Agent
  ↓
Tool


Not:

Agent
  ↓
Agent
