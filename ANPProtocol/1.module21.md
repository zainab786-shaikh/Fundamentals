Step 4: Authentication Module

ANP-02 relies on challenge/signature verification.

auth.py
from cryptography.hazmat.primitives.asymmetric import ed25519

private_key = (
    ed25519.Ed25519PrivateKey.generate()
)

public_key = (
    private_key.public_key()
)

Sign Function
def sign(message: bytes):

    return private_key.sign(message)

Verify Function
def verify(
    signature,
    message
):

    try:

        public_key.verify(
            signature,
            message
        )

        return True

    except Exception:

        return False

Build Discovery Server

ANP-08 focuses on discovery.

discovery.py
from fastapi import FastAPI

app = FastAPI()

registry = []

Register Agent
@app.post("/register")
def register(agent: dict):

    registry.append(agent)

    return {
        "status": "registered"
    }

Discover Agent
@app.get("/discover/{capability}")
def discover(capability: str):

    return [

        agent

        for agent in registry

        if capability in
           agent["capabilities"]
    ]

ANP-06 Meta Protocol

Before messaging:

travel = {

    "supported_protocols":

    ["json-v1", "json-v2"]
}

weather = {

    "supported_protocols":

    ["json-v2"]
}


Negotiate:

common = list(

    set(
        travel["supported_protocols"]
    )

    &

    set(
        weather["supported_protocols"]
    )
)


Result:

["json-v2"]


This mirrors the ANP communication meta-protocol idea of agreeing on compatible communication formats before exchanging application messages.
