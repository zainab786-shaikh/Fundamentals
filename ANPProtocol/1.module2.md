In Lesson 1 we learned:

Now let's answer the most important ANP question:

What exactly is a DID?

ANP uses decentralized identities, including did:wba, as the foundation for agent identity and trust.

The Problem

Suppose you have an agent:

agent = {
    "name": "WeatherAgent"
}


Question:

Which WeatherAgent?


Maybe:

Company A's WeatherAgent

Company B's WeatherAgent

A malicious fake WeatherAgent


Names alone are not reliable.

Naive Solution #1: Use Email
agent = {
    "email":
    "weather@company.com"
}


Problems:

Email identifies inboxes

Not agents

No standard agent verification

Naive Solution #2: Use URLs
agent = {
    "url":
    "https://weather.company.com"
}


Better, but still doesn't answer:

Who owns this?

How do I verify it?

Where are the public keys?

ANP Solution: DID

A DID (Decentralized Identifier) is a globally unique identifier for an agent. In ANP, identities are based on W3C DID concepts and commonly use did:wba.

Example:

did:wba:weather.company.com


Think:

Agent Passport Number

DID Structure

Let's examine:

did:wba:weather.company.com


Parts:

did
 │
 ├── wba
 │
 └── weather.company.com

Part 1
did


Means:

This is a decentralized identifier.

Part 2
wba


Means:

The DID method.


Similar to:

https

mailto

ftp


but for identity.

Part 3
weather.company.com


The unique identifier.

Real World Analogy

Humans:

Passport Number

Driver License

National ID


Agents:

DID

First Python DID Model
agent = {

    "name": "WeatherAgent",

    "did":
    "did:wba:weather.company.com"
}


Now the agent has a unique identity.

Why DIDs Are Powerful

Suppose two agents have the same name.

{
    "name": "WeatherAgent"
}


and

{
    "name": "WeatherAgent"
}


Confusing.

With DIDs:

{
    "did":
    "did:wba:companyA.com:weather"
}

{
    "did":
    "did:wba:companyB.com:weather"
}


No ambiguity.

Parsing a DID

Let's build our first ANP utility.

Input:

did = "did:wba:weather.company.com"


Split it:

parts = did.split(":")


Result:

[
  "did",
  "wba",
  "weather.company.com"
]

Extract Components
did = "did:wba:weather.company.com"

prefix, method, identifier = did.split(":")

print(prefix)
print(method)
print(identifier)


Output:

did

wba

weather.company.com

Basic Validation

We can verify:

def validate_did(did):

    parts = did.split(":")

    if len(parts) < 3:
        return False

    if parts[0] != "did":
        return False

    return True

Testing

Valid:

validate_did(
    "did:wba:weather.company.com"
)


Output:

True


Invalid:

validate_did(
    "weather.company.com"
)


Output:

False
