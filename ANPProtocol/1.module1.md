Lesson 1: Why ANP Exists?

Before learning DIDs, discovery, messaging, or authentication, we must answer:

Why was ANP created?

The Agent Network Protocol (ANP) is an open protocol stack for the "Agentic Web" that provides decentralized identity, discovery, messaging, authentication, authorization, and other foundations for interoperable AI agents.

The Problem

Imagine the year is 2026.

You have:

Travel Agent
Weather Agent
Finance Agent
Research Agent
Coding Agent


created by different companies.

Microsoft
Google
Amazon
Startups
Individuals


Now suppose:

Travel Agent


wants to talk to:

Weather Agent


Questions arise:

Who owns this agent?

Can I trust it?

How do I find it?

How do I authenticate it?

How do I message it securely?


A2A mostly focuses on communication patterns.

But communication alone is not enough.

Real World Analogy

The Internet doesn't work because:

Everyone knows everyone.


The Internet works because of:

DNS
TLS

Identity


Similarly, an Agent Internet requires:

Identity
Discovery
Trust
Messaging

Life Without ANP

Suppose Agent A wants to talk to Agent B.

The developer hardcodes:

agent = {
    "name": "WeatherAgent",
    "url": "https://my-weather-agent.com"
}


Problems:

No verification

No authentication

ANP Solution

ANP introduces a protocol stack.

Think:

Internet
---------
DNS
HTTP
TLS


Agent Internet:

Identity
Discovery
Messaging
Authentication
Authorization


ANP organizes these concerns into layered protocols so agents can establish identity, discover capabilities, and communicate securely.

First ANP Mental Model

A2A starts with:

What work can you do?


ANP starts with:

Who are you?


This is a HUGE difference.

Example

Suppose we have:

weather_agent = {
    "name": "WeatherAgent"
}


A2A would ask:

What skills does it provide?


ANP asks first:

Can I prove this agent's identity?

Identity Before Communication

Human world:

Meet Person
↓
Verify Identity
↓
Start Conversation


ANP:

Find Agent
↓
Verify Identity
↓
Start Communication

Simple Python Example

Without identity:

agent = {
    "name": "WeatherAgent"
}


With identity:

agent = {
    "name": "WeatherAgent",

    "did":
    "did:wba:weather.example.com"
}


The DID becomes the agent's globally verifiable identity. ANP uses DID-based identity mechanisms, including did:wba.

Why Names Are Not Enough

Imagine:

WeatherAgent


exists in:

Company A

Company B

Company C


Names collide.

Identity solves this.

Example:

did:wba:companyA.com:weather

did:wba:companyB.com:weather


Now they're unique.
