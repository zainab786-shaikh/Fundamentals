Perfect. Since you've already learned A2A in a structured "problem → solution → code" manner, I would recommend learning ANP (Agent Network Protocol) the same way.

ANP is much broader than A2A. A2A primarily focuses on agent communication and task exchange, while ANP aims to provide a complete protocol stack for the "Agentic Web", including identity, discovery, messaging, authentication, authorization, and domain protocols.
