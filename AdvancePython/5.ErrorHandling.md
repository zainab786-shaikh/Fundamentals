Below are the variants for each topic in section 5, with one simple example each. They are all in Python and inline (no canvas).

## 1. Exceptions

| Variant | Idea |
|---|---|
| Basic `try/except` | Catch one specific error |
| Multiple `except` | Handle different errors differently |
| Tuple of exceptions | One handler for several types |
| `else` | Runs only if no exception was raised |
| `finally` | Always runs, used for cleanup |
| `raise` / re-raise | Signal an error or pass it up |
| Exception chaining (`raise ... from`) | Keep the original cause |
| Custom exceptions | Domain-specific error types |
| Context managers (`with`) | Automatic cleanup |
| `ExceptionGroup` / `except*` (3.11+) | Handle several errors at once |

```python name=exceptions.py
# Basic + multiple except
def parse(s):
    try:
        return int(s)
    except ValueError:
        return None
    except TypeError:
        return -1

# Tuple of exceptions
def safe_div(a, b):
    try:
        return a / b
    except (ZeroDivisionError, TypeError) as e:
        print(f"Bad input: {e}")

# else + finally
def read_first_line(path):
    try:
        f = open(path, encoding="utf-8")
    except FileNotFoundError:
        print("missing file")
    else:
        with f:
            return f.readline()   # only runs if open succeeded
    finally:
        print("done")             # always runs

# Re-raise and chaining
def load_config(raw):
    try:
        return int(raw)
    except ValueError as e:
        raise RuntimeError("Invalid config value") from e

# Custom exceptions
class AppError(Exception):
    """Base class for app errors."""

class InsufficientFunds(AppError):
    def __init__(self, balance, amount):
        super().__init__(f"Balance {balance} < {amount}")
        self.balance, self.amount = balance, amount

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFunds(balance, amount)
    return balance - amount

# Custom context manager
from contextlib import contextmanager

@contextmanager
def managed(name):
    print(f"open {name}")
    try:
        yield name
    finally:
        print(f"close {name}")

# ExceptionGroup (Python 3.11+)
try:
    raise ExceptionGroup("multi", [ValueError("a"), TypeError("b")])
except* ValueError as eg:
    print("value errors:", eg.exceptions)
except* TypeError as eg:
    print("type errors:", eg.exceptions)

print(parse("42"), parse("x"))            # 42 None
safe_div(1, 0)                            # Bad input: division by zero
try:
    withdraw(10, 50)
except AppError as e:
    print(e)                              # Balance 10 < 50
with managed("db"):
    print("working")                      # open db / working / close db
```

Tip: catch specific exceptions. Avoid a bare `except:` because it also swallows `KeyboardInterrupt` and `SystemExit`.

## 2. `logging`

| Variant | Idea |
|---|---|
| `basicConfig` | Quickest setup |
| Log levels | DEBUG, INFO, WARNING, ERROR, CRITICAL |
| Named logger | `getLogger(__name__)` per module |
| File handler | Write logs to a file |
| Rotating file handler | Cap file size and keep backups |
| Custom formatter | Control the output format |
| `logger.exception` | Logs the message plus the traceback |
| Lazy `%s` formatting | Avoids building strings for disabled levels |
| `dictConfig` | Configuration as data |
| JSON/structured logs | Machine-readable output (custom formatter) |

```python name=logging_types.py
import logging
import logging.config
import json
from logging.handlers import RotatingFileHandler

# basicConfig + levels
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s: %(message)s",
)
log = logging.getLogger(__name__)
log.debug("hidden at INFO level")
log.info("started")
log.warning("disk at %d%%", 91)   # lazy formatting

# logger.exception inside except
try:
    1 / 0
except ZeroDivisionError:
    log.exception("calculation failed")   # includes traceback

# File + rotating handler on a named logger
app = logging.getLogger("app")
app.setLevel(logging.DEBUG)
handler = RotatingFileHandler("app.log", maxBytes=1_000_000, backupCount=3,
                              encoding="utf-8")
handler.setFormatter(logging.Formatter("%(asctime)s [%(levelname)s] %(message)s"))
app.addHandler(handler)
app.info("written to rotating file")

# JSON formatter
class JsonFormatter(logging.Formatter):
    def format(self, record):
        return json.dumps({
            "time": self.formatTime(record),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
        })

jlog = logging.getLogger("json")
h = logging.StreamHandler()
h.setFormatter(JsonFormatter())
jlog.addHandler(h)
jlog.propagate = False
jlog.warning("structured")

# dictConfig
logging.config.dictConfig({
    "version": 1,
    "disable_existing_loggers": False,
    "formatters": {"simple": {"format": "%(levelname)s - %(message)s"}},
    "handlers": {"console": {"class": "logging.StreamHandler",
                             "formatter": "simple"}},
    "root": {"level": "INFO", "handlers": ["console"]},
})
logging.getLogger("cfg").info("configured via dict")
```

Security note: never log secrets, tokens or passwords. Sanitize user input before logging it, to prevent log injection through newlines.

## 3. Debugging with `pdb`

| Variant | Idea |
|---|---|
| `breakpoint()` | Built-in way to drop into the debugger (3.7+) |
| `import pdb; pdb.set_trace()` | The older equivalent |
| `python -m pdb script.py` | Start the script under the debugger |
| Post-mortem (`pdb.pm()` / `pdb.post_mortem()`) | Inspect state after a crash |
| Conditional breakpoint | `b file.py:10, x > 5` |
| `PYTHONBREAKPOINT=0` | Disable all `breakpoint()` calls |

```python name=pdb_examples.py
# 1. breakpoint()
def total(items):
    s = 0
    for i in items:
        breakpoint()      # pauses here
        s += i
    return s

# 2. Post-mortem on exception
import pdb

def crash():
    x = {}
    return x["missing"]

try:
    crash()
except KeyError:
    pdb.post_mortem()     # opens pdb at the failing frame
```

Run from the shell:

```bash
python -m pdb pdb_examples.py          # start under the debugger
PYTHONBREAKPOINT=0 python script.py    # disable breakpoint() calls
python -m pdb -c continue script.py    # run, stop automatically on crash
```

Common pdb commands:

| Command | Meaning |
|---|---|
| `n` | Next line (step over) |
| `s` | Step into a function |
| `c` | Continue |
| `r` | Run until the current function returns |
| `l` / `ll` | List the source / the whole function |
| `p expr` / `pp expr` | Print / pretty-print |
| `w` | Show the stack |
| `u` / `d` | Move up / down the stack |
| `b 12` | Set a breakpoint at line 12 |
| `b 12, i > 3` | Conditional breakpoint |
| `cl` | Clear breakpoints |
| `q` | Quit |

Security note: remove `breakpoint()` calls before shipping, or set `PYTHONBREAKPOINT=0` in production. A stray breakpoint can hang a service or expose an interactive shell.
