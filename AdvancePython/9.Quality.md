# 9. Testing and Code Quality: Types and Simple Examples

## 1. `unittest` and `pytest`

**a) Basic `unittest`**
```python
import unittest

def add(a, b): return a + b

class TestAdd(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(2, 3), 5)

if __name__ == "__main__":
    unittest.main()
```

**b) Common `unittest` assertions**
```python
class TestAsserts(unittest.TestCase):
    def test_all(self):
        self.assertTrue(1 < 2)
        self.assertIn(2, [1, 2])
        self.assertIsNone(None)
        self.assertAlmostEqual(0.1 + 0.2, 0.3)
        with self.assertRaises(ZeroDivisionError):
            1 / 0
```

**c) `setUp` / `tearDown`**
```python
class TestList(unittest.TestCase):
    def setUp(self):
        self.items = [1, 2, 3]

    def tearDown(self):
        self.items.clear()

    def test_len(self):
        self.assertEqual(len(self.items), 3)
```

**d) `subTest` (loop of cases)**
```python
class TestSquares(unittest.TestCase):
    def test_squares(self):
        for x, exp in [(2, 4), (3, 9)]:
            with self.subTest(x=x):
                self.assertEqual(x * x, exp)
```

**e) Basic `pytest` (plain `assert`)**
```python
def test_add():
    assert add(2, 3) == 5
```

**f) Testing exceptions**
```python
import pytest

def test_zero_division():
    with pytest.raises(ZeroDivisionError):
        1 / 0
```

**g) Parametrize**
```python
import pytest

@pytest.mark.parametrize("a, b, expected", [(1, 2, 3), (0, 0, 0), (-1, 1, 0)])
def test_add_many(a, b, expected):
    assert add(a, b) == expected
```

**h) Fixtures**
```python
import pytest

@pytest.fixture
def items():
    return [1, 2, 3]

def test_len(items):
    assert len(items) == 3
```

**i) Fixture with teardown (`yield`)**
```python
@pytest.fixture
def resource():
    r = {"open": True}
    yield r
    r["open"] = False  # cleanup
```

**j) Built-in fixtures (`tmp_path`, `capsys`)**
```python
def test_file(tmp_path):
    f = tmp_path / "a.txt"
    f.write_text("hi")
    assert f.read_text() == "hi"

def test_print(capsys):
    print("hello")
    assert capsys.readouterr().out == "hello\n"
```

**k) Markers (skip / xfail / custom)**
```python
import sys, pytest

@pytest.mark.skip(reason="not ready")
def test_skip(): ...

@pytest.mark.skipif(sys.platform == "win32", reason="posix only")
def test_posix(): ...

@pytest.mark.xfail
def test_known_bug(): assert False
```

**l) Shared fixtures in `conftest.py`**
```python
# conftest.py
import pytest

@pytest.fixture
def user():
    return {"name": "sam"}
```

**m) Running tests**
```bash
python -m unittest
pytest -v
pytest -k "add" -x          # filter by name, stop at first failure
pytest tests/test_a.py::test_add
```

## 2. Mocking

**a) `Mock` and return value**
```python
from unittest.mock import Mock

m = Mock()
m.get.return_value = 42
print(m.get())  # 42
m.get.assert_called_once()
```

**b) `patch` as a decorator**
```python
from unittest.mock import patch

@patch("os.getcwd", return_value="/fake")
def test_cwd(mock_cwd):
    import os
    assert os.getcwd() == "/fake"
```

**c) `patch` as a context manager**
```python
with patch("time.time", return_value=1000):
    import time
    assert time.time() == 1000
```

**d) `side_effect` (exceptions or sequences)**
```python
m = Mock(side_effect=[1, 2, ValueError("boom")])
print(m(), m())   # 1 2
# m() now raises ValueError
```

**e) `MagicMock` (supports magic methods)**
```python
from unittest.mock import MagicMock

mm = MagicMock()
mm.__len__.return_value = 3
print(len(mm))  # 3
```

**f) `spec` / `autospec` (catch wrong usage)**
```python
from unittest.mock import create_autospec

def fetch(url: str) -> str: ...

fake = create_autospec(fetch)
fake("http://x")      # OK
# fake(1, 2, 3)       # TypeError: wrong signature
```

**g) Patch where the name is used (not defined)**
```python
# app.py: from requests import get
# test: patch("app.get"), NOT patch("requests.get")
```

**h) Verify calls**
```python
m = Mock()
m(1, key="a")
m.assert_called_with(1, key="a")
print(m.call_count, m.call_args)
```

**i) pytest `monkeypatch`**
```python
def test_env(monkeypatch):
    monkeypatch.setenv("MODE", "test")
    import os
    assert os.environ["MODE"] == "test"
```

**j) `pytest-mock` (`mocker` fixture)**
```python
def test_with_mocker(mocker):
    mocker.patch("os.getcwd", return_value="/fake")
```

**k) `patch.object` and `patch.dict`**
```python
from unittest.mock import patch
import os

with patch.dict(os.environ, {"API_KEY": "test"}):
    assert os.environ["API_KEY"] == "test"
```

## 3. Linting (`ruff`) and Formatting

**a) Install**
```bash
pip install ruff
```

**b) Lint**
```bash
ruff check .
ruff check . --fix            # auto-fix safe issues
```

**c) Format (Black-compatible)**
```bash
ruff format .
ruff format --check .         # CI-friendly, no changes
```

**d) Example of what gets flagged**
```python
import os          # F401 unused import
x=1                # E225 / formatting
```

**e) Configure in `pyproject.toml`**
```toml
[tool.ruff]
line-length = 88
target-version = "py312"

[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP", "S"]   # S = security (bandit rules)
ignore = ["E501"]

[tool.ruff.lint.per-file-ignores]
"tests/*" = ["S101"]          # allow assert in tests
```

**f) Suppress a single line**
```python
import os  # noqa: F401
```

**g) Import sorting (rule `I`)**
```bash
ruff check --select I --fix .
```

**h) Pre-commit hook**
```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.6.9   # pin to the latest release
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format
```

## 4. Type Checking (`mypy`)

**a) Install and run**
```bash
pip install mypy
mypy app.py
mypy src/ --strict
```

**b) Catching a type error**
```python
def double(x: int) -> int:
    return x * 2

double("a")   # mypy: Argument 1 has incompatible type "str"; expected "int"
```

**c) Optional handling**
```python
def length(s: str | None) -> int:
    if s is None:
        return 0
    return len(s)     # narrowed to str
```

**d) Config in `pyproject.toml`**
```toml
[tool.mypy]
python_version = "3.12"
strict = true
warn_unused_ignores = true

[[tool.mypy.overrides]]
module = "untyped_lib.*"
ignore_missing_imports = true
```

**e) Ignore a single line**
```python
x: int = "a"  # type: ignore[assignment]
```

**f) `reveal_type` (debug inference)**
```python
reveal_type([1, 2, 3])   # mypy: list[int]
```

**g) Third-party stubs**
```bash
pip install types-requests
mypy --install-types
```

**h) Alternative: `pyright`**
```bash
pip install pyright
pyright src/
```

## 5. Code Coverage

**a) `coverage.py` directly**
```bash
pip install coverage
coverage run -m pytest
coverage report -m            # shows missing lines
coverage html                 # open htmlcov/index.html
```

**b) `pytest-cov`**
```bash
pip install pytest-cov
pytest --cov=mypkg --cov-report=term-missing
```

**c) Enforce a minimum (fail CI)**
```bash
pytest --cov=mypkg --cov-fail-under=85
```

**d) Branch coverage**
```bash
pytest --cov=mypkg --cov-branch
```

**e) Config in `pyproject.toml`**
```toml
[tool.coverage.run]
branch = true
source = ["mypkg"]

[tool.coverage.report]
fail_under = 85
exclude_lines = [
    "pragma: no cover",
    "if __name__ == .__main__.:",
    "if TYPE_CHECKING:",
]
```

**f) Exclude a line or block**
```python
def debug_only():  # pragma: no cover
    ...
```

**g) XML report for CI tools**
```bash
pytest --cov=mypkg --cov-report=xml
```

## Combined CI Example (GitHub Actions)

```yaml
name: ci
on: [push, pull_request]
permissions:
  contents: read          # least privilege
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -e . ruff mypy pytest pytest-cov
      - run: ruff check .
      - run: ruff format --check .
      - run: mypy src/
      - run: pytest --cov=mypkg --cov-fail-under=85
```

**Tips:**
- Coverage measures executed lines, not test quality. Pair it with meaningful assertions.
- Mock at boundaries (network, disk, time), not your own internal logic.
- Add `pip-audit` to CI to scan dependencies for known vulnerabilities.

# Security Auditing and Extra Code Quality Tools

## 1. Vulnerability Auditing

**a) `pip-audit` (scan installed packages)**
```bash
pip install pip-audit
pip-audit
```

**b) Audit a requirements file**
```bash
pip-audit -r requirements.txt
```

**c) Auto-fix by upgrading vulnerable packages**
```bash
pip-audit --fix
pip-audit --fix --dry-run     # preview first
```

**d) Strict, CI-friendly options**
```bash
pip-audit -r requirements.txt --strict          # fail if a package can't be audited
pip-audit -f json -o audit.json                 # machine-readable report
```

**e) Hash-pinned requirements (supply-chain protection)**
```bash
pip install pip-tools
pip-compile --generate-hashes -o requirements.txt requirements.in
pip install --require-hashes -r requirements.txt
```

**f) Alternative: `safety`**
```bash
pip install safety
safety scan
```

## 2. Static Security Analysis

**a) `bandit` (finds insecure code patterns)**
```bash
pip install bandit
bandit -r src/
bandit -r src/ -ll            # medium severity and above
```

**Example of what it flags:**
```python
import subprocess
subprocess.run(user_input, shell=True)   # B602: shell injection risk
import pickle; pickle.loads(data)        # B301: unsafe deserialization
```

**b) `ruff` security rules (no extra tool needed)**
```bash
ruff check --select S .
```

**c) `semgrep` (rule-based scanning)**
```bash
pip install semgrep
semgrep --config auto src/
```

**d) Secret scanning**
```bash
pip install detect-secrets
detect-secrets scan > .secrets.baseline
```
Or use `gitleaks detect` to scan git history.

## 3. Other Code Quality Commands

**a) Complexity (`radon`)**
```bash
pip install radon
radon cc src/ -a -nc          # cyclomatic complexity, show C rating and worse
radon mi src/                 # maintainability index
```

**b) Dead code (`vulture`)**
```bash
pip install vulture
vulture src/ --min-confidence 80
```

**c) Docstring style (`ruff` rules `D`)**
```bash
ruff check --select D .
```

**d) Docstring coverage (`interrogate`)**
```bash
pip install interrogate
interrogate -v --fail-under 80 src/
```

**e) Ruff complexity rule (`C90`)**
```toml
[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP", "S", "C90", "SIM", "PERF", "RUF"]

[tool.ruff.lint.mccabe]
max-complexity = 10
```

**f) Mutation testing (`mutmut`, checks test quality)**
```bash
pip install mutmut
mutmut run --paths-to-mutate src/
mutmut results
```

**g) Property-based testing (`hypothesis`)**
```python
from hypothesis import given, strategies as st

@given(st.integers(), st.integers())
def test_add_commutative(a, b):
    assert add(a, b) == add(b, a)
```

**h) Detect flaky tests / random order**
```bash
pip install pytest-randomly pytest-xdist
pytest -p randomly            # randomized order
pytest -n auto                # parallel run
```

**i) Check packaging/dependency health**
```bash
pip check                     # broken/incompatible dependencies
pip list --outdated
```

## 5. Updated CI Workflow

```yaml
name: ci
on: [push, pull_request]
permissions:
  contents: read
jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -e . ruff mypy pytest pytest-cov bandit pip-audit
      - run: ruff check .
      - run: ruff format --check .
      - run: mypy src/
      - run: bandit -r src/ -ll
      - run: pip-audit -r requirements.txt --strict
      - run: pytest --cov=mypkg --cov-fail-under=85
```

**Notes:**
- Version pins (`rev:`) above are examples. Check each tool's releases page for the current version before use.
- Enable GitHub Dependabot and CodeQL for continuous dependency and code scanning.
- Treat scanner output as a signal, since false positives happen. Review before suppressing with `# nosec` or `# noqa`.
