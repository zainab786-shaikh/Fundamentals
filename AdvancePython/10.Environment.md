# 10. Environment and Packaging: Types and Simple Examples

## 1. `venv` (Virtual Environments)

**a) Create and activate**
```bash
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
```
```powershell
.venv\Scripts\Activate.ps1       # Windows PowerShell
```

**b) Deactivate**
```bash
deactivate
```

**c) Use without activating**
```bash
.venv/bin/python script.py
.venv/bin/pip install requests
```

**d) Specific Python version**
```bash
python3.12 -m venv .venv
```

**e) Include system packages (rarely needed)**
```bash
python -m venv .venv --system-site-packages
```

**f) Recreate cleanly**
```bash
rm -rf .venv && python -m venv .venv      # Linux/macOS
```
```powershell
Remove-Item -Recurse -Force .venv; python -m venv .venv
```

**g) Verify which Python is active**
```python
import sys
print(sys.prefix != sys.base_prefix)   # True inside a venv
print(sys.executable)
```

**h) Git ignore**
```gitignore
.venv/
__pycache__/
*.pyc
.env
```

**Tip:** Never commit `.venv` or `.env` (secrets).

## 2. `pip` / `uv`

### `pip`

**a) Install, upgrade, uninstall**
```bash
pip install requests
pip install "requests>=2.31,<3"
pip install --upgrade requests
pip uninstall requests
```

**b) Requirements file**
```bash
pip freeze > requirements.txt
pip install -r requirements.txt
```

**c) Editable install (development)**
```bash
pip install -e .
pip install -e ".[dev]"          # with optional extras
```

**d) Inspect**
```bash
pip list
pip show requests
pip check
pip list --outdated
```

**e) Hash-checked install (supply-chain safety)**
```bash
pip install --require-hashes -r requirements.txt
```

**f) Constraints file**
```bash
pip install -r requirements.txt -c constraints.txt
```

### `uv` (fast, modern, by Astral)

**g) Install uv**
```bash
pip install uv
# or: curl -LsSf https://astral.sh/uv/install.sh | sh
```

**h) Drop-in pip replacement**
```bash
uv venv
uv pip install requests
uv pip install -r requirements.txt
uv pip compile requirements.in -o requirements.txt
uv pip sync requirements.txt
```

**i) Project workflow**
```bash
uv init myproj
cd myproj
uv add requests
uv add --dev pytest ruff
uv remove requests
uv sync                          # create/update .venv from lockfile
uv lock                          # write uv.lock
uv run pytest                    # run inside the env
```

**j) Manage Python versions**
```bash
uv python install 3.12
uv python list
uv venv --python 3.12
```

**k) Run tools without installing (like `npx`)**
```bash
uvx ruff check .
uv tool install ruff
```

**l) Single-file script with inline dependencies (PEP 723)**
```python
# /// script
# requires-python = ">=3.12"
# dependencies = ["requests"]
# ///
import requests
print(requests.get("https://example.com").status_code)
```
```bash
uv run script.py
```

**m) Audit with uv**
```bash
uv export --no-dev -o requirements.txt
pip-audit -r requirements.txt
```

### Comparison

| Need | `pip` | `uv` |
|---|---|---|
| Speed | Baseline | Much faster |
| Lockfile | Via `pip-tools` | Built in (`uv.lock`) |
| Python version mgmt | No | Yes |
| Ubiquity | Everywhere | Growing quickly |

## 3. `pyproject.toml`

**a) Minimal (PEP 621)**
```toml
[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[project]
name = "mypkg"
version = "0.1.0"
description = "Short description"
readme = "README.md"
requires-python = ">=3.10"
license = "MIT"
dependencies = ["requests>=2.31"]
```

**b) Optional dependencies (extras)**
```toml
[project.optional-dependencies]
dev = ["pytest", "ruff", "mypy", "pip-audit"]
```
```bash
pip install -e ".[dev]"
```

**c) Dependency groups (PEP 735, supported by `uv`)**
```toml
[dependency-groups]
dev = ["pytest", "ruff"]
```

**d) CLI entry point**
```toml
[project.scripts]
mycli = "mypkg.cli:main"
```

**e) Metadata: classifiers and URLs**
```toml
[project]
classifiers = [
    "Programming Language :: Python :: 3",
    "Typing :: Typed",
]

[project.urls]
Homepage = "https://github.com/me/mypkg"
Issues = "https://github.com/me/mypkg/issues"
```

**f) Dynamic version (from a file)**
```toml
[project]
dynamic = ["version"]

[tool.hatch.version]
path = "src/mypkg/__init__.py"
```

**g) Tool configuration in one file**
```toml
[tool.ruff]
line-length = 88

[tool.mypy]
strict = true

[tool.pytest.ini_options]
testpaths = ["tests"]
addopts = "-q"
```

**h) Alternative build backends**
```toml
# setuptools
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

# uv_build, flit_core, pdm-backend, and poetry-core are also options
```

**i) Recommended `src` layout**
```
mypkg/
├── pyproject.toml
├── README.md
├── LICENSE
├── src/
│   └── mypkg/
│       ├── __init__.py
│       └── py.typed
└── tests/
```

## 4. Building and Publishing Packages

**a) Build sdist and wheel**
```bash
pip install build
python -m build                  # creates dist/*.tar.gz and dist/*.whl
```
```bash
uv build                         # uv equivalent
```

**b) Validate the artifacts**
```bash
pip install twine
twine check dist/*
```

**c) Inspect contents**
```bash
unzip -l dist/*.whl
tar -tf dist/*.tar.gz
```

**d) Test in a clean env**
```bash
python -m venv /tmp/t && /tmp/t/bin/pip install dist/*.whl
```

**e) Publish to TestPyPI first**
```bash
twine upload --repository testpypi dist/*
pip install --index-url https://test.pypi.org/simple/ mypkg
```
```bash
uv publish --publish-url https://test.pypi.org/legacy/
```

**f) Publish to PyPI**
```bash
twine upload dist/*
uv publish
```

**g) Prefer tokens, never passwords**
```bash
# Use an API token, passed via environment variable
export TWINE_USERNAME=__token__
export TWINE_PASSWORD="$PYPI_TOKEN"     # from a secret store
```

**h) Trusted Publishing from GitHub Actions (recommended, no stored token)**
```yaml
name: publish
on:
  release:
    types: [published]
permissions:
  contents: read
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install build
      - run: python -m build
      - uses: actions/upload-artifact@v4
        with:
          name: dist
          path: dist/

  publish:
    needs: build
    runs-on: ubuntu-latest
    environment: pypi                 # protect with required reviewers
    permissions:
      id-token: write                 # OIDC, only
