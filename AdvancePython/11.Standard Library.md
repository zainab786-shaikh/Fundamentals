## 1. `datetime`

**a) Now, today (timezone-aware, preferred)**
```python
from datetime import datetime, date, timezone

print(datetime.now(timezone.utc))
print(date.today())
```
Avoid `datetime.utcnow()`. It is deprecated since 3.12 and returns a naive value.

**b) Create specific values**
```python
from datetime import datetime, date, time
d = date(2026, 10, 21)
t = time(14, 30)
dt = datetime(2026, 10, 21, 14, 30, tzinfo=timezone.utc)
```

**c) Format and parse**
```python
dt.strftime("%Y-%m-%d %H:%M")                       # to string
datetime.strptime("2026-10-21", "%Y-%m-%d")         # from string
dt.isoformat()                                      # ISO 8601
datetime.fromisoformat("2026-10-21T14:30:00+00:00")
```

**d) `timedelta` arithmetic**
```python
from datetime import timedelta
print(dt + timedelta(days=7, hours=2))
print((date(2026, 12, 25) - date.today()).days)
```

**e) Time zones (`zoneinfo`, 3.9+)**
```python
from zoneinfo import ZoneInfo
print(dt.astimezone(ZoneInfo("Asia/Kolkata")))
```

**f) Timestamps**
```python
ts = dt.timestamp()
datetime.fromtimestamp(ts, tz=timezone.utc)
```

**g) Replace / compare**
```python
dt.replace(hour=0, minute=0)
dt1 < dt2        # both must be aware or both naive
```

## 2. `re` (Regular Expressions)

**a) `search`, `match`, `fullmatch`**
```python
import re
re.search(r"\d+", "abc 123")        # first match anywhere
re.match(r"\d+", "123abc")          # at start only
re.fullmatch(r"\d{3}", "123")       # whole string
```

**b) `findall` / `finditer`**
```python
re.findall(r"\d+", "a1 b22 c333")                   # ['1', '22', '333']
for m in re.finditer(r"\d+", "a1 b22"):
    print(m.group(), m.span())
```

**c) Groups and named groups**
```python
m = re.search(r"(?P<y>\d{4})-(?P<m>\d{2})", "2026-10")
print(m["y"], m.group("m"), m.groupdict())
```

**d) `sub` (replace), with function**
```python
re.sub(r"\s+", " ", "a   b    c")
re.sub(r"\d+", lambda m: str(int(m.group()) * 2), "a1 b2")
```

**e) `split`**
```python
re.split(r"[,;]\s*", "a, b;c")
```

**f) Compile and flags**
```python
pat = re.compile(r"^hello", re.IGNORECASE | re.MULTILINE)
pat.findall("Hello\nhello")
```

**g) Verbose pattern**
```python
phone = re.compile(r"""
    (\d{3})   # area
    -(\d{4})  # number
""", re.VERBOSE)
```

**h) Lookahead / non-greedy**
```python
re.findall(r"\w+(?=@)", "me@x.com")      # lookahead
re.findall(r"<.+?>", "<a><b>")           # non-greedy
```

**Security:** Avoid nested quantifiers like `(a+)+` on untrusted input (ReDoS). Limit input length.

## 3. `itertools`

**a) Infinite: `count`, `cycle`, `repeat`**
```python
from itertools import count, cycle, repeat, islice
list(islice(count(5), 3))        # [5, 6, 7]
list(islice(cycle("ab"), 5))     # a b a b a
list(repeat(0, 3))
```

**b) Combinatorics**
```python
from itertools import product, permutations, combinations, combinations_with_replacement
list(product([1, 2], "ab"))
list(permutations([1, 2, 3], 2))
list(combinations([1, 2, 3], 2))
```

**c) `chain` / `chain.from_iterable`**
```python
from itertools import chain
list(chain([1], [2, 3]))
list(chain.from_iterable([[1], [2]]))
```

**d) `groupby` (sort first)**
```python
from itertools import groupby
for k, g in groupby(sorted("aabbb")):
    print(k, len(list(g)))
```

**e) `accumulate`**
```python
from itertools import accumulate
list(accumulate([1, 2, 3, 4]))   # [1, 3, 6, 10]
```

**f) `zip_longest`, `pairwise`, `batched`**
```python
from itertools import zip_longest, pairwise, batched
list(zip_longest([1, 2], "a", fillvalue="-"))
list(pairwise([1, 2, 3]))        # 3.10+
list(batched(range(5), 2))       # 3.12+
```

**g) `takewhile` / `dropwhile` / `compress` / `starmap` / `tee`**
```python
from itertools import takewhile, dropwhile, compress, starmap
list(takewhile(lambda x: x < 3, [1, 2, 5, 1]))
list(dropwhile(lambda x: x < 3, [1, 2, 5, 1]))
list(compress("abc", [1, 0, 1]))
list(starmap(pow, [(2, 3), (3, 2)]))
```

## 4. `functools`

**a) `lru_cache` / `cache`**
```python
from functools import lru_cache, cache

@lru_cache(maxsize=128)
def fib(n): return n if n < 2 else fib(n - 1) + fib(n - 2)

@cache
def sq(n): return n * n
```

**b) `partial`**
```python
from functools import partial
int2 = partial(int, base=2)
int2("101")   # 5
```

**c) `reduce`**
```python
from functools import reduce
reduce(lambda a, b: a * b, [1, 2, 3, 4])   # 24
```

**d) `wraps`**
```python
from functools import wraps
```
Used in decorators to preserve function metadata.

**e) `cached_property`**
```python
from functools import cached_property

class A:
    @cached_property
    def data(self): return [1, 2, 3]
```

**f) `singledispatch`**
```python
from functools import singledispatch

@singledispatch
def show(x): return "other"

@show.register
def _(x: int): return "int"
```

**g) `total_ordering`**
```python
from functools import total_ordering

@total_ordering
class V:
    def __init__(self, n): self.n = n
    def __eq__(self, o): return self.n == o.n
    def __lt__(self, o): return self.n < o.n
```

**h) `cmp_to_key`**
```python
from functools import cmp_to_key
sorted([3, 1, 2], key=cmp_to_key(lambda a, b: b - a))
```

## 5. `os` and `sys`

**a) Environment variables (use for secrets)**
```python
import os
os.environ.get("API_KEY", "")
os.getenv("HOME")
```

**b) Paths and files**
```python
os.getcwd()
os.listdir(".")
os.makedirs("a/b", exist_ok=True)
os.path.join("a", "b.txt")
os.path.exists("a")
os.remove("a/b.txt")
```

**c) `os.walk`**
```python
for root, dirs, files in os.walk("."):
    print(root, files)
```

**d) Process info**
```python
os.getpid()
os.cpu_count()
os.name          # 'posix' or 'nt'
```

**e) `sys.argv`, `sys.exit`**
```python
import sys
print(sys.argv)
sys.exit(1)
```

**f) Version and platform**
```python
sys.version_info >= (3, 12)
sys.platform
sys.executable
```

**g) Streams**
```python
print("error", file=sys.stderr)
data = sys.stdin.read()
```

**h) Module search path**
```python
sys.path
sys.modules.keys()
```

**i) Recursion limit and sizes**
```python
sys.getrecursionlimit()
sys.getsizeof([])
```

## 6. Important Modules Missing From Your List

### `pathlib` (modern paths, prefer over `os.path`)
```python
from pathlib import Path
p = Path("data") / "file.txt"
p.parent.mkdir(parents=True, exist_ok=True)
p.write_text("hi", encoding="utf-8")
print(p.read_text(), p.suffix, p.stem, p.exists())
list(Path(".").glob("**/*.py"))
```
Security: to prevent path traversal, resolve and check the result.
```python
base = Path("/safe/dir").resolve()
target = (base / user_input).resolve()
if not target.is_relative_to(base):    # 3.9+
    raise ValueError("Invalid path")
```
