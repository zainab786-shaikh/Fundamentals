Lesson 1: What Problem Does A2A Solve?
Problem

You have two agents:

Travel Agent
Weather Agent


Travel Agent needs weather information.

Without a standard protocol, every agent invents its own API.

weather_agent.get_weather(city)


What if another vendor uses:

fetch_weather(location)


Now every agent must learn every other agent's API.

This does not scale.

A2A Solution

A2A says:

Every agent speaks the same language.

Agent A
    |
    | A2A Message
    |
Agent B


Agent A doesn't care whether Agent B is built using:

LangGraph
CrewAI
Semantic Kernel
Custom Python

A2A defines a common communication format.

Small Python Example

Without A2A:

class WeatherAgent:
    def weather(self, city):
        return f"Sunny in {city}"


With A2A mindset:

message = {
    "task": "weather_lookup",
    "city": "Mumbai"
}


Any A2A-compliant agent understands the structure.

Mental Model

Think:

HTTP = common language for websites

A2A = common language for agents

Lesson 2: Agent Card
Problem

You discover a new agent.

How do you know:

Agent name?
Skills?
Available capabilities?
Real World Analogy

Meeting a new person.

First thing:

Hi
I am Arif
I am a Software Architect


That's an introduction.

Agents need introductions too.

A2A Solution

An Agent Card.

An Agent Card describes:

Who am I?
What can I do?
How can you contact me?


A2A agents expose metadata about themselves through an Agent Card.

Python Example
agent_card = {
    "name": "WeatherAgent",
    "description": "Provides weather data",
    "skills": [
        "weather_lookup"
    ]
}

Mental Model
Agent Card = LinkedIn Profile of an Agent

Lesson 4: Message
Problem

Once agents discover each other, how do they talk?

A2A Solution

Messages.

A message is the basic communication unit between agents.

Python Example
message = {
    "role": "user",
    "parts": [
        {
            "text": "What's the weather in Mumbai?"
        }
    ]
}

Mental Model
Email between people

=

Message between agents

Lesson 5: Task
Problem

Some requests take time.

Example:

Generate annual report


Could take minutes.

You cannot keep waiting forever.

A2A Solution

Create a Task.

Task #123


Agent returns:

Accepted
Task created


and works asynchronously.

Python Example
task = {
    "id": "123",
    "status": "submitted"
}

Mental Model
Restaurant Order Token

Token #51


You don't stand in the kitchen.

You track progress.

Lesson 7: Artifact
Problem

Agent completes task.

What does it return?

A simple message?

What if output is:

PDF
Analysis report
CSV
Image
A2A Solution

Artifact.

Artifacts represent output produced by an agent.

Python Example
artifact = {
    "id": "report1",
    "content": "Sales increased by 12%"
}

Mental Model
Task = Work Order

Artifact = Deliverable

Lesson 9: Delegation
Problem

A travel planner receives:

Plan trip to Bangalore


Needs:

Weather
Hotels
Flights

One agent can't do everything.

A2A Solution

Delegate.

Travel Agent
    |
    +--> Weather Agent
    |
    +--> Hotel Agent


Multi-agent collaboration is a primary goal of A2A.

Python Example
weather_result = "Sunny"

hotel_result = "Taj Hotel"

response = {
    "weather": weather_result,
    "hotel": hotel_result
}

Mental Model
Manager delegates work
to specialists

Lesson 10: Coordinator Agent
Problem

Many specialist agents exist.

Who orchestrates them?

Solution

Coordinator Agent.

User
 |
Coordinator
 |
+--> Agent A
+--> Agent B
+--> Agent C

Python Example
class Coordinator:

    def handle(self, request):

        weather = "Sunny"
        hotel = "Taj"

        return {
            "weather": weather,
            "hotel": hotel
        }

Project Manager


coordinates work.
