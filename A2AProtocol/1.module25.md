Lesson 25: Multi-Agent Task Chaining (Sequential Workflows)

Until now, our coordinator delegated tasks in parallel:

          Coordinator
         /    |    \
        /     |     \
 Weather  Hotel  Flight


This is great when tasks are independent.

Problem Statement

Suppose the user asks:

Plan my trip under ₹30,000


Can the Budget Agent start immediately?

❌ No.

Why?

Because Budget Agent needs:

Flight Cost
+
Hotel Cost


before calculating affordability.

So the workflow becomes:

Flight Agent
      ↓
Hotel Agent
      ↓
Budget Agent


This is called task chaining.

Parallel vs Sequential
Parallel Delegation

Independent tasks.

Weather
Hotel
Flight


Run together.

await asyncio.gather(
    weather(),
    hotel(),
    flight()
)

Task Chaining

Dependent tasks.

Flight
   ↓
Hotel
   ↓
Budget


Must execute in order.

Real-World Analogy

Building a house:

Paint Walls


cannot happen before:

Build Walls


And:

Build Walls


cannot happen before:

Lay Foundation


Some work naturally forms a chain.

Step 1: Flight Agent
class FlightAgent:

    def search_flight(self):

        return {
            "artifact": {
                "price": 7500
            }
        }

Step 2: Hotel Agent
class HotelAgent:

    def search_hotel(self):

        return {
            "artifact": {
                "price": 12000
            }
        }

Step 3: Budget Agent

Budget depends on both.

class BudgetAgent:

    def analyze(
        self,
        flight_price,
        hotel_price
    ):

        total = flight_price + hotel_price

        return {
            "artifact": {
                "total": total,
                "within_budget":
                    total <= 30000
            }
        }

Step 4: Coordinator Chain
class Coordinator:

    def plan_trip(self):

        flight_agent = FlightAgent()

        flight_result = (
            flight_agent.search_flight()
        )

        hotel_agent = HotelAgent()

        hotel_result = (
            hotel_agent.search_hotel()
        )

        budget_agent = BudgetAgent()

        budget_result = budget_agent.analyze(

            flight_result["artifact"]["price"],

            hotel_result["artifact"]["price"]
        )

        return budget_result

Artifact Passing

This is the key idea.

Without chaining:

Agent A


returns result directly to coordinator.

With chaining:

Agent A Artifact
        ↓
Agent B Input
        ↓
Agent B Artifact
        ↓
Agent C Input


Artifacts become inputs to later tasks.

Example

Flight Agent:

{
    "artifact": {
        "price": 7500
    }
}


Budget Agent receives:

7500


as input.

This is artifact propagation.

Hybrid Workflow

Real systems combine:

Parallel
+
Sequential


Example:

            Coordinator

               |
      +--------+--------+
      |                 |

      Weather       Flight

                     |
                     v

                   Hotel

                     |
                     v

                   Budget


Weather is independent.

Flight → Hotel → Budget is a chain.

Async Chaining Example

Some stages can still run together.

weather_task = get_weather()

flight_task = get_flight()

weather, flight = await asyncio.gather(

    weather_task,

    flight_task
)


Then:

budget = await calculate_budget(
    flight
)


Combination of:

Parallel
then
Sequential


Very common.

Failure Propagation

Suppose:

Flight Search Failed


Then:

Budget Analysis


cannot run.

Chain breaks.

Coordinator may return:

{
    "status": "failed",
    "reason": "Flight data unavailable"
}


or a partial result.

Mental Model

Think of a relay race:

Runner A
   ↓
Runner B
   ↓
Runner C


The baton is the artifact.

Without the baton:

Next runner cannot continue


Similarly:

Artifact
      ↓
Input
      ↓
New Artifact
