This lesson is the point where everything comes together.

We'll build:

User
  |
  v
Coordinator Agent
  |
  +--> Weather Agent
  |
  +--> Hotel Agent
  |

The coordinator will:

Discover agents
Read Agent Cards
Select skills
Send messages over HTTP
Collect artifacts
Aggregate results
Return a final artifact

This is the architecture A2A was designed to enable: independent agents collaborating through a common protocol. A2A Protocol enables agent interoperability, task delegation, and multi-agent collaboration across independently built agents.

Problem Statement

User asks:

Plan my Bangalore trip


Required capabilities:

weather_lookup
hotel_search
flight_search


No single agent knows everything.

A coordinator must orchestrate the work.

Step 5: Discovery

The coordinator discovers capabilities.

import requests

def discover_agent(skill):

    for entry in registry:

        card = requests.get(
            f"{entry['url']}/agent-card"
        ).json()

        if skill in card["skills"]:

            return entry["url"]

    return None

Why This Is Important

Notice:

discover_agent("weather_lookup")


NOT:

find_weather_agent()


A2A is capability-driven.

Think:

Find capability
not implementation

Step 6: Coordinator
import requests

class Coordinator:

Weather Delegation
    def get_weather(self, city):

        agent_url = discover_agent(
            "weather_lookup"
        )

        response = requests.post(

            f"{agent_url}/message",

            json={
                "city": city
            }
        )

        return response.json()

Hotel Delegation
    def get_hotel(self, city):

        agent_url = discover_agent(
            "hotel_search"
        )

        response = requests.post(

            f"{agent_url}/message",

            json={
                "city": city
            }
        )

        return response.json()

Flight Delegation
    def get_flight(self, city):

        agent_url = discover_agent(
            "flight_search"
        )

        response = requests.post(

            f"{agent_url}/message",

            json={
                "city": city
            }
        )

        return response.json()

Aggregate Everything
    def plan_trip(self, city):

        weather = self.get_weather(city)

        hotel = self.get_hotel(city)

        flight = self.get_flight(city)

        return {

            "task_id": "trip-001",

            "status": "completed",

            "artifact": {

                "artifact_id":
                "trip-plan-001",

                "content": {

                    "city": city,

                    "weather":
                    weather["artifact"]["content"],

                    "hotel":
                    hotel["artifact"]["content"],

                    "flight":
                    flight["artifact"]["content"]
                }
            }
        }

Execute
