Now let's build something that behaves like a real A2A agent.

The A2A Protocol defines agent interoperability using standardized agent descriptions (Agent Cards), task handling, and message exchanges between agents.

Problem Statement

So far our agents have been Python objects:

weather_agent.handle_message(message)


But in reality:

Coordinator Agent --> HTTP --> Weather Agent


The agents usually run as separate services.

Question:

How does one agent communicate with another over a network?

Solution

Expose APIs.

Think:

Weather Agent
      |
      +-- GET /agent-card
      |
      +-- POST /message


Other agents can:

Discover capabilities
Send messages
Receive results
Architecture
Coordinator Agent
        |
        | HTTP
        |
        v
+----------------+
| Weather Agent  |
+----------------+

Step 1: Install FastAPI
pip install fastapi uvicorn

Step 2: Create Agent Card Endpoint

Create:

from fastapi import FastAPI

app = FastAPI()


Expose Agent Card:

@app.get("/agent-card")
def get_agent_card():

    return {
        "name": "WeatherAgent",
        "description": "Provides weather information",
        "skills": [
            "weather_lookup"
        ]
    }

Why This Endpoint Exists

A Coordinator can call:

GET /agent-card


and learn:

Who are you?
What skills do you provide?


Exactly what we learned earlier.

Let's Add Tasks

Current implementation is synchronous.

Everything happens immediately.

But we learned:

Long-running work
=
Task

In-Memory Task Store
tasks = {}

Task Submission
from uuid import uuid4

@app.post("/tasks")
def create_task():

    task_id = str(uuid4())

    tasks[task_id] = {
        "status": "submitted"
    }

    return {
        "task_id": task_id,
        "status": "submitted"
    }

Retrieve Task
@app.get("/tasks/{task_id}")
def get_task(task_id: str):

    return tasks[task_id]

Usage

Create Task:

POST /tasks


Response:

{
   "task_id":"abc123",
   "status":"submitted"
}


Check Status:

GET /tasks/abc123


Response:

{
   "status":"submitted"
}

Let's Build a Coordinator Client

card = requests.get(

print(card.json())

Sending Message

    "http://localhost:8000/message",

    }

print(response.json())
