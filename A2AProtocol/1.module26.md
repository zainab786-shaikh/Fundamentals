Lesson 26: Agent-to-Agent Negotiation & Dynamic Routing

Welcome to one of the most important enterprise A2A topics.

Until now, discovery looked like this:

agent = discover_agent("weather_lookup")


We assumed:

One Skill
↓
One Agent


Real systems are rarely that simple.

The A2A Protocol is designed to support interoperable ecosystems where multiple agents may provide the same capability, allowing orchestrators to select the most appropriate agent dynamically.

Problem Statement

Suppose your registry contains:

WeatherAgentIndia
WeatherAgentUS
WeatherAgentPremium


All support:

weather_lookup


Your discovery function returns:

3 matching agents


Question:

Which one should the Coordinator choose?

Naive Solution

Always choose the first.

return agents[0]


Problem:

Agent might be slow
Agent might be expensive
Agent might be overloaded


Not ideal.

Real-World Analogy

Imagine booking a cab.

You have:

Uber Go
Uber Premier
Uber XL


All solve:

Transportation


But you choose based on:

Cost
Speed
Comfort


A2A coordinators do the same thing.

Dynamic Routing

Instead of:

Find Agent


we do:

Find Best Agent

Selection Based on Cost

Requirement:

Choose cheapest weather agent

matching_agents = [
    a for a in agents
    if "weather_lookup" in a["skills"]
]

best_agent = min(
    matching_agents,
    key=lambda a: a["cost"]
)

Example

Input:

[
    {
        "name":"A",
        "cost":3
    },
    {
        "name":"B",
        "cost":1
    }
]


Result:

{
    "name":"B"
}

Selection Based on Latency

Requirement:

Choose fastest agent

best_agent = min(
    matching_agents,
    key=lambda a: a["latency"]
)

Example
Agent A = 500ms

Agent B = 100ms

Agent C = 300ms


Coordinator selects:

Agent B

Selection Based on Trust

Imagine:

{
   "name":"WeatherAgentPremium",
   "trust_score":95
}

{
   "name":"WeatherAgentCommunity",
   "trust_score":60
}


For critical workflows:

best = max(
    agents,
    key=lambda a: a["trust_score"]
)

Enterprise Routing Strategy

Many organizations score agents.

score =
    trust_score
    - cost
    - latency_factor


Example:

agent = {

    "trust": 95,

    "cost": 5,

    "latency": 100
}


Calculate:

score = 95 - 5 - 10

score = 80


Highest score wins.

Negotiation Concept

Now imagine:

Coordinator


finds three weather agents.

Instead of immediately assigning work:

Coordinator:
Can you handle this request?


Each agent responds:

Agent A:
Cost = $1

Agent B:
Cost = $3

Agent C:
Cost = $2


Coordinator chooses.

This is a form of agent negotiation.

Simple Python Simulation
Agents
agents = [

    {
        "name": "WeatherA",

    },

    {
        "name": "WeatherB",
        "cost": 2
    },

    {
        "name": "WeatherC",
        "cost": 3
    }
]


Coordinator:

best = min(

print(best)

{
    "name":"WeatherB",
    "cost":2
}

Fallback Routing

Suppose selected agent fails.

WeatherA ❌


Coordinator automatically retries:

WeatherB ✅


Example:

for agent in ranked_agents:

    try:
        return call_agent(agent)

    except:
        continue
