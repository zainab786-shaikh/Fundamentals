Lesson 3: Skills

In Lesson 2, we learned that an agent publishes an Agent Card describing itself.

Now let's answer an important question:

If I discover an agent, how do I know exactly what operation to ask it to perform?

This is why A2A has the concept of Skills. An agent advertises one or more skills that other agents can invoke. A2A Protocol defines skills as capabilities exposed by an agent and discoverable through its Agent Card.

The Problem

Suppose you discover this agent:

{
    "name": "FinanceAgent"
}


What can it do?

Maybe:

Get stock prices


Or maybe:

Calculate taxes


Or:

Create financial reports


The name alone isn't enough.

Naive Solution

Put everything into the description.

{
    "name": "FinanceAgent",
    "description": "Can get stock prices, calculate taxes and generate reports"
}


Problem:

How does software reliably understand that?

Agents need something structured.

A2A Solution: Skills

A skill is a specific capability an agent offers. Other agents inspect the Agent Card and decide which skill to use.

Think of a skill as:

A menu item in a restaurant


The restaurant is the Agent.

The dishes are the Skills.

Example

A Finance Agent advertises:

agent_card = {
    "name": "FinanceAgent",
    "skills": [
        "stock_price",
        "tax_calculation",
        "report_generation"
    ]
}

Why Skills Matter

Suppose your Travel Agent wants weather information.

It discovers:

{
    "name": "WeatherAgent",
    "skills": [
        "weather_lookup",
        "weather_forecast"
    ]
}


Now it knows exactly what requests are valid.

weather_lookup ✅

tax_calculation ❌

Simple Python Example

Let's build a tiny agent.

class WeatherAgent:

    def get_agent_card(self):
        return {
            "name": "WeatherAgent",
            "skills": [
                "weather_lookup",
                "weather_forecast"
            ]
        }


Client:

agent = WeatherAgent()

card = agent.get_agent_card()

print(card["skills"])


Output:

['weather_lookup', 'weather_forecast']

Choosing the Correct Skill

Imagine the user asks:

What is today's weather in Mumbai?


The client agent thinks:

Need current weather


and chooses:

"weather_lookup"


A request becomes:

{
    "skill": "weather_lookup",
    "city": "Mumbai"
}

Supporting Multiple Skills

Let's build a Calculator Agent.

class CalculatorAgent:

    def get_agent_card(self):
        return {
            "name": "CalculatorAgent",
            "skills": [
                "add",
                "subtract"
            ]
        }

Handling Different Skills
class CalculatorAgent:

    def handle_message(self, message):

        skill = message["skill"]

        if skill == "add":
            return {
                "result": message["a"] + message["b"]
            }

        if skill == "subtract":
            return {
                "result": message["a"] - message["b"]
            }

Usage
agent = CalculatorAgent()

request = {
    "skill": "add",
    "a": 10,
    "b": 20
}

response = agent.handle_message(request)

print(response)


Output:

{'result': 30}

Adding Another Skill

No need to create another agent.

Just advertise another capability.

{
    "name": "CalculatorAgent",
    "skills": [
        "add",
        "subtract",
        "multiply"
    ]
}


Now the same agent can perform three operations.

Real-World Analogy

Consider a hospital:

Hospital = Agent

Cardiology = Skill
Neurology = Skill
Orthopedics = Skill


When a patient arrives:

Need heart treatment


they are routed to:

Cardiology


Similarly:

Need stock price


routes to:

stock_price

Mental Model

Remember:

Agent = Restaurant

Agent Card = Menu

Skill = Menu Item

Message = Order


Example:

Agent      → Calculator

Skill      → add

Message    → add 10 and 20

Result     → 30

What We've Learned

An Agent tells us who it is through its Agent Card.

A Skill tells us what it can do.

Agent Card
    |
    +-- Skill A
    +-- Skill B
    +-- Skill C


Without skills:

"What can this agent do?"


With skills:

"I know exactly which capability to invoke."
