Problem Statement

User asks:

Plan my Bangalore trip


To answer this, we need:

Weather Agent
Hotel Agent


A Coordinator Agent should:

Discover agents
Check their skills
Send messages
Collect results
Create a final artifact

This is very close to how a real A2A Protocol system operates.

Step 1: Weather Agent
class WeatherAgent:

    def get_agent_card(self):
        return {
            "name": "WeatherAgent",
            "skills": ["weather_lookup"]
        }

    def handle_message(self, message):

        city = message["city"]

        return {
            "artifact": {
                "artifact_id": "weather-001",
                "content": f"Sunny in {city}"
            }
        }

Step 2: Hotel Agent
class HotelAgent:

    def get_agent_card(self):

Step 3: Agent Registry (Discovery)

Think of this as a company directory.

weather_agent = WeatherAgent()
hotel_agent = HotelAgent()

agent_registry = [

    {
        "card": weather_agent.get_agent_card(),
        "instance": weather_agent
    },

    {
        "card": hotel_agent.get_agent_card(),
        "instance": hotel_agent
    }

]

Step 4: Discovery Function
def discover_agent(skill):

    for entry in agent_registry:

        card = entry["card"]

        if skill in card["skills"]:

            return entry["instance"]

    return None

Step 5: Coordinator Agent
class TravelCoordinator:

    def plan_trip(self, city):

        weather_agent = discover_agent(
            "weather_lookup"
        )

        hotel_agent = discover_agent(
            "hotel_search"
        )

        weather_result = weather_agent.handle_message(
            {
                "city": city
            }
        )

        hotel_result = hotel_agent.handle_message(
            {
                "city": city
            }
        )

        return {
            "task_id": "trip-001",
            "status": "completed",

            "artifact": {
                "artifact_id": "trip-plan-001",

                "content": {

                    "city": city,

                    "weather":
                    weather_result["artifact"]["content"],

                    "hotel":
                    hotel_result["artifact"]["content"]
                }
            }
        }

Step 6: Execute
coordinator = TravelCoordinator()

result = coordinator.plan_trip(
    "Bangalore"
)

print(result)

The Architectural Insight

Notice something important:

The Coordinator never does:

WeatherAgent()
HotelAgent()


inside its code.

Instead:

discover_agent(skill)


This means a new agent can join the system without changing coordinator logic.

That's one of the main goals of A2A Protocol: interoperability and loose coupling between independently built agents.
