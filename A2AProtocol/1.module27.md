Lesson 27: Hierarchical Multi-Agent Systems (Coordinator of Coordinators)

Welcome to the architecture used in large enterprises.

Up to now, we had:

User
  |
Coordinator
  |
+----+----+----+
|    |    |
A    B    C


This works for a handful of agents.

But what happens when your organization has:

100 Agents
500 Agents
1000+ Agents


One coordinator becomes a bottleneck.

Problem Statement

Suppose you're building an Enterprise Assistant.

User asks:

Prepare Q4 Business Review


This requires:

Sales Data
Finance Data
HR Data
Technology Data
Risk Data


If one coordinator manages everything:

Coordinator
 |
 +--- 100 Agents

Too many dependencies
Hard to maintain

Complex routing logic

Instead of:

 |

Global Coordinator
        |

    "task":
    "Prepare Q4 Business Review"

Python Example
Business Coordinator
class BusinessCoordinator:

    def execute(self):

        return {
            "sales": "$10M",

            "finance":
            "Profitable",

            "hr":
            "500 Employees"
        }

Technology Coordinator
class TechnologyCoordinator:

    def execute(self):

        return {
            "cloud": "Azure",

            "security":
            "Healthy",

            "platform":
            "Stable"
        }

Global Coordinator
class GlobalCoordinator:

    def execute(self):

        business = (
            BusinessCoordinator()
            .execute()
        )

        technology = (
            TechnologyCoordinator()
            .execute()
        )

        return {

            "business":
            business,

            "technology":
            technology
        }

Artifact Aggregation

Bottom-level agents produce artifacts.

Example:

Sales Report


↓

Business Coordinator combines.

Business Summary


↓

Global Coordinator combines.

Enterprise Review


This is called progressive aggregation.

Progressive Aggregation Pattern
Agent
 ↓
Sub-Coordinator
 ↓
Coordinator
 ↓
Final Artifact


Each layer produces a higher-level summary.

Failure Isolation

Suppose:

Security Agent Fails


Does the entire system fail?

Not necessarily.

Technology Coordinator may return:

{
    "cloud": "Complete",

    "platform": "Complete",

    "security":
    "Unavailable"
}


Global Coordinator can still generate a report.

This is why hierarchical systems are more resilient.

Async Hierarchical Execution

Each coordinator can execute its children in parallel.

business = await business_coordinator()

technology = await technology_coordinator()


And inside Business Coordinator:

sales, finance, hr = await asyncio.gather(
    sales_agent(),
    finance_agent(),
    hr_agent()
)


This scales extremely well.
