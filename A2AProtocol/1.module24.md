Lesson 24: Build a Mini A2A Server (tasks/send, tasks/get, tasks/cancel)

So far we've handled a single request.

Now let's solve a real problem:

What happens after a task is created?

A real A2A-style agent needs to:

Create Tasks
Track Tasks
Cancel Tasks
Store Task State
Return Artifacts


This lesson will build a small in-memory A2A server that supports:

tasks/send
tasks/get
tasks/cancel


These operations map directly to the task-oriented interaction model used by the A2A Protocol.

Problem Statement

Suppose a coordinator sends:

{
  "id": 1,
  "method": "tasks/send"
}


Task gets created.

Five minutes later:

What's the status?


How do we answer?

We need task storage.

Step 1: Create a Task Store

Think of this as a mini database.

tasks = {}


Example:

tasks["T1"] = {
    "status": "working"
}

Step 2: Implement tasks/send

This method creates a new task.

import uuid

tasks = {}

def send_task(params):

    task_id = str(uuid.uuid4())

    task = {
        "task_id": task_id,
        "status": "submitted"
    }

    tasks[task_id] = task

    return task

Test
result = send_task({})

print(result)


Output:

{
    "task_id": "...",
    "status": "submitted"
}

Step 3: Implement tasks/get

Now retrieve an existing task.

def get_task(params):

    return tasks.get(task_id)

Step 4: Implement tasks/cancel

Sometimes work must stop.

Example:

User closes browser

Request no longer needed


Add cancel support.

def cancel_task(params):

Complete Server
import uuid

tasks = {}

def send_task(params):

    task_id = str(uuid.uuid4())

    task = {
        "task_id": task_id,
        "status": "submitted"
    }

    tasks[task_id] = task

    return task


def get_task(params):

    return tasks.get(
        params["task_id"]
    )


def cancel_task(params):

    task_id = params["task_id"]

    if task_id in tasks:

        tasks[task_id]["status"] = "cancelled"

        return tasks[task_id]


def handle_request(request):

    method = request["method"]

    params = request["params"]

    if method == "tasks/send":

        result = send_task(params)

    elif method == "tasks/get":

        result = get_task(params)

    elif method == "tasks/cancel":

        result = cancel_task(params)

    else:

        return {
            "id": request["id"],
            "error": {
                "code": "INVALID_METHOD"
            }
        }

    return {

        "id": request["id"],

        "result": result
    }
