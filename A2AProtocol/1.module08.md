Your Travel Agent needs weather information.

How does it find the Weather Agent?

Naive Solution

Why This Fails

New WeatherAgent deployed

A better WeatherAgent is available


Now you must update all clients.

Imagine:

100 Agents

Each knows every other agent


Chaos.

Real World Analogy

Think about LinkedIn.

You don't already know every architect, developer, or manager.

Instead:

Search
→ Find Person

Discovery works the same way for agents.

A2A Solution: Agent Discovery

In the Agent2Agent (A2A) Protocol, agents expose an Agent Card so that other agents can discover their capabilities, skills, and endpoints before interacting with them.

The process becomes:

Search
    ↓
Find Agent Card
    ↓
Inspect Skills
    ↓
Send Message

First Discovery Registry

Let's create a simple registry.

agents = [
    {
        "name": "WeatherAgent",
        "skills": [
            "weather_lookup"
        ]
    },
    {
        "name": "FinanceAgent",
        "skills": [
            "stock_price"
        ]
    },
    {
        "name": "TranslationAgent",
        "skills": [
            "translate_text"
        ]
    }
]


Think of this as a mini company directory.

Finding an Agent

Suppose we need:

weather_lookup


Search the registry.

for agent in agents:

    if "weather_lookup" in agent["skills"]:

        print(agent["name"])


Output:

WeatherAgent


Discovery successful ✅

Why Search by Skill?

Beginners often think:

Find WeatherAgent


But A2A thinks differently.

Ask:

Who can perform weather_lookup?


Why?

Because tomorrow:

WeatherAgentV2
WeatherProAgent
GlobalWeatherAgent


might all support:

weather_lookup


Your client doesn't care about names.

It cares about capabilities.

Better Discovery Function
def discover_agent(skill, agents):

    for agent in agents:

        if skill in agent["skills"]:

            return agent

    return None


Usage:

result = discover_agent(
    "weather_lookup",
    agents
)

print(result)


Output:

{
    'name': 'WeatherAgent',
    'skills': ['weather_lookup']
}

This is one reason A2A emphasizes capabilities rather than hardcoded agent names.

Complete Example
agents = [

    {
        "name": "WeatherAgent",
        "skills": ["weather_lookup"]
    },

    {
        "name": "FinanceAgent",
        "skills": ["stock_price"]
    }
]


def discover_agent(skill):

    for agent in agents:

        if skill in agent["skills"]:
            return agent

    return None


agent = discover_agent("stock_price")

print(agent)


Output:

{
   'name': 'FinanceAgent',
   'skills': ['stock_price']
}
