Problem Statement

Suppose you're building a:

Weather Agent


Question:

What makes it an A2A Agent?

Not the business logic.

This:

def get_weather(city):
    return "Sunny"


is NOT A2A.

An A2A agent must expose:

1. Agent Card
2. Task Interface
3. Message Processing
4. Artifact Generation


as defined by the A2A Protocol.

Step 1: Agent Card

First introduce yourself.

agent_card = {
    "name": "WeatherAgent",
    "description": "Provides weather information",
    "skills": [
        {
            "id": "weather_lookup",
            "description": "Get weather for city"
        }
    ]
}


Think:

LinkedIn Profile

Step 2: Message Arrives

Coordinator sends:

{
  "role": "user",
  "parts": [
    {
      "type": "text",
      "text": "Weather in Mumbai"
    }
  ]
}

Step 3: Create Task

Agent creates:

task = {

    "task_id": "W001",

    "status": "submitted"
}

Step 4: Process Request
task["status"] = "working"


Agent executes:

weather = "Sunny in Mumbai"

Step 5: Create Artifact
artifact = {

    "artifact_id": "A001",

    "content": weather
}

Step 6: Complete Task
task["status"] = "completed"

task["artifact"] = artifact

Complete Flow
Message
    ↓
Task Created
    ↓
Task Working
    ↓
Artifact Created
    ↓
Task Completed


Notice:

Message ≠ Result

Task ≠ Result

Artifact = Result


This is a key A2A principle.

Minimal Python Version
class WeatherAgent:

    def process(self, city):

        task = {
            "task_id": "W001",
            "status": "working"
        }

        weather = f"Sunny in {city}"

        artifact = {
            "artifact_id": "A001",
            "content": weather
        }

        task["status"] = "completed"
        task["artifact"] = artifact

        return task


Usage:

agent = WeatherAgent()

print(
    agent.process("Mumbai")
)


Output:

{
    'task_id': 'W001',
    'status': 'completed',
    'artifact': {
        'artifact_id': 'A001',
        'content': 'Sunny in Mumbai'
    }
}
