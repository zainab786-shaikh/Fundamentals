Lesson 18: Asynchronous A2A (Why Async Matters)

Until now, our Coordinator works like this:

Get Weather
     ↓
Get Hotel
     ↓
Get Flight


This is called sequential execution.

Problem Statement

Suppose:

Weather Agent = 2 sec

Hotel Agent = 3 sec

Flight Agent = 4 sec


Our current code:

weather = get_weather()

hotel = get_hotel()

flight = get_flight()


Timeline:

0s → Weather starts
2s → Weather completed

2s → Hotel starts
5s → Hotel completed

5s → Flight starts
9s → Flight completed


Total:

9 seconds

Humans naturally do things in parallel.

A2A systems should too.

Solution: Async Delegation

Instead of:

A
then B
then C


we do:

A
B
C

at the same time


Timeline:

Weather starts

4 seconds

9 seconds

Understanding Asyncio

Python provides:

import asyncio


Think of async as:

Start work

↓

Don't wait

↓

Start another work

↓

Collect all results later

Simple Example

Normal:

import time

def weather():
    time.sleep(2)
    return "Sunny"

def hotel():
    time.sleep(3)
    return "Taj"

weather_result = weather()
hotel_result = hotel()


This waits.

Async Version
import asyncio

async def weather():

    await asyncio.sleep(2)

    return "Sunny"

async def hotel():

    await asyncio.sleep(3)

    return "Taj"


Notice:

async
await


These are the two new keywords.

First Async Execution
async def main():

    weather_result = await weather()

    hotel_result = await hotel()

    print(weather_result)
    print(hotel_result)


Still sequential.

The Real Power: Parallel Execution

Use:

asyncio.gather()

Example
async def main():

    weather_result, hotel_result = await asyncio.gather(

        weather(),

        hotel()

    )

    print(weather_result)
    print(hotel_result)


Now both tasks start together.

Visual Timeline

Without gather:

Weather (2s)

↓

Hotel (3s)

Total = 5s


With gather:

Weather (2s)
Hotel   (3s)

Running Together

Total = 3s

Applying This to A2A

Our Coordinator previously did:

weather = get_weather()

hotel = get_hotel()

flight = get_flight()


Sequential.

Let's make specialists async.

Specialist Agents
import asyncio

class WeatherAgent:

    async def handle_message(self):

        await asyncio.sleep(2)

        return "Sunny"

class HotelAgent:

    async def handle_message(self):

        await asyncio.sleep(3)

        return "Taj Hotel"

class FlightAgent:

    async def handle_message(self):

        await asyncio.sleep(4)

        return "AI101"

Async Coordinator
class Coordinator:

    async def plan_trip(self):

        weather_agent = WeatherAgent()

        hotel_agent = HotelAgent()

        flight_agent = FlightAgent()

        weather, hotel, flight = await asyncio.gather(

            weather_agent.handle_message(),

            hotel_agent.handle_message(),

            flight_agent.handle_message()

        )

        return {
            "weather": weather,
            "hotel": hotel,
            "flight": flight
        }

Execute
result = asyncio.run(
    Coordinator().plan_trip()
)

print(result)


Output:

{
    'weather': 'Sunny',
    'hotel': 'Taj Hotel',
    'flight': 'AI101'
}

Why A2A Systems Use Async

Imagine a Coordinator working with:

Weather Agent
Hotel Agent
Flight Agent
Maps Agent
Restaurant Agent
Traffic Agent
Events Agent


Sequential:

1 + 2 + 3 + 4 + 5 + 6 + 7


Very slow.

Parallel:

max(1,2,3,4,5,6,7)


Much faster.

This is why most production agent systems heavily use asynchronous execution.

Real HTTP Example

Earlier we used:

requests.post(...)


which blocks.

Modern A2A agents often use:

httpx.AsyncClient()


Example:

import httpx

async with httpx.AsyncClient() as client:

    response = await client.post(
        "http://agent/message",
        json=data
    )


Notice:

await


The coordinator can call many agents concurrently.

Problem-Solving Exercise
Requirement

Three specialists:

AdditionAgent
2 seconds

MultiplicationAgent
3 seconds

DivisionAgent
4 seconds


Run them simultaneously.

Solution
import asyncio

async def add():

    await asyncio.sleep(2)

    return 30


async def multiply():

    await asyncio.sleep(3)

    return 200


async def divide():

    await asyncio.sleep(4)

    return 5


async def main():

    results = await asyncio.gather(

        add(),

        multiply(),

        divide()

    )

    print(results)


asyncio.run(main())


Output:

[30, 200, 5]


Total runtime:

4 seconds


not

9 seconds
