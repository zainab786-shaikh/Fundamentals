Aggregating Child States

Rule:

IF all child tasks completed

THEN parent completed

Simple Example
child_tasks = [

    {"status": "completed"},

    {"status": "completed"},

    {"status": "completed"}
]


Check:

all_completed = all(
    task["status"] == "completed"
    for task in child_tasks
)

print(all_completed)


Output:

True

Parent Completion
if all_completed:

    parent_task["status"] = "completed"

Python Implementation
class Coordinator:

    def create_trip_task(self):

        parent_task = {
            "task_id": "T1",
            "status": "working"
        }

        child_tasks = [

            {
                "task_id": "T1.1",
                "status": "completed"
            },

            {
                "task_id": "T1.2",
                "status": "completed"
            },

            {
                "task_id": "T1.3",
                "status": "completed"
            }
        ]

        if all(
            t["status"] == "completed"
            for t in child_tasks
        ):

            parent_task["status"] = "completed"

        return parent_task
