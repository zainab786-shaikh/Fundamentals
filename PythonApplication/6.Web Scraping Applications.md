# 6. Web Scraping Applications

Web scraping uses software to retrieve web pages, select useful information, and convert it into structured data.

> **Important:** Scrape only public information you are authorized to access. Follow the website’s terms, `robots.txt`, copyright rules, privacy requirements, and rate limits. Do not bypass authentication, CAPTCHAs, or technical access controls.

## 6.1 Introduction to Web Scraping

### How web scraping works

A basic scraper usually:

1. Sends an HTTP request.
2. Receives HTML.
3. Parses the HTML.
4. Selects the required elements.
5. Cleans and stores the extracted information.

The following example downloads `example.com` and extracts its page title:

```python name=basic_scraper.py
import requests
from bs4 import BeautifulSoup

URL = "https://example.com/"

response = requests.get(
    URL,
    timeout=10,
    headers={"User-Agent": "LearningScraper/1.0"},
)
response.raise_for_status()

soup = BeautifulSoup(response.text, "html.parser")
title = soup.title.get_text(strip=True) if soup.title else "No title"

print(title)
```

- `timeout` prevents the program from waiting indefinitely.
- `raise_for_status()` raises an exception for unsuccessful HTTP responses.
- `get_text(strip=True)` extracts clean text from an element.

### Common use cases and limitations

Common uses include:

- Monitoring public product prices.
- Collecting public articles or reports.
- Detecting changes to documentation.
- Building searchable datasets.
- Monitoring public service status pages.

Common limitations include:

- HTML structure can change without notice.
- JavaScript may load content after the initial request.
- Rate limits may restrict request frequency.
- Login-protected or personalized pages require authorization.
- Scraped data may be incomplete or inaccurate.

### Ethical, legal, and privacy considerations

Before scraping a website:

- Review its terms of service.
- Collect only the information needed.
- Avoid personal or sensitive information.
- Do not bypass login pages or access controls.
- Avoid reproducing copyrighted content without permission.
- Identify your scraper when appropriate.
- Provide contact information for substantial crawlers.

### Respecting `robots.txt`

Python includes a standard `urllib.robotparser` module for checking `robots.txt` rules:

```python name=robots_check.py
from urllib.robotparser import RobotFileParser

BASE_URL = "https://example.com"
TARGET_URL = f"{BASE_URL}/"
USER_AGENT = "LearningScraper"

robots = RobotFileParser()
robots.set_url(f"{BASE_URL}/robots.txt")
robots.read()

if robots.can_fetch(USER_AGENT, TARGET_URL):
    print("The robots.txt rules allow this request.")
else:
    print("The robots.txt rules do not allow this request.")
```

A missing or permissive `robots.txt` file does **not** automatically grant legal permission. Terms of service and applicable laws still matter.

### Applying a request delay

A delay reduces pressure on the target server:

```python name=polite_requests.py
import time

import requests

URLS = [
    "https://example.com/",
    "https://example.com/?page=2",
]

session = requests.Session()
session.headers["User-Agent"] = "LearningScraper/1.0"

for url in URLS:
    response = session.get(url, timeout=10)
    response.raise_for_status()

    print(url, response.status_code)
    time.sleep(2)
```

## 6.2 Price Monitoring

### Extracting product names, prices, and availability

For learning and testing, parse locally defined HTML instead of depending on a real store:

```python name=extract_products.py
from decimal import Decimal, InvalidOperation

from bs4 import BeautifulSoup

HTML = """
<section class="product">
    <h2 class="name">Wireless Keyboard</h2>
    <span class="price">49.99</span>
    <span class="availability">In stock</span>
</section>
"""

soup = BeautifulSoup(HTML, "html.parser")

for product in soup.select(".product"):
    name_element = product.select_one(".name")
    price_element = product.select_one(".price")
    availability_element = product.select_one(".availability")

    if not name_element or not price_element:
        continue

    try:
        price = Decimal(price_element.get_text(strip=True))
    except InvalidOperation:
        print("Invalid price; skipping product.")
        continue

    product_data = {
        "name": name_element.get_text(strip=True),
        "price": price,
        "availability": (
            availability_element.get_text(strip=True)
            if availability_element
            else "Unknown"
        ),
    }

    print(product_data)
```

`Decimal` is preferable to `float` for monetary values because it avoids common floating-point rounding errors.

### Comparing prices across websites

Normalize all results into the same structure before comparing them:

```python name=compare_prices.py
from decimal import Decimal

offers = [
    {"store": "Store A", "product": "Wireless Keyboard", "price": Decimal("49.99")},
    {"store": "Store B", "product": "Wireless Keyboard", "price": Decimal("44.50")},
    {"store": "Store C", "product": "Wireless Keyboard", "price": Decimal("47.25")},
]

lowest_offer = min(offers, key=lambda offer: offer["price"])

print(
    f"Lowest price: {lowest_offer['store']} "
    f"at ${lowest_offer['price']:.2f}"
)
```

Make sure products are genuinely equivalent before comparing prices. Model number, size, currency, tax, shipping, and condition may differ.

### Scheduling recurring collection

One simple option is to run a Python script with an operating-system scheduler:

- **Linux/macOS:** `cron`
- **Windows:** Task Scheduler
- **Production:** GitHub Actions, a job queue, or a cloud scheduler

Keep the Python script focused on one execution:

```python name=monitor_price.py
from datetime import UTC, datetime
from decimal import Decimal


def collect_price() -> Decimal:
    # Replace this demonstration value with an authorized scraper.
    return Decimal("44.50")


def main() -> None:
    price = collect_price()
    checked_at = datetime.now(UTC)

    print(f"{checked_at.isoformat()}: ${price:.2f}")


if __name__ == "__main__":
    main()
```

A cron job could execute it every six hours:

```cron name=price-monitor.cron
0 */6 * * * /path/to/.venv/bin/python /path/to/monitor_price.py
```

### Sending price-drop notifications

This example prints an alert. In production, the same function could call an approved email, SMS, or webhook provider.

```python name=price_alert.py
from decimal import Decimal


def notify_price_drop(product: str, current: Decimal, target: Decimal) -> None:
    if current <= target:
        print(
            f"Price alert: {product} is now ${current:.2f}; "
            f"your target was ${target:.2f}."
        )


notify_price_drop(
    product="Wireless Keyboard",
    current=Decimal("44.50"),
    target=Decimal("45.00"),
)
```

Do not hardcode API keys for notification services. Read secrets from environment variables or a secrets manager.

## 6.3 Content Collection

### Collecting articles and listings

```python name=collect_articles.py
from bs4 import BeautifulSoup

HTML = """
<main>
    <article>
        <h2><a href="/articles/python-basics">Python Basics</a></h2>
        <p>Learn the foundations of Python.</p>
    </article>
    <article>
        <h2><a href="/articles/web-scraping">Web Scraping</a></h2>
        <p>Learn how HTML parsing works.</p>
    </article>
</main>
"""

soup = BeautifulSoup(HTML, "html.parser")
articles: list[dict[str, str]] = []

for article in soup.select("article"):
    link = article.select_one("h2 a")
    summary = article.select_one("p")

    if not link:
        continue

    articles.append(
        {
            "title": link.get_text(" ", strip=True),
            "url": link.get("href", ""),
            "summary": summary.get_text(" ", strip=True) if summary else "",
        }
    )

print(articles)
```

### Handling pagination

Pagination is commonly represented by page numbers or a “Next” link.

```python name=pagination.py
from urllib.parse import urljoin

from bs4 import BeautifulSoup

BASE_URL = "https://example.com"
HTML = """
<a class="next" href="/articles?page=2">Next</a>
"""

soup = BeautifulSoup(HTML, "html.parser")
next_link = soup.select_one("a.next")

if next_link and next_link.get("href"):
    next_url = urljoin(BASE_URL, next_link["href"])
    print(next_url)
```

A production crawler should also:

- Set a maximum number of pages.
- Track visited URLs to avoid loops.
- Apply a delay between requests.
- Stop when no next-page link exists.

### Handling infinite scrolling

Infinite scrolling normally requires browser automation because JavaScript loads additional content as the user scrolls. Playwright can scroll the page and wait for new elements, as shown later in section 6.7.

### Storing data in SQLite

Parameterized queries prevent SQL injection and safely handle special characters:

```python name=store_articles.py

articles = [
    (
        "Python Basics",
        "https://example.com/articles/python-basics",
    ),
]

    connection.execute(
        """
        CREATE TABLE IF NOT EXISTS articles (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL,
            url TEXT NOT NULL UNIQUE
        )
        """

    connection.executemany(
        """
        INSERT INTO articles (title, url)
        VALUES (?, ?)
        ON CONFLICT(url) DO UPDATE SET title = excluded.title
        """,
        articles,
    )
```

## 6.4 Change Detection

### Detecting page changes

A simple method is to hash the relevant content and compare it with the previous hash.

```python name=detect_change.py
import hashlib
from pathlib import Path

STATE_FILE = Path("previous_hash.txt")


def create_hash(content: str) -> str:
    normalized = " ".join(content.split())
    return hashlib.sha256(normalized.encode("utf-8")).hexdigest()


current_content = "Service status: Operational"
current_hash = create_hash(current_content)

previous_hash = (
    STATE_FILE.read_text(encoding="utf-8").strip()
    if STATE_FILE.exists()
    else None
)

if previous_hash is None:
    print("Initial snapshot created.")
elif previous_hash != current_hash:
    print("The monitored content changed.")
else:
    print("No change detected.")

STATE_FILE.write_text(current_hash, encoding="utf-8")
```

### Monitoring a selected element

Hash only the relevant element to avoid false alerts caused by advertisements, timestamps, or unrelated layout changes:

```python name=monitor_element.py
import hashlib

from bs4 import BeautifulSoup

HTML = """
<html>
    <p id="service-status">Operational</p>
    <p>Page generated at 10:30</p>
</html>
"""

soup = BeautifulSoup(HTML, "html.parser")
status_element = soup.select_one("#service-status")

if status_element is None:
    raise ValueError("Expected status element was not found.")

status_text = status_element.get_text(" ", strip=True)
status_hash = hashlib.sha256(status_text.encode("utf-8")).hexdigest()

print(status_text)
print(status_hash)
```

### Generating webhook alerts

Webhook destinations must be allow-listed to prevent Server-Side Request Forgery (SSRF):

```python name=webhook_alert.py
import os
from urllib.parse import urlparse

import requests

ALLOWED_WEBHOOK_HOSTS = {"hooks.example.com"}


def validate_webhook_url(url: str) -> None:
    parsed = urlparse(url)

    if parsed.scheme != "https":
        raise ValueError("Webhook URL must use HTTPS.")

    if parsed.hostname not in ALLOWED_WEBHOOK_HOSTS:
        raise ValueError("Webhook host is not allowed.")

    if parsed.port not in (None, 443):
        raise ValueError("Webhook must use the standard HTTPS port.")

    if not parsed.path.startswith("/scraper-alerts/"):
        raise ValueError("Webhook path is not allowed.")

    if parsed.username or parsed.password:
        raise ValueError("Credentials must not appear in the URL.")


webhook_url = os.environ["SCRAPER_WEBHOOK_URL"]
validate_webhook_url(webhook_url)

response = requests.post(
    webhook_url,
    json={"message": "The monitored page changed."},
    timeout=10,
    allow_redirects=False,
)
response.raise_for_status()
```

In production, DNS resolution must also be checked to ensure an allowed hostname does not resolve to a private, loopback, or link-local address.

## 6.6 Scrapy

Scrapy is a crawling framework suited to multi-page collection. It includes request scheduling, concurrency control, retries, item processing, and export support.

### Creating a spider

Create a project:

```bash name=create_scrapy_project.sh
scrapy startproject tutorial
cd tutorial
scrapy genspider example example.com
```

A simple spider could look like this:

```python name=tutorial/spiders/example.py
import scrapy


class ExampleSpider(scrapy.Spider):
    name = "example"
    allowed_domains = ["example.com"]
    start_urls = ["https://example.com/"]

    custom_settings = {
        "ROBOTSTXT_OBEY": True,
        "CONCURRENT_REQUESTS_PER_DOMAIN": 2,
        "DOWNLOAD_DELAY": 1.0,
    }

    def parse(self, response: scrapy.http.Response):
        yield {
            "title": response.css("title::text").get(default="").strip(),
            "url": response.url,
        }
```

Run it with:

```bash name=run_scrapy.sh
scrapy crawl example -O results.json
```

`-O` overwrites the output file. Use `-o` if you want Scrapy’s supported append behavior.

### Following links and crawl rules

```python name=tutorial/spiders/articles.py
import scrapy
from scrapy.linkextractors import LinkExtractor
from scrapy.spiders import CrawlSpider, Rule


class ArticleSpider(CrawlSpider):
    name = "articles"
    allowed_domains = ["example.com"]
    start_urls = ["https://example.com/articles"]

    rules = (
        Rule(
            LinkExtractor(allow=(r"/articles/",)),
            callback="parse_article",
            follow=True,
        ),
    )

    custom_settings = {
        "ROBOTSTXT_OBEY": True,
        "DOWNLOAD_DELAY": 1.0,
        "CLOSESPIDER_PAGECOUNT": 100,
    }

    def parse_article(self, response: scrapy.http.Response):
        yield {
            "title": response.css("h1::text").get(default="").strip(),
            "url": response.url,
        }
```

`allowed_domains`, the link pattern, and `CLOSESPIDER_PAGECOUNT` help prevent accidental crawling outside the intended scope.

### Processing data with item pipelines

Pipelines can validate, clean, discard, or save scraped records:

```python name=tutorial/pipelines.py
from itemadapter import ItemAdapter
from scrapy.exceptions import DropItem


class ValidateArticlePipeline:
    def process_item(self, item, spider):
        adapter = ItemAdapter(item)

        title = adapter.get("title", "").strip()
        url = adapter.get("url", "").strip()

        if not title:
            raise DropItem("Missing article title.")

        if not url.startswith("https://example.com/"):
            raise DropItem("Unexpected article URL.")

        adapter["title"] = title
        adapter["url"] = url
        return item
```

Enable the pipeline in settings:

```python name=tutorial/settings.py
ROBOTSTXT_OBEY = True

ITEM_PIPELINES = {
    "tutorial.pipelines.ValidateArticlePipeline": 300,
}

CONCURRENT_REQUESTS_PER_DOMAIN = 2
DOWNLOAD_DELAY = 1.0
RANDOMIZE_DOWNLOAD_DELAY = True

RETRY_ENABLED = True
RETRY_TIMES = 2

DOWNLOAD_TIMEOUT = 15
```

### Retries, throttling, and concurrency

- **Retries** handle temporary network or server failures.
- **Throttling** reduces request speed when the server responds slowly.
- **Concurrency** controls how many requests run simultaneously.

Scrapy’s AutoThrottle extension can adjust delays automatically:

```python name=tutorial/settings_autothrottle.py
AUTOTHROTTLE_ENABLED = True
AUTOTHROTTLE_START_DELAY = 1.0
AUTOTHROTTLE_MAX_DELAY = 30.0
AUTOTHROTTLE_TARGET_CONCURRENCY = 1.0
```

AutoThrottle improves politeness but does not override a website’s stated rate limits.

## 6.7 Playwright

Playwright controls real browsers. It is useful when JavaScript renders the required content or when an authorized workflow requires normal browser interaction.

### Scraping JavaScript-rendered content

```python name=playwright_scraper.py
from playwright.sync_api import sync_playwright

URL = "https://example.com/"

with sync_playwright() as playwright:
    browser = playwright.chromium.launch(headless=True)

    page = browser.new_page(
        user_agent="LearningScraper/1.0",
        viewport={"width": 1280, "height": 720},
    )

    page.goto(URL, wait_until="domcontentloaded", timeout=15_000)

    title = page.locator("h1").text_content()
    print(title.strip() if title else "No heading")

    browser.close()
```

### Interacting with forms and buttons

Use this pattern only on websites and accounts you are authorized to automate:

```python name=playwright_form.py
from playwright.sync_api import sync_playwright

with sync_playwright() as playwright:
    browser = playwright.chromium.launch(headless=True)
    page = browser.new_page()

    page.set_content(
        """
        <form>
            <label>
                Search
                <input name="query">
            </label>
            <button type="submit">Submit</button>
        </form>
        """
    )

    page.get_by_label("Search").fill("Python")
    page.get_by_role("button", name="Submit").click()

    browser.close()
```

Role- and label-based selectors are generally clearer and more accessible than fragile selectors based on layout.

### Waiting for dynamic content

Wait for a specific state instead of adding arbitrary sleep periods:

```python name=playwright_wait.py
from playwright.sync_api import sync_playwright

with sync_playwright() as playwright:
    browser = playwright.chromium.launch(headless=True)
    page = browser.new_page()

    page.set_content(
        """
        <div id="status">Loaded</div>
        """
    )

    status = page.locator("#status")
    status.wait_for(state="visible", timeout=5_000)

    print(status.text_content())
    browser.close()
```

Prefer:

- `locator.wait_for()`
- `page.wait_for_url()`
- `page.expect_response()`

Avoid fixed sleeps unless no reliable page signal exists.

### Handling infinite scrolling

```python name=playwright_scroll.py
from playwright.sync_api import sync_playwright

MAX_SCROLLS = 5

with sync_playwright() as playwright:
    browser = playwright.chromium.launch(headless=True)
    page = browser.new_page()
    page.goto(
        "https://example.com/",
        wait_until="domcontentloaded",
        timeout=15_000,
    )

    previous_height = 0

    for _ in range(MAX_SCROLLS):
        current_height = page.evaluate("document.body.scrollHeight")

        if current_height == previous_height:
            break

        previous_height = current_height
        page.evaluate("window.scrollTo(0, document.body.scrollHeight)")
        page.wait_for_timeout(1_000)

    print(f"Found {page.locator('article').count()} articles.")
    browser.close()
```

A maximum scroll count prevents an endless loop.

### Handling authentication securely

Never hardcode usernames, passwords, tokens, or cookies:


## 6.8 Reliability and Security

### Strict URL allow-list validation

Accepting arbitrary user-provided URLs can create an SSRF vulnerability, allowing attackers to target internal services.

```python name=url_validation.py
from urllib.parse import urlparse

ALLOWED_TARGETS = {
    "example.com": {"/", "/articles", "/products"},
}


def validate_target_url(url: str) -> str:
    parsed = urlparse(url)

    if parsed.scheme != "https":
        raise ValueError("Only HTTPS URLs are allowed.")

    if parsed.username or parsed.password:
        raise ValueError("URL credentials are not allowed.")

    if parsed.hostname not in ALLOWED_TARGETS:
        raise ValueError("Host is not allowed.")

    if parsed.port not in (None, 443):
        raise ValueError("Only the standard HTTPS port is allowed.")

    if parsed.path not in ALLOWED_TARGETS[parsed.hostname]:
        raise ValueError("Path is not allowed.")

    if parsed.fragment:
        raise ValueError("URL fragments are not allowed.")

    return url


print(validate_target_url("https://example.com/articles"))
```

Production protection should additionally:

- Resolve DNS before connecting.
- Reject loopback, private, link-local, multicast, and reserved IP ranges.
- Validate every redirect target.
- Protect against DNS rebinding.
- Apply outbound firewall or proxy restrictions.
- Disable redirects when they are unnecessary.

### Timeouts and retries

Retries should be limited and used only for temporary failures:

```python name=request_with_retries.py
import time

import requests

URL = "https://example.com/"
MAX_ATTEMPTS = 3

for attempt in range(1, MAX_ATTEMPTS + 1):
    try:
        response = requests.get(URL, timeout=(3, 10))
        response.raise_for_status()
        print("Request completed.")
        break
    except requests.RequestException as error:
        if attempt == MAX_ATTEMPTS:
            raise RuntimeError("Request failed after all attempts.") from error

        delay_seconds = 2 ** (attempt - 1)
        print(f"Temporary failure; retrying in {delay_seconds} seconds.")
        time.sleep(delay_seconds)
```

Exponential backoff prevents rapid repeated requests during an outage.

### Rate limiting

A basic local rate limiter can maintain a minimum interval between requests:

```python name=rate_limiter.py
import time


class RateLimiter:
    def __init__(self, minimum_interval_seconds: float) -> None:
        self.minimum_interval = minimum_interval_seconds
        self.last_request_at: float | None = None

    def wait(self) -> None:
        if self.last_request_at is not None:
            elapsed = time.monotonic() - self.last_request_at
            remaining = self.minimum_interval - elapsed

            if remaining > 0:
                time.sleep(remaining)

        self.last_request_at = time.monotonic()


limiter = RateLimiter(minimum_interval_seconds=2)

for page_number in range(1, 4):
    limiter.wait()
    print(f"Requesting page {page_number}")
```

Distributed workers require a shared limiter, such as one implemented with a centralized queue or Redis.

### Safe logging

Do not log passwords, cookies, authorization headers, API keys, or full URLs containing sensitive query parameters:

```python name=safe_logging.py
import logging
from urllib.parse import urlsplit, urlunsplit

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(message)s",
)
logger = logging.getLogger("scraper")


def remove_query_parameters(url: str) -> str:
    scheme, host, path, _, _ = urlsplit(url)
    return urlunsplit((scheme, host, path, "", ""))


target_url = "https://example.com/search?token=secret&query=python"
logger.info("Requesting %s", remove_query_parameters(target_url))
```

## Key Recommendations

1. Prefer an official API when one is available.
2. Obtain permission before collecting protected or sensitive content.
3. Respect `robots.txt`, terms of service, and published rate limits.
4. Use Beautiful Soup for static HTML.
5. Use Scrapy for structured multi-page crawling.
6. Use Playwright only when browser rendering is genuinely required.
7. Apply HTTPS, URL allow-lists, timeouts, bounded retries, and rate limits.
8. Store secrets in environment variables or a secrets manager.
9. Validate extracted data before storing or using it.
10. Add tests and monitoring because website structures frequently change.
