
# Topic 3: FastAPI Fundamentals

## 1. Install FastAPI

```bash name=install.sh
python -m venv .venv
source .venv/bin/activate
pip install "fastapi[standard]"
```

On Windows PowerShell, activate the environment with:

```powershell name=install.ps1
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install "fastapi[standard]"
```

A virtual environment keeps project dependencies isolated.

---

## 2. Create the Application

```python name=main.py
from fastapi import FastAPI

app = FastAPI(title="Learning API")


@app.get("/")
def root() -> dict[str, str]:
    return {"message": "Welcome to FastAPI"}
```

`FastAPI()` creates the application. The decorator connects an HTTP method and URL to a function.

Run it with:

```bash name=run.sh
fastapi dev main.py
```

Open:

- API: `http://127.0.0.1:8000`
- Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc: `http://127.0.0.1:8000/redoc`

## 3. Path Parameters

```python name=path_parameters.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/products/{product_id}")
def get_product(product_id: int) -> dict[str, object]:
    return {"id": product_id, "name": "Keyboard"}
```

In `/products/10`, FastAPI validates and converts `10` to an integer.

## 4. Query Parameters

```python name=query_parameters.py
from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/products")
def list_products(
    search: str | None = None,
    limit: int = Query(default=10, ge=1, le=100),
) -> dict[str, object]:
    return {"search": search, "limit": limit}
```

Call `/products?search=mouse&limit=5`. Validation prevents invalid or excessively large limits.

## 5. Request Body

```python name=request_body.py
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()


class ProductCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    price: float = Field(gt=0)


@app.post("/products", status_code=201)
def create_product(product: ProductCreate) -> ProductCreate:
    return product
```

Pydantic validates incoming JSON before the function runs.

Example request:

```json name=request.json
{
  "name": "Keyboard",
  "price": 50.0
}
```

## 6. Response Models

```python name=response_model.py
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class UserResponse(BaseModel):
    id: int
    username: str


@app.get("/users/{user_id}", response_model=UserResponse)
def get_user(user_id: int) -> dict[str, object]:
    return {
        "id": user_id,
        "username": "alice",
        "password_hash": "must-not-be-returned",
    }
```

The response model returns only `id` and `username`, preventing accidental exposure of sensitive fields.

## 7. Status Codes and Exceptions

```python name=exceptions.py
from fastapi import FastAPI, HTTPException, status

app = FastAPI()

products = {1: "Keyboard"}


@app.get("/products/{product_id}")
def get_product(product_id: int) -> dict[str, object]:
    if product_id not in products:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Product not found",
        )

    return {"id": product_id, "name": products[product_id]}
```

`HTTPException` stops processing and returns a controlled error response.

## 8. Dependency Injection

```python name=dependencies.py
from typing import Annotated

from fastapi import Depends, FastAPI, Header, HTTPException, status

app = FastAPI()


def require_api_key(
    x_api_key: Annotated[str | None, Header()] = None,
) -> str:
    if x_api_key != "learning-key":
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid credentials",
        )

    return x_api_key


@app.get("/protected")
def protected_route(
    _: Annotated[str, Depends(require_api_key)],
) -> dict[str, str]:
    return {"message": "Access granted"}
```

Dependencies provide reusable logic such as authentication and database sessions. Real keys must come from environment variables, not source code.

## 9. Organize Routes with `APIRouter`

```python name=routers/products.py
from fastapi import APIRouter

router = APIRouter(prefix="/products", tags=["Products"])


@router.get("")
def list_products() -> list[dict[str, object]]:
    return [{"id": 1, "name": "Keyboard"}]
```

```python name=main.py
from fastapi import FastAPI

from routers.products import router as products_router

app = FastAPI(title="Store API")
app.include_router(products_router)
```

`APIRouter` separates endpoints into manageable modules.

## 10. Application Configuration

```python name=config.py
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    app_name: str = "Store API"
    debug: bool = False

    model_config = SettingsConfigDict(
        env_file=".env",
        extra="ignore",
    )


settings = Settings()
```

```python name=main.py
from fastapi import FastAPI

from config import settings

app = FastAPI(
    title=settings.app_name,
    debug=settings.debug,
)
```

Configuration comes from environment variables. Keep debugging disabled in production to avoid exposing internal information.
