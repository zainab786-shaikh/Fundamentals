
# Topic 7: FastAPI Application Architecture

A layered architecture keeps API routes, validation, business logic, and database access separate.

## 2. Configuration Layer

```python name=app/config.py
from functools import lru_cache

from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    app_name: str = "User API"
    database_url: str
    debug: bool = False

    model_config = SettingsConfigDict(
        env_file=".env",
        extra="ignore",
    )


@lru_cache
def get_settings() -> Settings:
    return Settings()
```

Configuration comes from environment variables. `lru_cache` creates the settings object only once.

```text name=.env.example
APP_NAME=User API
DATABASE_URL=sqlite:///./app.db
DEBUG=false
```

Do not commit the real `.env` file if it contains secrets.

## 3. Database Layer

```python name=app/database.py
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, sessionmaker

from app.config import get_settings

settings = get_settings()

engine = create_engine(
    settings.database_url,
    connect_args=(
        {"check_same_thread": False}
        if settings.database_url.startswith("sqlite")
        else {}
    ),
    pool_pre_ping=True,
)

SessionLocal = sessionmaker(
    bind=engine,
    autoflush=False,
    expire_on_commit=False,
)


class Base(DeclarativeBase):
    pass
```

The engine manages connections. `SessionLocal` creates database sessions.

## 4. Database Session Dependency

```python name=app/dependencies.py
from collections.abc import Generator
from typing import Annotated

from fastapi import Depends
from sqlalchemy.orm import Session

from app.database import SessionLocal


def get_db() -> Generator[Session, None, None]:
    with SessionLocal() as session:
        yield session


DatabaseSession = Annotated[Session, Depends(get_db)]
```

FastAPI opens one session for each request and closes it afterward.

## 5. ORM Model Layer

```python name=app/models/user.py
from sqlalchemy import Boolean, String
from sqlalchemy.orm import Mapped, mapped_column

from app.database import Base


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100), nullable=False)
    email: Mapped[str] = mapped_column(
        String(255),
        unique=True,
        index=True,
        nullable=False,
    )
    is_active: Mapped[bool] = mapped_column(
        Boolean,
        default=True,
        nullable=False,
    )
```

ORM models describe database tables and relationships. They should not be returned directly from API endpoints.

## 6. Schema Layer

```python name=app/schemas/user.py
from pydantic import BaseModel, ConfigDict, EmailStr, Field


class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    email: EmailStr


class UserResponse(BaseModel):
    id: int
    name: str
    email: EmailStr
    is_active: bool

    model_config = ConfigDict(from_attributes=True)
```

Schemas validate requests and control responses. `UserResponse` exposes only approved fields.

## 7. Repository Layer

```python name=app/repositories/user_repository.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.user import User


class UserRepository:
    def get_by_id(self, db: Session, user_id: int) -> User | None:
        return db.get(User, user_id)

    def get_by_email(self, db: Session, email: str) -> User | None:
        statement = select(User).where(User.email == email)
        return db.scalar(statement)

    def create(self, db: Session, name: str, email: str) -> User:
        user = User(name=name, email=email)

        db.add(user)
        db.commit()
        db.refresh(user)

        return user
```

The repository contains database queries. SQLAlchemy creates parameterized SQL, helping prevent SQL injection.

## 8. Service Layer

```python name=app/services/user_service.py
from fastapi import HTTPException, status
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.models.user import User
from app.repositories.user_repository import UserRepository
from app.schemas.user import UserCreate


class UserService:
    def __init__(self, repository: UserRepository) -> None:
        self.repository = repository

    def create_user(self, db: Session, data: UserCreate) -> User:
        existing_user = self.repository.get_by_email(db, data.email)

        if existing_user is not None:
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Email is already registered",
            )

        try:
            return self.repository.create(
                db=db,
                name=data.name,
                email=data.email,
            )
        except IntegrityError:
            db.rollback()
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Email is already registered",
            ) from None
```

The service contains business rules. The database constraint remains the final protection against duplicate emails.

## 9. Router Layer

```python name=app/routers/users.py
from fastapi import APIRouter, HTTPException, status

from app.dependencies import DatabaseSession
from app.repositories.user_repository import UserRepository
from app.schemas.user import UserCreate, UserResponse
from app.services.user_service import UserService

router = APIRouter(prefix="/users", tags=["Users"])

user_service = UserService(UserRepository())


@router.post(
    "",
    response_model=UserResponse,
    status_code=status.HTTP_201_CREATED,
)
def create_user(
    data: UserCreate,
    db: DatabaseSession,
) -> UserResponse:
    user = user_service.create_user(db, data)
    return UserResponse.model_validate(user)


@router.get("/{user_id}", response_model=UserResponse)
def get_user(
    user_id: int,
    db: DatabaseSession,
) -> UserResponse:
    user = user_service.repository.get_by_id(db, user_id)

    if user is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="User not found",
        )

    return UserResponse.model_validate(user)
```

Routers handle HTTP details and delegate business logic to services.

## 10. Application Entry Point

```python name=app/main.py
from fastapi import FastAPI

from app.config import get_settings
from app.routers.users import router as users_router

settings = get_settings()

app = FastAPI(
    title=settings.app_name,
    debug=settings.debug,
)

app.include_router(users_router)


@app.get("/health", tags=["System"])
def health_check() -> dict[str, str]:
    return {"status": "healthy"}
```

The entry point creates the application and registers routers. Debug mode should remain disabled in production.

## Layer Responsibilities

| Layer | Responsibility |
|---|---|
| Router | HTTP requests and responses |
| Schema | Input validation and response shape |
| Service | Business rules |
| Repository | Database queries |
| Model | Database table definition |
| Dependency | Shared request resources |
| Configuration | Environment-based settings |

Request flow:

```text name=request-flow.txt
HTTP request
    → Router
    → Schema validation
    → Service
    → Repository
    → Database
```
