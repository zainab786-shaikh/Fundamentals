**FastAPI is a strong choice for API-focused development** because it is lightweight, supports async programming, provides automatic OpenAPI documentation, and integrates well with type hints. Django is preferable when you need a complete framework with a built-in admin panel, authentication, and ORM.

## FastAPI Web API Learning Roadmap

### 1. Python Foundations
- Variables and data types
- Lists, dictionaries, tuples, and sets
- Conditions and loops
- Functions and type hints
- Classes and object-oriented programming
- Modules, packages, and virtual environments
- Exceptions and error handling
- Async/await fundamentals

### 2. Web and REST Fundamentals
- Client-server architecture
- HTTP methods: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`
- URLs, routes, headers, and request bodies
- HTTP status codes
- JSON serialization
- RESTful resource design
- Authentication versus authorization
- API versioning and pagination

### 3. FastAPI Fundamentals
- Project setup and application structure
- Creating routes and path operations
- Path and query parameters
- Request bodies
- Pydantic validation models
- Response models
- Status codes and exceptions
- Dependency injection
- Automatic Swagger and ReDoc documentation

### 4. Database Fundamentals
- Relational database concepts
- Tables, rows, columns, and data types
- Primary and foreign keys
- One-to-one, one-to-many, and many-to-many relationships
- SQL CRUD operations
- Joins and indexes
- Transactions
- Constraints and normalization

**Recommended database:** Start with SQLite for learning, then move to PostgreSQL for real applications.

### 5. SQLAlchemy ORM
- Engine and database connections
- Declarative ORM models
- Database sessions
- Creating, reading, updating, and deleting records
- Model relationships
- Filtering, sorting, and pagination
- Transactions and rollback
- Eager versus lazy loading
- Avoiding N+1 query problems
- Async SQLAlchemy

### 6. Database Migrations with Alembic
- Why migrations are required
- Initializing Alembic
- Creating migration revisions
- Applying and reverting migrations
- Reviewing generated migration files
- Safely changing existing schemas
- Migration practices for production

### 7. Application Architecture
Use a clear, layered structure:

- **Routers:** HTTP endpoints
- **Schemas:** Request and response validation
- **Models:** ORM database entities
- **Services:** Business logic
- **Repositories:** Database access
- **Dependencies:** Shared FastAPI dependencies
- **Configuration:** Environment-based settings

Keep API, business, and database logic separated.

### 8. CRUD API Development
Build APIs for:
- Creating records
- Getting one or multiple records
- Updating records with `PUT` and `PATCH`
- Deleting records
- Filtering and searching
- Sorting and pagination
- Consistent error responses
- Duplicate-record handling

### 9. Authentication and Security
- Secure password hashing with Argon2 or bcrypt
- User registration and login
- OAuth2 concepts
- Access and refresh tokens
- Role- and permission-based authorization
- Deny-by-default access control
- Input validation
- Rate limiting and account lockout
- CORS configuration
- HTTPS and security headers
- Environment variables and secret management
- Preventing SQL injection, XSS, and information leakage

Never store plain-text passwords or hardcode secrets.

### 10. Testing
- Unit and integration testing with `pytest`
- FastAPI test clients
- Testing routes and services
- Test database setup
- Dependency overrides
- Authentication and authorization tests
- Validation and error-case tests
- Mocking external services
- Code coverage

### 11. Logging and Error Handling
- Centralized exception handling
- Structured logging
- Request or correlation IDs
- Safe production error messages
- Database rollback on failure
- Health and readiness endpoints
- Audit logging for sensitive operations

### 12. Advanced FastAPI
- Async database operations
- Background tasks
- File uploads with size and type validation
- WebSockets
- Middleware
- Caching
- API versioning
- OpenAPI customization
- External API integration with timeouts and retries

### 13. Deployment
- Running FastAPI with an ASGI server
- Environment-specific configuration
- Docker and Docker Compose
- PostgreSQL containers
- CI/CD pipelines
- Automated tests and dependency scanning
- HTTPS through a reverse proxy or cloud service
- Database migration during deployment
- Monitoring, backups, and rollback planning

## Suggested Practice Projects

1. **Task Management API**
   - Users, tasks, categories, and status
   - CRUD, validation, filtering, and pagination

2. **Blog API**
   - Users, posts, comments, and tags
   - Relationships, authentication, and permissions

3. **E-commerce API**
   - Products, carts, orders, and inventory
   - Transactions, role-based access, and testing

## Recommended Learning Stack

- **Language:** Python
- **Framework:** FastAPI
- **Validation:** Pydantic
- **ORM:** SQLAlchemy
- **Migrations:** Alembic
- **Database:** PostgreSQL
- **Testing:** pytest
- **Development tools:** VS Code, Git, Docker
- **API testing:** FastAPI Swagger UI or an API client

Follow this order: **Python → HTTP/REST → FastAPI → SQL → SQLAlchemy → Alembic → Authentication → Testing → Docker and deployment**.
