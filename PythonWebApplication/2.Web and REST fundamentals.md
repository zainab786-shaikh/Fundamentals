## 1. Client–Server Architecture

```python name=client_request.py
import requests

response = requests.get("https://api.example.com/users", timeout=10)

print(response.status_code)
print(response.json())
```

The client sends an HTTP request to a server. The server processes it and returns a response. A timeout prevents indefinite waiting.

---

## 2. HTTP Methods

```python name=http_methods.py
import requests

base_url = "https://api.example.com/users"

users = requests.get(base_url, timeout=10)
created = requests.post(
    base_url,
    json={"name": "Alice"},
    timeout=10,
)
updated = requests.put(
    f"{base_url}/1",
    json={"name": "Alice Smith"},
    timeout=10,
)
deleted = requests.delete(f"{base_url}/1", timeout=10)
```

- `GET`: Read data
- `POST`: Create data
- `PUT`: Replace data
- `PATCH`: Partially update data
- `DELETE`: Remove data

## 3. URLs and Routes

```python name=routes.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/users")
def get_users() -> list[dict[str, object]]:
    return [{"id": 1, "name": "Alice"}]


@app.get("/users/{user_id}")
def get_user(user_id: int) -> dict[str, object]:
    return {"id": user_id, "name": "Alice"}
```

`/users` identifies a collection. `/users/{user_id}` identifies one user.

## 4. Query Parameters

```python name=query_parameters.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/users")
def get_users(limit: int = 10) -> dict[str, int]:
    return {"limit": limit}
```

A request such as `/users?limit=5` passes `5` as the `limit` query parameter.

## 5. Request Body

```python name=request_body.py
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()


class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    age: int = Field(ge=18, le=120)


@app.post("/users", status_code=201)
def create_user(user: UserCreate) -> UserCreate:
    return user
```

The request body contains JSON data. Pydantic validates its type, length, and allowed range.

## 6. Request Headers

```python name=request_headers.py
from typing import Annotated

from fastapi import FastAPI, Header

app = FastAPI()


@app.get("/profile")
def get_profile(
    authorization: Annotated[str | None, Header()] = None,
) -> dict[str, bool]:
    return {"authorization_provided": authorization is not None}
```

Headers carry metadata such as authentication credentials. Never return or log authorization tokens.

## 7. HTTP Status Codes

```python name=status_codes.py
from fastapi import FastAPI, HTTPException, status

app = FastAPI()


@app.get("/users/{user_id}")
def get_user(user_id: int) -> dict[str, object]:
    if user_id != 1:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="User not found",
        )

    return {"id": 1, "name": "Alice"}
```

Common codes:

- `200`: Successful request
- `201`: Resource created
- `204`: Successful response without content
- `400`: Invalid request
- `401`: Authentication required
- `403`: Permission denied
- `404`: Resource not found
- `422`: Validation failed
- `500`: Internal server error

## 9. RESTful Resource Design

```python name=rest_resources.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/users")
def list_users() -> list[dict[str, object]]:
    return []


@app.post("/users", status_code=201)
def create_user() -> dict[str, object]:
    return {"id": 1}


@app.get("/users/{user_id}")
def get_user(user_id: int) -> dict[str, int]:
    return {"id": user_id}
```

Use nouns such as `/users`, not actions such as `/getUsers`. The HTTP method describes the action.

## 10. Authentication and Authorization

```python name=authorization.py
from fastapi import Depends, FastAPI, HTTPException, status

app = FastAPI()


def get_current_role() -> str:
    return "user"


@app.delete("/users/{user_id}")
def delete_user(
    user_id: int,
    role: str = Depends(get_current_role),
) -> dict[str, str]:
    if role != "admin":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Permission denied",
        )

    return {"message": f"User {user_id} deleted"}
```

Authentication verifies identity. Authorization checks permissions. Access should be denied unless the required permission is present.

## 11. Pagination

```python name=pagination.py
from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/users")
def get_users(
    page: int = Query(default=1, ge=1),
    page_size: int = Query(default=10, ge=1, le=100),
) -> dict[str, int]:
    offset = (page - 1) * page_size

    return {
        "page": page,
        "page_size": page_size,
        "offset": offset,
    }
```

Pagination returns data in smaller groups. Limiting `page_size` protects the server from oversized requests.
