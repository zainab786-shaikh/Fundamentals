
# Topic 8: CRUD API Development

CRUD means:

- **Create** a record
- **Read** one or more records
- **Update** a record
- **Delete** a record

This topic continues with the layered structure from Topic 7.

## 1. Request and Response Schemas

```python name=app/schemas/user.py
from pydantic import BaseModel, ConfigDict, EmailStr, Field


class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    email: EmailStr


class UserUpdate(BaseModel):
    name: str | None = Field(default=None, min_length=2, max_length=100)
    email: EmailStr | None = None
    is_active: bool | None = None


class UserResponse(BaseModel):
    id: int
    name: str
    email: EmailStr
    is_active: bool

    model_config = ConfigDict(from_attributes=True)


class UserListResponse(BaseModel):
    items: list[UserResponse]
    total: int
    page: int
    page_size: int
```

Separate schemas validate creation, partial updates, and responses. Optional fields allow `PATCH` to update only supplied values.

## 2. Repository: Create a User

```python name=app/repositories/user_repository.py
from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.models.user import User


class UserRepository:
    def create(self, db: Session, name: str, email: str) -> User:
        user = User(name=name, email=email)

        db.add(user)
        db.flush()
        db.refresh(user)

        return user
```

`flush()` sends the insert to the database without committing. The service controls the transaction.

## 4. Repository: List Users

```python name=app/repositories/user_repository.py
from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.models.user import User


class UserRepository:
    def list(
        self,
        db: Session,
        page: int,
        page_size: int,
        search: str | None = None,
    ) -> tuple[list[User], int]:
        query = select(User)
        count_query = select(func.count()).select_from(User)

        if search:
            search_value = f"%{search}%"
            query = query.where(User.name.ilike(search_value))
            count_query = count_query.where(User.name.ilike(search_value))

        query = (
            query
            .order_by(User.id)
            .offset((page - 1) * page_size)
            .limit(page_size)
        )

        users = list(db.scalars(query).all())
        total = db.scalar(count_query) or 0

        return users, total
```

This query supports searching, sorting, and pagination. SQLAlchemy safely parameterizes the search value.

## 6. Repository: Update a User

```python name=app/repositories/user_repository.py
from sqlalchemy.orm import Session

from app.models.user import User


class UserRepository:
    def update(
        self,
        db: Session,
        user: User,
        changes: dict[str, object],
    ) -> User:
        allowed_fields = {"name", "email", "is_active"}

        for field, value in changes.items():
            if field in allowed_fields:
                setattr(user, field, value)

        db.flush()
        db.refresh(user)

        return user
```

The allow-list prevents unexpected fields such as `id` from being modified.

## 8. Service: Create a User

```python name=app/services/user_service.py
from fastapi import HTTPException, status
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.models.user import User
from app.repositories.user_repository import UserRepository
from app.schemas.user import UserCreate


class UserService:
    def __init__(self, repository: UserRepository) -> None:
        self.repository = repository

    def create_user(self, db: Session, data: UserCreate) -> User:
        if self.repository.get_by_email(db, data.email):
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Email is already registered",
            )

        try:
            user = self.repository.create(db, data.name, data.email)
            db.commit()
            db.refresh(user)
            return user
        except IntegrityError:
            db.rollback()
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Email is already registered",
            ) from None
```

The service checks duplicates and controls the transaction. The unique database constraint handles concurrent duplicate requests.

## 9. Service: Read a User

## 10. Service: Update a User

```python name=app/services/user_service.py
from fastapi import HTTPException, status
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.models.user import User
from app.schemas.user import UserUpdate


class UserService:
    def update_user(
        self,
        db: Session,
        user_id: int,
        data: UserUpdate,
    ) -> User:
        user = self.get_user(db, user_id)
        changes = data.model_dump(exclude_unset=True)

        if not changes:
            return user

        if "email" in changes:
            existing = self.repository.get_by_email(db, str(changes["email"]))

            if existing is not None and existing.id != user_id:
                raise HTTPException(
                    status_code=status.HTTP_409_CONFLICT,
                    detail="Email is already registered",
                )

        try:
            updated_user = self.repository.update(db, user, changes)
            db.commit()
            db.refresh(updated_user)
            return updated_user
        except IntegrityError:
            db.rollback()
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Email is already registered",
            ) from None
```

`exclude_unset=True` updates only fields included in the request.

## 11. Service: Delete a User

```python name=app/services/user_service.py
from sqlalchemy.orm import Session


class UserService:
    def delete_user(self, db: Session, user_id: int) -> None:
        user = self.get_user(db, user_id)

        try:
            self.repository.delete(db, user)
            db.commit()
        except Exception:
            db.rollback()
            raise
```

The service rolls back the transaction if deletion fails.

## 12. Create Endpoint

```python name=app/routers/users.py
from fastapi import APIRouter, status

from app.dependencies import DatabaseSession
from app.repositories.user_repository import UserRepository
from app.schemas.user import UserCreate, UserResponse
from app.services.user_service import UserService

router = APIRouter(prefix="/users", tags=["Users"])
service = UserService(UserRepository())


@router.post(
    "",
    response_model=UserResponse,
    status_code=status.HTTP_201_CREATED,
)
def create_user(
    data: UserCreate,
    db: DatabaseSession,
) -> UserResponse:
    user = service.create_user(db, data)
    return UserResponse.model_validate(user)
```

`POST /users` creates a user and returns `201 Created`.

## 14. List and Search Endpoint

```python name=app/routers/users.py
from fastapi import Query

from app.schemas.user import UserListResponse, UserResponse


@router.get("", response_model=UserListResponse)
def list_users(
    db: DatabaseSession,
    page: int = Query(default=1, ge=1),
    page_size: int = Query(default=10, ge=1, le=100),
    search: str | None = Query(default=None, min_length=1, max_length=100),
) -> UserListResponse:
    users, total = service.repository.list(
        db=db,
        page=page,
        page_size=page_size,
        search=search,
    )

    return UserListResponse(
        items=[UserResponse.model_validate(user) for user in users],
        total=total,
        page=page,
        page_size=page_size,
    )
```

Example: `GET /users?page=1&page_size=10&search=alice`. The maximum page size protects database performance.

`PATCH` modifies only the supplied fields.

## CRUD Endpoint Summary

| Method | Endpoint | Purpose |
|---|---|---|
| `POST` | `/users` | Create a user |
| `GET` | `/users` | List and search users |
| `GET` | `/users/{user_id}` | Read one user |
| `PATCH` | `/users/{user_id}` | Partially update a user |
| `DELETE` | `/users/{user_id}` | Delete a user |

All modifying endpoints should require proper authentication and authorization in a production application.
