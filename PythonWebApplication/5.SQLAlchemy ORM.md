
# Topic 5: SQLAlchemy ORM

SQLAlchemy ORM lets you work with database tables using Python classes. We will use modern **SQLAlchemy 2.x-style** code and SQLite for learning.

## 1. Install SQLAlchemy

```bash name=install.sh
pip install sqlalchemy
```

For PostgreSQL later:

```bash name=install-postgresql.sh
pip install "psycopg[binary]"
```

SQLAlchemy provides the ORM. Psycopg is the PostgreSQL database driver.

---

## 2. Create the Database Engine

```python name=database.py
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

DATABASE_URL = "sqlite:///./app.db"

engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False},
)

SessionLocal = sessionmaker(
    bind=engine,
    autoflush=False,
    expire_on_commit=False,
)
```

- `engine` manages database connections.
- `SessionLocal` creates database sessions.
- `check_same_thread` is needed for SQLite with FastAPI.

---

## 3. Create the Base Model

```python name=models/base.py
from sqlalchemy.orm import DeclarativeBase


class Base(DeclarativeBase):
    pass
```

Every ORM model inherits from `Base`. It stores SQLAlchemy model metadata.

---

## 4. Create a User Model

```python name=models/user.py
from sqlalchemy import Boolean, String
from sqlalchemy.orm import Mapped, mapped_column

from models.base import Base


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    email: Mapped[str] = mapped_column(String(255), unique=True, index=True)
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)
```

The `User` class represents the `users` table. `Mapped` provides modern type-safe column declarations.

## 6. Open and Close a Session

```python name=session_example.py
from database import SessionLocal

with SessionLocal() as session:
    print("Database session opened")
```

A session tracks database operations. The `with` block closes it automatically.

---

## 7. Create a Record

```python name=create_user.py
from sqlalchemy.exc import IntegrityError

from database import SessionLocal
from models.user import User

with SessionLocal() as session:
    user = User(
        name="Alice",
        email="alice@example.com",
    )

    try:
        session.add(user)
        session.commit()
        session.refresh(user)
        print(user.id)
    except IntegrityError:
        session.rollback()
        print("A user with this email already exists.")
```

- `add()` stages the record.
- `commit()` saves it.
- `refresh()` loads generated values such as `id`.
- `rollback()` restores the session after failure.

## 8. Read One Record

```python name=get_user.py
from database import SessionLocal
from models.user import User

with SessionLocal() as session:
    user = session.get(User, 1)

    if user is None:
        print("User not found")
    else:
        print(user.name)
```

`session.get()` finds a record by its primary key.

---

## 9. Filter Records

```python name=find_user.py
from sqlalchemy import select

from database import SessionLocal
from models.user import User

with SessionLocal() as session:
    statement = select(User).where(
        User.email == "alice@example.com",
    )
    user = session.scalar(statement)

    print(user.name if user else "User not found")
```

`select()` creates a parameterized query. SQLAlchemy safely passes values separately from SQL.

## 10. Read Multiple Records

```python name=list_users.py
from sqlalchemy import select

from database import SessionLocal
from models.user import User

with SessionLocal() as session:
    statement = (
        select(User)
        .where(User.is_active.is_(True))
        .order_by(User.name)
        .limit(10)
    )

    users = session.scalars(statement).all()

    for user in users:
        print(user.name)
```

This query filters active users, sorts by name, and limits the result to 10 records.

## 11. Update a Record

```python name=update_user.py
from database import SessionLocal
from models.user import User

with SessionLocal() as session:
    user = session.get(User, 1)

    if user is not None:
        user.name = "Alice Smith"
        session.commit()
        session.refresh(user)
        print(user.name)
```

Change the model property and call `commit()`. SQLAlchemy generates the corresponding `UPDATE` statement.

## 13. One-to-Many Relationship

```python name=models/post.py
from __future__ import annotations

from sqlalchemy import ForeignKey, String
from sqlalchemy.orm import Mapped, mapped_column, relationship

from models.base import Base


class Post(Base):
    __tablename__ = "posts"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200))
    author_id: Mapped[int] = mapped_column(
        ForeignKey("users.id", ondelete="CASCADE"),
        index=True,
    )

    author: Mapped["User"] = relationship(back_populates="posts")
```

Add the matching relationship to `User`:

```python name=models/user.py
from __future__ import annotations

from sqlalchemy import Boolean, String
from sqlalchemy.orm import Mapped, mapped_column, relationship

from models.base import Base


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    email: Mapped[str] = mapped_column(String(255), unique=True, index=True)
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)

    posts: Mapped[list["Post"]] = relationship(
        back_populates="author",
        cascade="all, delete-orphan",
    )
```

One user can have many posts. `back_populates` connects both sides of the relationship.

## 14. Load Related Records Efficiently

```python name=get_user_with_posts.py
from sqlalchemy import select
from sqlalchemy.orm import selectinload

from database import SessionLocal
from models.user import User

with SessionLocal() as session:
    statement = (
        select(User)
        .options(selectinload(User.posts))
        .where(User.id == 1)
    )

    user = session.scalar(statement)

    if user:
        for post in user.posts:
            print(post.title)
```

`selectinload()` loads related posts efficiently and helps avoid the N+1 query problem.

## 15. Pagination

```python name=paginate_users.py
from sqlalchemy import select

from database import SessionLocal
from models.user import User

page = 1
page_size = 10
offset = (page - 1) * page_size

with SessionLocal() as session:
    statement = (
        select(User)
        .order_by(User.id)
        .offset(offset)
        .limit(page_size)
    )

    users = session.scalars(statement).all()
```

`offset()` skips previous records, while `limit()` controls the page size.

## 16. FastAPI Database Dependency

```python name=dependencies.py
from collections.abc import Generator

from sqlalchemy.orm import Session

from database import SessionLocal


def get_db() -> Generator[Session, None, None]:
    with SessionLocal() as session:
        yield session
```

Use the dependency in an endpoint:

```python name=routers/users.py
from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session

from dependencies import get_db
from models.user import User

router = APIRouter(prefix="/users", tags=["Users"])

DatabaseSession = Annotated[Session, Depends(get_db)]


@router.get("/{user_id}")
def get_user(user_id: int, db: DatabaseSession) -> dict[str, object]:
    user = db.get(User, user_id)

    if user is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="User not found",
        )

    return {
        "id": user.id,
        "name": user.name,
        "email": user.email,
    }
```

FastAPI creates a session for the request and closes it afterward.
