
## Topic 1: Python Foundations

### 1. Variables and Data Types

```python name=variables.py
name: str = "Alice"
age: int = 25
height: float = 1.68
is_active: bool = True

print(name, age, height, is_active)
```

Variables store values. Type hints such as `str` and `int` describe the expected data type.

### 2. Collections

```python name=collections.py
languages: list[str] = ["Python", "JavaScript"]
user: dict[str, str] = {"name": "Alice", "role": "admin"}
coordinates: tuple[int, int] = (10, 20)
unique_roles: set[str] = {"admin", "editor", "admin"}

print(languages[0])
print(user["role"])
print(coordinates)
print(unique_roles)
```

- `list`: Ordered and changeable  
- `dict`: Key-value pairs  
- `tuple`: Ordered and immutable  
- `set`: Unique values  

### 3. Conditions

```python name=conditions.py
age = 20

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

`if` and `else` run code based on a condition.

### 4. Loops

```python name=loops.py
users = ["Alice", "Bob", "Charlie"]

for user in users:
    print(user)
```

A `for` loop processes every item in a collection.

### 5. Functions and Type Hints

```python name=functions.py
def add(number1: int, number2: int) -> int:
    return number1 + number2


result = add(5, 3)
print(result)
```

Functions organize reusable logic. Type hints describe parameters and return values.

### 6. Classes

```python name=classes.py
class User:
    def __init__(self, name: str) -> None:
        self.name = name

    def greet(self) -> str:
        return f"Hello, {self.name}"


user = User("Alice")
print(user.greet())
```

A class defines an object’s data and behavior. ORM database models are commonly represented as classes.

### 7. Exception Handling

```python name=exceptions.py
try:
    number = int("invalid")
except ValueError:
    print("The value must be a valid number.")
```

`try` and `except` handle errors without crashing the application.

### 8. Async/Await

```python name=async_example.py
import asyncio


async def fetch_data() -> str:
    await asyncio.sleep(1)
    return "Data received"


async def main() -> None:
    result = await fetch_data()
    print(result)


asyncio.run(main())
```

`async` and `await` allow other work to continue while waiting for operations such as database or network requests.
