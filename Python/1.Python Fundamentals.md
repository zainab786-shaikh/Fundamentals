# 1. Python Fundamentals: Examples

Python has no built-in "array" type for general use, so the examples below iterate a `list`. Each subtopic has one simple example.

## 1.1 Syntax, Variables, and Types
```python
name = "Ada"          # str
age = 30              # int
height = 1.65         # float
is_admin = True       # bool
nothing = None        # NoneType

print(type(age))      # <class 'int'>
age = "thirty"        # dynamic typing: names can be rebound
```

## 1.2 Operators and Expressions
```python
print(7 / 2)          # 3.5   true division
print(7 // 2)         # 3     floor division
print(7 % 2)          # 1     modulo
print(2 ** 3)         # 8     power
print(3 < 5 and 5 < 9)  # True
print(3 < 5 < 9)        # True (chained comparison)
print("a" in "cat")     # True (membership)
if (n := len("hello")) > 3:   # walrus operator
    print(n)
```

## 1.3 Control Flow

**`if` / `elif` / `else`**
```python
score = 82
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

**`match`** (Python 3.10+)
```python
command = "stop"
match command:
    case "start":
        print("Starting")
    case "stop" | "halt":
        print("Stopping")
    case _:
        print("Unknown")
```

**Ways to iterate a list**
```python
nums = [10, 20, 30]

# 1. for loop over items
for n in nums:
    print(n)

# 2. for loop with index (range + len)
for i in range(len(nums)):
    print(i, nums[i])

# 3. enumerate (preferred when you need the index)
for i, n in enumerate(nums):
    print(i, n)

# 4. while loop with manual index
i = 0
while i < len(nums):
    print(nums[i])
    i += 1

# 5. zip (iterate two lists together)
for a, b in zip(nums, ["x", "y", "z"]):
    print(a, b)

# 6. reversed
for n in reversed(nums):
    print(n)

# 7. comprehension (builds a new list)
doubled = [n * 2 for n in nums]

# 8. map with a function
doubled = list(map(lambda n: n * 2, nums))

# 9. iterator protocol (what `for` does internally)
it = iter(nums)
print(next(it))   # 10
```

**Loop controls**
```python
for n in [1, 2, 3, 4]:
    if n == 2:
        continue      # skip this iteration
    if n == 4:
        break         # exit the loop
    print(n)
else:
    print("runs only if no break")  # not printed here
```

## 1.4 Functions

**Arguments**
```python
def greet(name, greeting="Hello"):    # default value
    return f"{greeting}, {name}"

print(greet("Ada"))
print(greet(greeting="Hi", name="Bob"))  # keyword arguments
```

**`*args` and `**kwargs`**
```python
def demo(*args, **kwargs):
    print(args)      # (1, 2)
    print(kwargs)    # {'x': 3}

demo(1, 2, x=3)
```

**Lambda**
```python
square = lambda x: x * x
print(sorted(["bb", "a", "ccc"], key=lambda s: len(s)))
```

**Scope**
```python
x = "global"
def show():
    x = "local"
    print(x)         # local
show()
print(x)             # global
```

**Closure**
```python
def make_multiplier(factor):
    def multiply(n):
        return n * factor
    return multiply

double = make_multiplier(2)
print(double(5))     # 10
```

## 1.5 Modules and Packages
```python
# Importing
import math
from math import sqrt
import math as m
from math import *        # avoid: pollutes namespace

print(math.pi, sqrt(16), m.floor(2.7))

# Your own module: utils.py
# def add(a, b): return a + b
# import utils; utils.add(1, 2)

# Package layout
# mypkg/
#   __init__.py
#   tools.py
# from mypkg.tools import something

if __name__ == "__main__":    # runs only when executed directly
    print("script mode")
```

## 1.6 Input/Output and String Formatting
```python
name = input("Name: ")        # always returns str
print("Hello", name, sep=", ", end="!\n")

pi = 3.14159
print(f"{pi:.2f}")                  # f-string: 3.14
print("{} is {}".format("Ada", 30)) # str.format
print("%s is %d" % ("Ada", 30))     # old style, avoid in new code
print(f"{1234567:,}")               # 1,234,567
print(f"{'left':<10}|{'right':>10}")
```
