# 8. Concurrency: Types and Simple Examples

## 1. Threading

**a) Basic thread**
```python
import threading

def work(name):
    print(f"Hello from {name}")

t = threading.Thread(target=work, args=("T1",))
t.start()
t.join()
```

**b) Multiple threads**
```python
import threading

threads = [threading.Thread(target=work, args=(f"T{i}",)) for i in range(3)]
for t in threads: t.start()
for t in threads: t.join()
```

**c) `ThreadPoolExecutor` (preferred)**
```python
from concurrent.futures import ThreadPoolExecutor

def square(x): return x * x

with ThreadPoolExecutor(max_workers=4) as ex:
    print(list(ex.map(square, range(5))))  # [0, 1, 4, 9, 16]
```

**d) `submit` and `as_completed`**
```python
from concurrent.futures import ThreadPoolExecutor, as_completed

with ThreadPoolExecutor() as ex:
    futures = [ex.submit(square, i) for i in range(5)]
    for f in as_completed(futures):
        print(f.result())
```

**e) Lock (avoid race conditions)**
```python
import threading

counter = 0
lock = threading.Lock()

def inc():
    global counter
    for _ in range(100_000):
        with lock:
            counter += 1

ts = [threading.Thread(target=inc) for _ in range(4)]
for t in ts: t.start()
for t in ts: t.join()
print(counter)  # 400000
```

**f) `RLock` (re-entrant)**
```python
rlock = threading.RLock()
with rlock:
    with rlock:  # same thread can re-acquire
        print("ok")
```

**g) `Event` (signaling)**
```python
import threading, time

ready = threading.Event()

def waiter():
    ready.wait()
    print("go!")

threading.Thread(target=waiter).start()
time.sleep(1)
ready.set()
```

**h) `Semaphore` (limit concurrency)**
```python
sem = threading.Semaphore(2)

def limited(i):
    with sem:
        print(f"running {i}")
```

**i) `queue.Queue` (producer/consumer)**
```python
import queue, threading

q = queue.Queue()

def consumer():
    while (item := q.get()) is not None:
        print("got", item)

t = threading.Thread(target=consumer)
t.start()
for i in range(3): q.put(i)
q.put(None)  # sentinel
t.join()
```

**j) Daemon thread**
```python
t = threading.Thread(target=lambda: None, daemon=True)  # killed when main exits
```

**k) Thread-local data**
```python
local = threading.local()
local.value = 42  # each thread sees its own value
```

## 2. Multiprocessing

**a) Basic process**
```python
from multiprocessing import Process

def work(n):
    print(f"process {n}")

if __name__ == "__main__":   # required on Windows/macOS
    p = Process(target=work, args=(1,))
    p.start()
    p.join()
```

**b) `Pool`**
```python
from multiprocessing import Pool

def square(x): return x * x

if __name__ == "__main__":
    with Pool(4) as pool:
        print(pool.map(square, range(5)))
```

**c) `ProcessPoolExecutor` (preferred)**
```python
from concurrent.futures import ProcessPoolExecutor

if __name__ == "__main__":
    with ProcessPoolExecutor() as ex:
        print(list(ex.map(square, range(5))))
```

**d) `Queue` (inter-process communication)**
```python
from multiprocessing import Process, Queue

def producer(q): q.put("hello")

if __name__ == "__main__":
    q = Queue()
    p = Process(target=producer, args=(q,))
    p.start()
    print(q.get())
    p.join()
```

**e) `Pipe`**
```python
from multiprocessing import Process, Pipe

def child(conn):
    conn.send("hi")
    conn.close()

if __name__ == "__main__":
    parent, c = Pipe()
    Process(target=child, args=(c,)).start()
    print(parent.recv())
```

**f) Shared memory value (`Value` / `Array`)**
```python
from multiprocessing import Process, Value

def inc(v):
    with v.get_lock():
        v.value += 1

if __name__ == "__main__":
    v = Value("i", 0)
    ps = [Process(target=inc, args=(v,)) for _ in range(4)]
    for p in ps: p.start()
    for p in ps: p.join()
    print(v.value)  # 4
```

**g) `Manager` (shared dict/list)**
```python
from multiprocessing import Manager

if __name__ == "__main__":
    with Manager() as m:
        d = m.dict()
        d["a"] = 1
```

**h) `shared_memory` (zero-copy, 3.8+)**
```python
from multiprocessing import shared_memory

shm = shared_memory.SharedMemory(create=True, size=10)
shm.buf[0] = 7
shm.close(); shm.unlink()
```

## 3. `asyncio`

**a) Basic coroutine**
```python
import asyncio

async def hello():
    await asyncio.sleep(1)
    return "done"

print(asyncio.run(hello()))
```

**b) Run concurrently with `gather`**
```python
async def job(n):
    await asyncio.sleep(1)
    return n

async def main():
    print(await asyncio.gather(job(1), job(2), job(3)))  # ~1s total

asyncio.run(main())
```

**c) `TaskGroup` (3.11+, structured concurrency)**
```python
async def main():
    async with asyncio.TaskGroup() as tg:
        t1 = tg.create_task(job(1))
        t2 = tg.create_task(job(2))
    print(t1.result(), t2.result())
```

**d) `create_task`**
```python
async def main():
    task = asyncio.create_task(job(1))
    print("doing other work")
    print(await task)
```

**e) Timeout**
```python
async def main():
    try:
        async with asyncio.timeout(1):   # 3.11+
            await asyncio.sleep(5)
    except TimeoutError:
        print("timed out")
```

**f) `wait_for` (older style)**
```python
await asyncio.wait_for(asyncio.sleep(5), timeout=1)
```

**g) `as_completed`**
```python
async def main():
    for coro in asyncio.as_completed([job(2), job(1)]):
        print(await coro)
```

**h) `Semaphore` (limit concurrency)**
```python
sem = asyncio.Semaphore(2)

async def limited(i):
    async with sem:
        await asyncio.sleep(1)
```

**i) `asyncio.Queue`**
```python
async def producer(q):
    for i in range(3): await q.put(i)
    await q.put(None)

async def consumer(q):
    while (item := await q.get()) is not None:
        print(item)

async def main():
    q = asyncio.Queue()
    await asyncio.gather(producer(q), consumer(q))
```

**j) Run blocking code off the loop**
```python
import time

async def main():
    await asyncio.to_thread(time.sleep, 2)   # 3.9+
```

**k) Async iterator / generator**
```python
async def ticker(n):
    for i in range(n):
        yield i
        await asyncio.sleep(0.1)

async def main():
    async for x in ticker(3):
        print(x)
```

**l) Cancellation**
```python
async def main():
    t = asyncio.create_task(asyncio.sleep(10))
    t.cancel()
    try:
        await t
    except asyncio.CancelledError:
        print("cancelled")
```

## 4. The GIL (Global Interpreter Lock)

The GIL lets only one thread execute Python bytecode at a time (in standard CPython). This affects CPU-bound code but not I/O-bound code.

**a) CPU-bound: threads don't speed up**
```python
import time
from concurrent.futures import ThreadPoolExecutor

def cpu(n): return sum(i * i for i in range(n))

start = time.perf_counter()
with ThreadPoolExecutor(4) as ex:
    list(ex.map(cpu, [5_000_000] * 4))
print(f"threads: {time.perf_counter() - start:.2f}s")  # ~ same as serial
```

**b) CPU-bound: processes bypass the GIL**
```python
from concurrent.futures import ProcessPoolExecutor

if __name__ == "__main__":
    start = time.perf_counter()
    with ProcessPoolExecutor(4) as ex:
        list(ex.map(cpu, [5_000_000] * 4))
    print(f"processes: {time.perf_counter() - start:.2f}s")  # faster on multi-core
```

**c) I/O-bound: threads work well (GIL released while waiting)**
```python
def io(_): time.sleep(1)

with ThreadPoolExecutor(10) as ex:
    list(ex.map(io, range(10)))  # ~1s, not 10s
```

**d) Check the GIL status (3.13+)**
```python
import sys
print(sys._is_gil_enabled())
```

**e) Free-threaded build (3.13+, experimental)**
Python 3.13+ offers a no-GIL build (`python3.13t`), per PEP 703. Threads can then run in parallel for CPU-bound work, though library compatibility varies.

**f) Native extensions release the GIL**
Libraries like NumPy release the GIL during heavy computation, so threads can parallelize those operations.

## Quick Chooser

| Workload | Best choice |
|---|---|
| Many network/file waits (high scale) | `asyncio` |
| I/O-bound with blocking libraries | `threading` / `ThreadPoolExecutor` |
| CPU-bound | `multiprocessing` / `ProcessPoolExecutor` |
| CPU-bound with NumPy-style libs | Threads may suffice |

**Security note:** Never unpickle data from untrusted sources. `multiprocessing` queues, pipes, and managers use `pickle` internally, so only connect them to trusted processes.
