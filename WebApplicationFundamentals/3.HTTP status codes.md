
# Topic 3: HTTP Status Codes and Error Responses

HTTP status codes tell the client whether a request succeeded or failed.

## 1. Status Code Categories

| Range | Meaning | Example |
|---|---|---|
| `1xx` | Informational | Request is still processing |
| `2xx` | Success | Request completed successfully |
| `3xx` | Redirection | Client must use another location or cached data |
| `4xx` | Client error | Request or credentials are invalid |
| `5xx` | Server error | Server failed to process a valid request |

---

## 2. `200 OK`

Used when a request succeeds and returns data.

```python name=app/main.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/{user_id}", status_code=200)
def get_user(user_id: int) -> dict[str, object]:
    return {"id": user_id, "name": "Alice"}
```

Commonly used for successful `GET`, `PUT`, and `PATCH` requests.

---

## 3. `201 Created`

Used when a new resource is created.

```python name=app/main.py
from fastapi import FastAPI, Response, status
from pydantic import BaseModel

app = FastAPI()


class UserCreate(BaseModel):
    name: str


@app.post("/users", status_code=status.HTTP_201_CREATED)
def create_user(data: UserCreate, response: Response) -> dict[str, object]:
    user_id = 1
    response.headers["Location"] = f"/users/{user_id}"

    return {"id": user_id, "name": data.name}
```

The `Location` header identifies the newly created resource.

---

## 4. `204 No Content`

Used when the request succeeds but no response body is required.

```python name=app/main.py
from fastapi import Response, status


@app.delete(
    "/users/{user_id}",
    status_code=status.HTTP_204_NO_CONTENT,
)
def delete_user(user_id: int) -> Response:
    return Response(status_code=status.HTTP_204_NO_CONTENT)
```

A `204` response must not contain a response body.

---

## 5. `304 Not Modified`

Tells the client to use its cached copy.

```python name=app/main.py
from typing import Annotated

from fastapi import Header, Response


@app.get("/settings")
def get_settings(
    if_none_match: Annotated[str | None, Header()] = None,
) -> Response:
    etag = '"settings-v1"'

    if if_none_match == etag:
        return Response(status_code=304)

    return Response(
        content='{"theme":"dark"}',
        media_type="application/json",
        headers={"ETag": etag},
    )
```

`304` reduces unnecessary data transfer and does not include a response body.

---

## 6. `400 Bad Request`

Used when the request is invalid beyond normal field validation.

```python name=app/main.py
from fastapi import HTTPException, Query, status


@app.get("/reports")
def get_report(
    start_year: int = Query(ge=2000),
    end_year: int = Query(ge=2000),
) -> dict[str, int]:
    if start_year > end_year:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="start_year must not be greater than end_year",
        )

    return {"start_year": start_year, "end_year": end_year}
```

The client must correct the request before retrying.

---

## 7. `401 Unauthorized`

Used when authentication is missing or invalid.

```python name=app/main.py
from typing import Annotated

from fastapi import Header, HTTPException, status


@app.get("/profile")
def get_profile(
    authorization: Annotated[str | None, Header()] = None,
) -> dict[str, str]:
    if authorization is None:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Authentication required",
            headers={"WWW-Authenticate": "Bearer"},
        )

    return {"name": "Alice"}
```

Despite its name, `401` means the client is **not authenticated**.

---

## 8. `403 Forbidden`

Used when the user is authenticated but lacks permission.

```python name=app/main.py
from fastapi import HTTPException, status


@app.delete("/users/{user_id}")
def delete_user(user_id: int, current_role: str = "user") -> dict[str, str]:
    if current_role != "admin":
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Insufficient permission",
        )

    return {"message": f"User {user_id} deleted"}
```

Authorization should be deny-by-default: permit access only when the required permission is present.

---

## 9. `404 Not Found`

Used when the requested resource does not exist.

```python name=app/main.py
from fastapi import HTTPException, status

users = {1: "Alice"}


@app.get("/users/{user_id}")
def get_user(user_id: int) -> dict[str, object]:
    if user_id not in users:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="User not found",
        )

    return {"id": user_id, "name": users[user_id]}
```

A `404` may also be used to hide the existence of a sensitive resource from unauthorized users.

---

## 10. `409 Conflict`

Used when the request conflicts with the current resource state.

```python name=app/main.py
from fastapi import HTTPException, status

registered_emails = {"alice@example.com"}


@app.post("/users")
def create_user(email: str) -> dict[str, str]:
    if email in registered_emails:
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="Email is already registered",
        )

    registered_emails.add(email)
    return {"email": email}
```

Common conflicts include duplicate emails and invalid state transitions.

---

## 11. `413 Content Too Large`

Used when an uploaded body or file exceeds the allowed size.

```python name=app/main.py
from fastapi import HTTPException, UploadFile, status

MAX_SIZE = 2 * 1024 * 1024


@app.post("/uploads")
async def upload_file(file: UploadFile) -> dict[str, str]:
    content = await file.read(MAX_SIZE + 1)

    if len(content) > MAX_SIZE:
        raise HTTPException(
            status_code=status.HTTP_413_CONTENT_TOO_LARGE,
            detail="File exceeds the 2 MB limit",
        )

    return {"message": "File accepted"}
```

Size limits protect memory, storage, and service availability.

---

## 12. `415 Unsupported Media Type`

Used when the request body format is not supported.

```python name=app/main.py
from typing import Annotated

from fastapi import Header, HTTPException, status


@app.post("/documents")
def create_document(
    content_type: Annotated[str | None, Header()] = None,
) -> dict[str, str]:
    if content_type != "application/json":
        raise HTTPException(
            status_code=status.HTTP_415_UNSUPPORTED_MEDIA_TYPE,
            detail="Content-Type must be application/json",
        )

    return {"message": "Document accepted"}
```

The client should send a supported `Content-Type`.

---

## 13. `422 Unprocessable Content`

FastAPI returns `422` when request validation fails.

```python name=app/main.py
from pydantic import BaseModel, Field


class ProductCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    price: float = Field(gt=0)


@app.post("/products", status_code=201)
def create_product(data: ProductCreate) -> ProductCreate:
    return data
```

A negative price or missing name produces `422` automatically.

---

## 14. `429 Too Many Requests`

Used when the client exceeds a rate limit.

```python name=app/main.py
from fastapi import HTTPException, status


def check_rate_limit(request_count: int) -> None:
    if request_count > 100:
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail="Rate limit exceeded",
            headers={"Retry-After": "60"},
        )
```

`Retry-After` tells the client when it may try again.

---

## 15. `500 Internal Server Error`

Used for unexpected server failures.

```python name=app/main.py
import logging

from fastapi import Request
from fastapi.responses import JSONResponse

logger = logging.getLogger(__name__)


@app.exception_handler(Exception)
async def handle_unexpected_error(
    request: Request,
    exception: Exception,
) -> JSONResponse:
    logger.exception("Unexpected API failure")

    return JSONResponse(
        status_code=500,
        content={
            "error": {
                "code": "internal_error",
                "message": "Internal server error",
            }
        },
    )
```

Log the internal exception securely, but never expose stack traces, SQL, credentials, or implementation details to clients.

---

## 16. `503 Service Unavailable`

Used when the API is temporarily unable to serve requests.

```python name=app/main.py
from fastapi import HTTPException, status


@app.get("/health/ready")
def readiness(database_available: bool = True) -> dict[str, str]:
    if not database_available:
        raise HTTPException(
            status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
            detail="Service temporarily unavailable",
        )

    return {"status": "ready"}
```

This commonly indicates unavailable dependencies or temporary maintenance.

## 17. Consistent Error Format

```python name=app/schemas/error.py
from pydantic import BaseModel


class ErrorDetail(BaseModel):
    code: str
    message: str
    request_id: str | None = None


class ErrorResponse(BaseModel):
    error: ErrorDetail
```

Example response:

```json name=error-response.json
{
  "error": {
    "code": "user_not_found",
    "message": "User not found",
    "request_id": "a9a93eb5-62eb-427f-b935-d68faad8fc7d"
  }
}
```

- `code`: Stable value for client applications
- `message`: Safe explanation for users
- `request_id`: Helps trace the failure in server logs

## Common Status-Code Summary

| Code | Meaning | Typical use |
|---:|---|---|
| `200` | OK | Successful read or update |
| `201` | Created | Resource created |
| `204` | No Content | Successful delete |
| `304` | Not Modified | Cached response remains valid |
| `400` | Bad Request | Invalid request logic |
| `401` | Unauthorized | Missing or invalid authentication |
| `403` | Forbidden | Insufficient permission |
| `404` | Not Found | Resource does not exist |
| `409` | Conflict | Duplicate or state conflict |
| `413` | Content Too Large | Request exceeds size limit |
| `415` | Unsupported Media Type | Unsupported body format |
| `422` | Unprocessable Content | Request validation failed |
| `429` | Too Many Requests | Rate limit exceeded |
| `500` | Internal Server Error | Unexpected server failure |
| `503` | Service Unavailable | Temporary dependency or service failure |
