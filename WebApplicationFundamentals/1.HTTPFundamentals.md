
# Topic 1: HTTP Fundamentals

HTTP is the communication protocol used by clients and web APIs.

## 1. Client–Server Architecture

- **Client:** Sends a request, such as a browser or mobile application.
- **Server:** Processes the request and returns a response.
- **API:** Defines how the client communicates with the server.

```text name=http-flow.txt
Client → HTTP Request → FastAPI Server
Client ← HTTP Response ← FastAPI Server
```

---

## 2. HTTP Request

A request normally contains:

- HTTP method
- URL
- Headers
- Optional body

```http name=request.http
POST /users HTTP/1.1
Host: api.example.com
Content-Type: application/json

{
  "name": "Alice"
}
```

This request asks the server to create a user.

---

## 3. HTTP Response

A response normally contains:

- Status code
- Headers
- Optional body

```http name=response.http
HTTP/1.1 201 Created
Content-Type: application/json

{
  "id": 1,
  "name": "Alice"
}
```

`201 Created` indicates that the resource was created successfully.

---

## 4. HTTP and HTTPS

- **HTTP:** Sends information without transport encryption.
- **HTTPS:** Encrypts traffic using TLS.
- Production APIs should use HTTPS only.

```text name=urls.txt
HTTP:  http://api.example.com
HTTPS: https://api.example.com
```

HTTPS protects passwords, tokens, and other data while they travel across the network.

---

## 5. URL Structure

```text name=url-structure.txt
https://api.example.com:443/users/10?include=posts
└─scheme─┘ └────host────┘ port └─path─┘ └query string─┘
```

- **Scheme:** `https`
- **Host:** `api.example.com`
- **Port:** `443`
- **Path:** `/users/10`
- **Query string:** `include=posts`

---

## 6. Path Parameters

Path parameters identify a specific resource.

```python name=app/main.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/{user_id}")
def get_user(user_id: int) -> dict[str, int]:
    return {"user_id": user_id}
```

A request to `/users/10` sets `user_id` to `10`.

---

## 7. Query Parameters

Query parameters filter or control the returned data.

```python name=app/main.py
from fastapi import FastAPI, Query

app = FastAPI()


@app.get("/users")
def list_users(
    page: int = Query(default=1, ge=1),
    page_size: int = Query(default=10, ge=1, le=100),
) -> dict[str, int]:
    return {"page": page, "page_size": page_size}
```

Example:

```text name=query-example.txt
GET /users?page=2&page_size=20
```

The limits prevent invalid or excessively large requests.

---

## 8. Request Headers

Headers provide metadata about a request.

```http name=headers.http
GET /profile HTTP/1.1
Accept: application/json
Authorization: Bearer access-token
```

- `Accept`: Requested response format
- `Authorization`: Authentication credentials

Tokens must never be included in URLs or application logs.

---

## 9. Request Body

The body contains data sent to the API.

```python name=app/main.py
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()


class UserCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)


@app.post("/users", status_code=201)
def create_user(data: UserCreate) -> dict[str, object]:
    return {"id": 1, "name": data.name}
```

FastAPI validates the body before running the endpoint.

---

## 10. JSON Serialization

APIs commonly exchange data using JSON.

```python name=app/main.py
@app.get("/products/1")
def get_product() -> dict[str, object]:
    return {
        "id": 1,
        "name": "Keyboard",
        "price": 50.0,
        "available": True,
    }
```

FastAPI converts the Python dictionary into JSON automatically.

---

## 11. Content Type

`Content-Type` describes the format of the body.

```http name=content-type.http
Content-Type: application/json
```

Common content types:

- `application/json`: JSON data
- `multipart/form-data`: File upload or form
- `text/plain`: Plain text
- `application/pdf`: PDF document

The server should reject unsupported content types.

---

## 12. Content Negotiation

The client uses `Accept` to request a response format.

```http name=content-negotiation.http
GET /users/1 HTTP/1.1
Accept: application/json
```

The server replies with:

```http name=content-negotiation-response.http
HTTP/1.1 200 OK
Content-Type: application/json
```

Most FastAPI APIs use JSON as their standard response format.

---

## 13. HTTP Versions

- **HTTP/1.1:** Common and widely supported
- **HTTP/2:** Supports multiple requests over one connection
- **HTTP/3:** Uses QUIC for improved connection performance

The application usually does not manage these directly. The web server, reverse proxy, or cloud platform handles them.

## Key Point

Every API interaction follows this pattern:

```text name=request-cycle.txt
Method + URL + Headers + Optional Body
                  ↓
             API processing
                  ↓
Status Code + Headers + Optional Body
```
