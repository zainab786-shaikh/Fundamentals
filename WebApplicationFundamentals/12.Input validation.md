
# Topic 12: Input Validation

**Input validation** checks all untrusted data before the application processes or stores it. Validate path parameters, query strings, headers, bodies, files, and URLs.

## 1. Path Parameter Validation

```python name=app/routers/users.py
from fastapi import APIRouter, Path

router = APIRouter(prefix="/users")


@router.get("/{user_id}")
def get_user(
    user_id: int = Path(ge=1),
) -> dict[str, int]:
    return {"id": user_id}
```

`user_id` must be an integer greater than or equal to `1`. FastAPI returns `422` for invalid values.

## 2. Query Parameter Validation

```python name=app/routers/users.py
from fastapi import Query


@router.get("")
def list_users(
    page: int = Query(default=1, ge=1),
    page_size: int = Query(default=20, ge=1, le=100),
    search: str | None = Query(
        default=None,
        min_length=2,
        max_length=100,
    ),
) -> dict[str, object]:
    return {
        "page": page,
        "page_size": page_size,
        "search": search,
    }
```

Length and range limits prevent malformed and excessively expensive requests.

## 3. Allow-List Validation

Use an allow-list when only specific values are acceptable.

```python name=app/routers/products.py
from typing import Literal

from fastapi import APIRouter

router = APIRouter(prefix="/products")


@router.get("")
def list_products(
    sort_by: Literal["name", "price", "created_at"] = "name",
    order: Literal["asc", "desc"] = "asc",
) -> dict[str, str]:
    return {"sort_by": sort_by, "order": order}
```

The client cannot supply arbitrary database column names. This reduces invalid queries and injection risks.

## 4. Header Validation

```python name=app/routers/integrations.py
from typing import Annotated

from fastapi import APIRouter, Header
from pydantic import StringConstraints

router = APIRouter(prefix="/integrations")

RequestId = Annotated[
    str,
    StringConstraints(
        pattern=r"^[A-Za-z0-9-]{1,64}$",
    ),
]


@router.get("/status")
def get_status(
    x_request_id: Annotated[RequestId, Header()],
) -> dict[str, str]:
    return {"request_id": x_request_id}
```

The request ID accepts only letters, numbers, and hyphens, with a maximum length of 64 characters.

## 6. Reject Unexpected Fields

```python name=app/schemas/user.py
from pydantic import BaseModel, ConfigDict, EmailStr, Field


class UserCreate(BaseModel):
    model_config = ConfigDict(extra="forbid")

    name: str = Field(min_length=2, max_length=100)
    email: EmailStr
    password: str = Field(min_length=12, max_length=128)
```

A request containing unexpected fields such as `role` or `is_admin` is rejected. This helps prevent mass-assignment vulnerabilities.

## 7. Normalize Input

```python name=app/schemas/user.py
from pydantic import BaseModel, EmailStr, field_validator


class UserCreate(BaseModel):
    name: str
    email: EmailStr

    @field_validator("name")
    @classmethod
    def normalize_name(cls, value: str) -> str:
        normalized = value.strip()

        if not normalized:
            raise ValueError("Name must not be empty")

        return normalized

    @field_validator("email", mode="before")
    @classmethod
    def normalize_email(cls, value: object) -> object:
        if isinstance(value, str):
            return value.strip().lower()

        return value
```

Normalization produces consistent values. Validation should happen after normalization where appropriate.

Do not modify passwords by trimming or changing case.

## 8. Cross-Field Validation

```python name=app/schemas/report.py
from datetime import date

from pydantic import BaseModel, model_validator


class ReportRequest(BaseModel):
    start_date: date
    end_date: date

    @model_validator(mode="after")
    def validate_date_range(self) -> "ReportRequest":
        if self.start_date > self.end_date:
            raise ValueError(
                "start_date must not be after end_date"
            )

        return self
```

Cross-field validation checks rules involving more than one field.

## 9. Safe Database Queries

```python name=app/repositories/user_repository.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.user import User


def find_user_by_email(
    db: Session,
    email: str,
) -> User | None:
    statement = select(User).where(User.email == email)
    return db.scalar(statement)
```

SQLAlchemy passes the email as a query parameter. Never construct SQL by concatenating untrusted input.

## 11. File-Upload Validation

```python name=app/routers/uploads.py
from pathlib import Path
from uuid import uuid4

from fastapi import APIRouter, HTTPException, UploadFile, status

router = APIRouter(prefix="/uploads")

UPLOAD_DIRECTORY = Path("uploads").resolve()
UPLOAD_DIRECTORY.mkdir(parents=True, exist_ok=True)

MAX_SIZE = 2 * 1024 * 1024
ALLOWED_SIGNATURES = {
    b"\x89PNG\r\n\x1a\n": ".png",
    b"\xff\xd8\xff": ".jpg",
}


@router.post("", status_code=status.HTTP_201_CREATED)
async def upload_image(file: UploadFile) -> dict[str, str]:
    content = await file.read(MAX_SIZE + 1)

    if len(content) > MAX_SIZE:
        raise HTTPException(413, "File exceeds the 2 MB limit")

    extension = next(
        (
            suffix
            for signature, suffix in ALLOWED_SIGNATURES.items()
            if content.startswith(signature)
        ),
        None,
    )

    if extension is None:
        raise HTTPException(415, "Unsupported file type")

    safe_name = f"{uuid4()}{extension}"
    destination = UPLOAD_DIRECTORY / safe_name
    destination.write_bytes(content)

    return {"file_name": safe_name}
```

Important protections:

- Limit file size.
- Check the actual file signature.
- Generate the filename on the server.
- Do not trust the original filename or declared content type.
- Scan files for malware in production.

## 12. Prevent Path Traversal

```python name=app/services/files.py
from pathlib import Path

BASE_DIRECTORY = Path("documents").resolve()


def resolve_safe_path(file_name: str) -> Path:
    if Path(file_name).name != file_name:
        raise ValueError("Invalid file name")

    candidate = (BASE_DIRECTORY / file_name).resolve()

    if not candidate.is_relative_to(BASE_DIRECTORY):
        raise ValueError("Path is outside the allowed directory")

    return candidate
```

This rejects inputs such as:

```text name=invalid-paths.txt
../../etc/passwd
../secret.txt
folder/private.txt
```

Prefer server-generated file identifiers instead of client-supplied paths.

## 13. Strict URL Validation

```python name=app/security/urls.py
from urllib.parse import urlsplit

ALLOWED_HOSTS = {"api.example.com"}
ALLOWED_PATH_PREFIX = "/public/"
ALLOWED_PORTS = {None, 443}


def validate_external_url(value: str) -> str:
    parsed = urlsplit(value)

    if parsed.scheme != "https":
        raise ValueError("Only HTTPS URLs are allowed")

    if (
        parsed.username is not None
        or parsed.password is not None
    ):
        raise ValueError("URL credentials are not allowed")

    if parsed.hostname not in ALLOWED_HOSTS:
        raise ValueError("Host is not allowed")

    if parsed.port not in ALLOWED_PORTS:
        raise ValueError("Port is not allowed")

    if not parsed.path.startswith(ALLOWED_PATH_PREFIX):
        raise ValueError("Path is not allowed")

    if parsed.fragment:
        raise ValueError("URL fragments are not allowed")

    return value
```

Validate the exact scheme, host, port, and path. This helps prevent server-side request forgery.

For highly sensitive applications, also protect against DNS rebinding and redirects to unapproved hosts.

## 14. Command-Line Input

Avoid running shell commands with untrusted strings.

Unsafe:

```python name=app/services/unsafe_command.py
import os


def unsafe_lookup(host: str) -> None:
    os.system(f"nslookup {host}")
```

Safer:

```python name=app/services/safe_command.py
import ipaddress
import subprocess


def lookup(address: str) -> str:
    validated_address = str(ipaddress.ip_address(address))

    result = subprocess.run(
        ["nslookup", validated_address],
        shell=False,
        check=True,
        capture_output=True,
        text=True,
        timeout=5,
    )

    return result.stdout
```

Pass arguments separately and keep `shell=False`. Strictly validate input before executing external programs.

## 15. Validation Error Response

FastAPI normally returns `422` for validation failures.

```json name=validation-error.json
{
  "detail": [
    {
      "type": "greater_than_equal",
      "loc": ["query", "page"],
      "msg": "Input should be greater than or equal to 1"
    }
  ]
}
```

Return enough information to correct the request, but do not expose secrets, SQL, stack traces, or internal implementation details.

## Key Security Rules

- Treat all client input as untrusted.
- Apply type, length, range, and format limits.
- Prefer allow-lists over block-lists.
- Reject unexpected fields.
- Use parameterized database queries.
- Generate uploaded filenames on the server.
- Validate file signatures and sizes.
- Prevent path traversal with resolved-path checks.
- Validate external URLs by scheme, host, port, and path.
- Avoid shell execution; pass validated arguments separately.
- Authorization is still required after input validation.
