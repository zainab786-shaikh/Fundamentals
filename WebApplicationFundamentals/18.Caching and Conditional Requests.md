
# Topic 20: API Performance and Reliability

Performance makes an API fast and efficient. Reliability keeps it available when databases, networks, or external services fail.

## 1. Synchronous vs Asynchronous Endpoints

Use `async def` for non-blocking I/O operations with async-compatible libraries.

```python name=app/routers/products.py
import httpx
from fastapi import APIRouter

router = APIRouter(prefix="/products")


@router.get("/external")
async def get_external_products() -> dict[str, object]:
    async with httpx.AsyncClient(timeout=5.0) as client:
        response = await client.get(
            "https://api.example.com/products"
        )
        response.raise_for_status()
        return response.json()
```

Use regular `def` for blocking libraries. Do not call blocking functions directly inside `async def`.

## 2. Database Connection Pooling

A connection pool reuses database connections instead of creating one for every request.

```python name=app/database.py
import os

from sqlalchemy import create_engine

engine = create_engine(
    os.environ["DATABASE_URL"],
    pool_size=10,
    max_overflow=20,
    pool_timeout=30,
    pool_recycle=1_800,
    pool_pre_ping=True,
)
```

- `pool_size`: Persistent connections
- `max_overflow`: Temporary extra connections
- `pool_timeout`: Maximum wait for a connection
- `pool_pre_ping`: Detects disconnected connections

Configure pool sizes according to database capacity and application instance count.

## 3. Select Only Required Columns

Avoid retrieving unnecessary or sensitive fields.

```python name=app/repositories/users.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.user import User


def list_user_summaries(
    db: Session,
) -> list[tuple[int, str]]:
    statement = (
        select(User.id, User.display_name)
        .order_by(User.id)
        .limit(100)
    )

    return list(db.execute(statement).tuples().all())
```

Selecting fewer columns reduces database, memory, and network usage.

## 4. Prevent N+1 Queries

Load related records efficiently.

```python name=app/repositories/users.py
from sqlalchemy import select
from sqlalchemy.orm import Session, selectinload

from app.models.user import User


def list_users_with_posts(db: Session) -> list[User]:
    statement = (
        select(User)
        .options(selectinload(User.posts))
        .order_by(User.id)
        .limit(100)
    )

    return list(db.scalars(statement).all())
```

`selectinload()` retrieves related posts in batches instead of executing one query for every user.

## 5. Add Appropriate Indexes

Indexes improve filtering, joining, and sorting.

```python name=app/models/order.py
from datetime import datetime

from sqlalchemy import DateTime, ForeignKey, Index
from sqlalchemy.orm import Mapped, mapped_column

from app.database import Base


class Order(Base):
    __tablename__ = "orders"
    __table_args__ = (
        Index(
            "ix_orders_customer_created",
            "customer_id",
            "created_at",
        ),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    customer_id: Mapped[int] = mapped_column(
        ForeignKey("users.id"),
    )
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True),
    )
```

Add indexes based on actual query patterns. Too many indexes increase storage use and slow writes.

## 6. Limit Response Size

Every collection endpoint should use pagination.

```python name=app/routers/orders.py
from fastapi import APIRouter, Query

router = APIRouter(prefix="/orders")


@router.get("")
def list_orders(
    page: int = Query(default=1, ge=1),
    page_size: int = Query(default=20, ge=1, le=100),
) -> dict[str, object]:
    return {
        "items": [],
        "page": page,
        "page_size": page_size,
    }
```

A maximum page size prevents clients from requesting excessive data.

## 7. Response Compression

Compression reduces the size of larger responses.

```python name=app/main.py
from fastapi import FastAPI
from fastapi.middleware.gzip import GZipMiddleware

app = FastAPI()

    GZipMiddleware,
```

## 8. External Request Timeouts

Every outbound request should have a timeout.

```python name=app/services/payment_client.py
import httpx


async def get_payment_status(payment_id: str) -> dict[str, object]:
    timeout = httpx.Timeout(
        connect=2.0,
        read=5.0,
        write=5.0,
        pool=2.0,
    )

    async with httpx.AsyncClient(timeout=timeout) as client:
        response = await client.get(
            f"https://payments.example.com/api/payments/{payment_id}"
        )
        response.raise_for_status()
        return response.json()
```

Timeouts prevent a slow external service from holding application resources indefinitely.

The host must come from trusted configuration, not unrestricted user input.

## 9. Limited Retries with Backoff

Retry only temporary failures and safe operations.

```python name=app/services/retry.py
import asyncio

import httpx


async def get_with_retry(url: str) -> httpx.Response:
    allowed_url = "https://status.example.com/health"

    if url != allowed_url:
        raise ValueError("URL is not allowed")

    async with httpx.AsyncClient(timeout=5.0) as client:
        for attempt in range(3):
            try:
                response = await client.get(url)
                response.raise_for_status()
                return response
            except (
                httpx.ConnectError,
                httpx.TimeoutException,
            ):
                if attempt == 2:
                    raise

                await asyncio.sleep(2**attempt)

    raise RuntimeError("Request failed")
```

Exponential backoff waits longer between attempts. Do not retry validation failures or non-idempotent operations without protection.

## 10. Idempotency Keys

Idempotency prevents duplicate processing when a client retries a `POST` request.

```python name=app/routers/orders.py
from typing import Annotated

from fastapi import Header, HTTPException, status


@router.post("", status_code=status.HTTP_201_CREATED)
def create_order(
    idempotency_key: Annotated[
        str,
        Header(alias="Idempotency-Key", min_length=16, max_length=128),
    ],
) -> dict[str, object]:
    existing_result = None  # Look up the key in persistent storage.

    if existing_result is not None:
        return existing_result

    # Atomically store the key and create the order.
    return {"id": 1, "status": "created"}
```

Store the key and result atomically in a database or shared store. Associate it with the authenticated user and request payload.

## 11. Background Jobs

Move long-running tasks outside the request-response cycle.

```python name=app/routers/reports.py
from fastapi import APIRouter, BackgroundTasks, status

router = APIRouter(prefix="/reports")


def generate_report(report_id: int) -> None:
    # Generate the report.
    pass


@router.post("", status_code=status.HTTP_202_ACCEPTED)
def request_report(
    background_tasks: BackgroundTasks,
) -> dict[str, object]:
    report_id = 1
    background_tasks.add_task(generate_report, report_id)

    return {
        "id": report_id,
        "status": "accepted",
    }
```

FastAPI background tasks suit small, non-critical work. Use a durable job queue for important, long-running, or retryable tasks.

## 12. Health Endpoints

Use separate liveness and readiness checks.

```python name=app/routers/health.py
from fastapi import APIRouter, HTTPException, status
from sqlalchemy import text

from app.dependencies import DatabaseSession

router = APIRouter(prefix="/health", tags=["System"])


@router.get("/live")
def liveness() -> dict[str, str]:
    return {"status": "alive"}


@router.get("/ready")
def readiness(db: DatabaseSession) -> dict[str, str]:
    try:
        db.execute(text("SELECT 1"))
    except Exception:
        raise HTTPException(
            status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
            detail="Service unavailable",
        ) from None

    return {"status": "ready"}
```

- **Liveness:** Confirms that the process is running.
- **Readiness:** Confirms that the application can receive traffic.

Do not expose internal infrastructure details.

## 13. Circuit Breaker Concept

A circuit breaker temporarily stops calls to a repeatedly failing dependency.

```text name=circuit-breaker.txt
Closed    → Requests are allowed
Open      → Requests fail immediately
Half-open → A small number of test requests are allowed
```

This prevents repeated failures from consuming resources and gives the dependency time to recover.

Use a maintained library, API gateway, or service-mesh feature for production implementations.

## 14. Graceful Shutdown

Close shared resources when the application stops.

```python name=app/main.py
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

import httpx
from fastapi import FastAPI


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    app.state.http_client = httpx.AsyncClient(
        timeout=httpx.Timeout(5.0),
    )

    yield

    await app.state.http_client.aclose()


app = FastAPI(lifespan=lifespan)
```

Graceful shutdown allows in-progress requests to finish and safely closes connections.

## 15. Request Size Limits

Large request bodies can exhaust memory or storage.

```python name=app/routers/uploads.py
from fastapi import HTTPException, UploadFile

MAX_FILE_SIZE = 2 * 1024 * 1024


async def read_limited_file(file: UploadFile) -> bytes:
    content = await file.read(MAX_FILE_SIZE + 1)

    if len(content) > MAX_FILE_SIZE:
        raise HTTPException(
            status_code=413,
            detail="File exceeds the 2 MB limit",
        )

    return content
```

Also configure request-size limits at the reverse proxy or API gateway.

## 16. Measure Request Duration

```python name=app/middleware/timing.py
import logging
from time import perf_counter

from fastapi import Request, Response

logger = logging.getLogger(__name__)


async def timing_middleware(
    request: Request,
    call_next,
) -> Response:
    started_at = perf_counter()
    response = await call_next(request)
    duration_ms = (perf_counter() - started_at) * 1_000

    logger.info(
        "Request completed method=%s path=%s status=%s duration_ms=%.2f",
        request.method,
        request.url.path,
        response.status_code,
        duration_ms,
    )

    return response
```

Measure performance before optimizing. Never include secrets, tokens, or sensitive query values in logs.

## 17. Test Dependency Failure

```python name=tests/test_health.py
from unittest.mock import Mock

from fastapi.testclient import TestClient


def test_readiness_fails_when_database_is_unavailable(
    client: TestClient,
    db: Mock,
) -> None:
    db.execute.side_effect = RuntimeError("Database unavailable")

    response = client.get("/health/ready")

    assert response.status_code == 503
    assert response.json()["detail"] == "Service unavailable"
```

Test timeouts, retries, unavailable dependencies, pool exhaustion, and graceful shutdown behavior.

## Key Points

- Use async code only with async-compatible I/O libraries.
- Reuse database and HTTP connections.
- Paginate and limit response sizes.
- Optimize queries and avoid N+1 operations.
- Add timeouts to all external calls.
- Retry only temporary failures with limited backoff.
- Protect non-idempotent operations against duplicate execution.
- Move long-running work to background workers.
- Provide liveness and readiness endpoints.
- Monitor latency, error rates, and dependency availability.
