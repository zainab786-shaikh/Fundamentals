
# Topic 11: Authorization

**Authorization** determines what an authenticated user is permitted to do.

## 1. Authentication vs Authorization

```text name=authentication-vs-authorization.txt
Authentication → Confirms the user's identity
Authorization  → Checks the user's permissions
```

A valid login does not automatically grant access to every resource.

---

## 2. Deny by Default

Reject access unless it is explicitly permitted.

```python name=app/security/authorization.py
from fastapi import HTTPException, status


def require_permission(
    user_permissions: set[str],
    required_permission: str,
) -> None:
    if required_permission not in user_permissions:
        raise HTTPException(
            status_code=status.HTTP_403_FORBIDDEN,
            detail="Insufficient permission",
        )
```

This follows least privilege: users receive only the permissions they need.

---

## 3. Role-Based Access Control

RBAC assigns permissions through roles such as `user`, `editor`, and `admin`.

```python name=app/security/roles.py
from enum import StrEnum


class Role(StrEnum):
    USER = "user"
    EDITOR = "editor"
    ADMIN = "admin"
```

Use an enum to prevent invalid role names.

---

## 4. Require a Role

```python name=app/dependencies/roles.py
from collections.abc import Callable
from typing import Annotated

from fastapi import Depends, HTTPException, status

from app.dependencies.auth import get_current_user
from app.models.user import User
from app.security.roles import Role


def require_role(required_role: Role) -> Callable[..., User]:
    def dependency(
        user: Annotated[User, Depends(get_current_user)],
    ) -> User:
        if user.role != required_role:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail="Insufficient permission",
            )

        return user

    return dependency
```

The request is denied unless the authenticated user has the required role.

## 5. Protect an Admin Endpoint

```python name=app/routers/admin.py
from typing import Annotated

from fastapi import APIRouter, Depends

from app.dependencies.roles import require_role
from app.models.user import User
from app.security.roles import Role

router = APIRouter(prefix="/admin", tags=["Administration"])

AdminUser = Annotated[User, Depends(require_role(Role.ADMIN))]


@router.get("/reports")
def get_reports(_: AdminUser) -> dict[str, str]:
    return {"report": "Confidential administration report"}
```

Only an authenticated administrator can access this endpoint.

## 6. Permission-Based Access Control

Permissions provide finer control than broad roles.

```python name=app/security/permissions.py
from enum import StrEnum


class Permission(StrEnum):
    USERS_READ = "users:read"
    USERS_UPDATE = "users:update"
    USERS_DELETE = "users:delete"


ROLE_PERMISSIONS: dict[str, set[Permission]] = {
    "user": set(),
    "support": {Permission.USERS_READ},
    "admin": {
        Permission.USERS_READ,
        Permission.USERS_UPDATE,
        Permission.USERS_DELETE,
    },
}
```

Each role receives only the permissions required for its responsibilities.

## 7. Require a Permission

```python name=app/dependencies/permissions.py
from collections.abc import Callable
from typing import Annotated

from fastapi import Depends, HTTPException, status

from app.dependencies.auth import get_current_user
from app.models.user import User
from app.security.permissions import Permission, ROLE_PERMISSIONS


def require_permission(
    permission: Permission,
) -> Callable[..., User]:
    def dependency(
        user: Annotated[User, Depends(get_current_user)],
    ) -> User:
        permissions = ROLE_PERMISSIONS.get(user.role, set())

        if permission not in permissions:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail="Insufficient permission",
            )

        return user

    return dependency
```

Unknown roles receive no permissions because `set()` is the default.

## 8. Protect an Endpoint with a Permission

```python name=app/routers/users.py
from typing import Annotated

from fastapi import APIRouter, Depends

from app.dependencies.permissions import require_permission
from app.models.user import User
from app.security.permissions import Permission

router = APIRouter(prefix="/users", tags=["Users"])

UserReader = Annotated[
    User,
    Depends(require_permission(Permission.USERS_READ)),
]


@router.get("")
def list_users(_: UserReader) -> list[dict[str, object]]:
    return [{"id": 1, "name": "Alice"}]
```

The endpoint checks the exact permission instead of only checking a general role.

## 9. Resource Ownership

Users should normally access only resources they own.

```python name=app/services/document_service.py
from fastapi import HTTPException, status

from app.models.document import Document
from app.models.user import User


def authorize_document_access(
    document: Document | None,
    current_user: User,
) -> Document:
    if document is None or document.owner_id != current_user.id:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Document not found",
        )

    return document
```

Returning `404` prevents revealing whether another user’s private document exists.

## 10. Ownership or Explicit Permission

An administrator may access resources owned by other users.

```python name=app/services/document_service.py
from app.security.permissions import Permission, ROLE_PERMISSIONS


def authorize_document_access(
    document: Document | None,
    current_user: User,
) -> Document:
    if document is None:
        raise HTTPException(status_code=404, detail="Document not found")

    permissions = ROLE_PERMISSIONS.get(current_user.role, set())
    is_owner = document.owner_id == current_user.id
    can_read_all = Permission.USERS_READ in permissions

    if not is_owner and not can_read_all:
        raise HTTPException(status_code=404, detail="Document not found")

    return document
```

Access is granted only to the owner or a user with an explicit elevated permission.

## 11. Prevent Insecure Direct Object References

Never retrieve a private record by ID without checking ownership.

Unsafe approach:

```python name=app/routers/documents.py
@router.get("/documents/{document_id}")
def get_document(document_id: int, db: DatabaseSession):
    return db.get(Document, document_id)
```

Secure approach:

```python name=app/routers/documents.py
from sqlalchemy import select

from app.dependencies.auth import CurrentUser
from app.models.document import Document


@router.get("/documents/{document_id}")
def get_document(
    document_id: int,
    current_user: CurrentUser,
    db: DatabaseSession,
) -> Document:
    document = db.scalar(
        select(Document).where(
            Document.id == document_id,
            Document.owner_id == current_user.id,
        )
    )

    if document is None:
        raise HTTPException(status_code=404, detail="Document not found")

    return document
```

Including `owner_id` in the query prevents access to another user’s record.

## 12. Tenant Isolation

In multi-tenant applications, every query must include the authenticated tenant ID.

```python name=app/repositories/project_repository.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.project import Project


def get_project(
    db: Session,
    project_id: int,
    tenant_id: int,
) -> Project | None:
    return db.scalar(
        select(Project).where(
            Project.id == project_id,
            Project.tenant_id == tenant_id,
        )
    )
```

Never trust a tenant ID supplied only by the client. Obtain it from the validated identity or server-side session.

## 13. Prevent Mass Assignment

Do not permit users to modify security-sensitive fields.

```python name=app/schemas/user.py
from pydantic import BaseModel, Field


class ProfileUpdate(BaseModel):
    display_name: str | None = Field(
        default=None,
        min_length=2,
        max_length=100,
    )
    language: str | None = None
```

Fields such as `role`, `is_admin`, `tenant_id`, and `permissions` are deliberately excluded.

## 14. Administrative Role Changes

Role changes require a dedicated, strongly protected endpoint.

```python name=app/schemas/admin.py
from pydantic import BaseModel

from app.security.roles import Role


class RoleUpdate(BaseModel):
    role: Role
```

```python name=app/routers/admin.py
@router.patch("/users/{user_id}/role")
def change_user_role(
    user_id: int,
    data: RoleUpdate,
    admin: AdminUser,
) -> dict[str, object]:
    # Update the role and write an audit event.
    return {
        "user_id": user_id,
        "role": data.role,
        "changed_by": admin.id,
    }
```

Role changes should be audited because they alter security privileges.

## 15. `401` vs `403`

| Status | Use |
|---:|---|
| `401 Unauthorized` | Authentication is missing, invalid, or expired |
| `403 Forbidden` | Authentication is valid, but permission is insufficient |
| `404 Not Found` | Resource is absent or its existence should be hidden |

Use consistent responses without exposing sensitive authorization details.

## Key Security Rules

- Authenticate before authorizing.
- Deny access by default.
- Grant the minimum required permissions.
- Check permissions on every protected operation.
- Verify resource ownership, not only resource IDs.
- Include tenant IDs in multi-tenant database queries.
- Do not expose privileged fields in normal update schemas.
- Audit role and permission changes.
- Recheck authorization server-side; never trust frontend controls.
- Return safe, consistent errors.
