
# Topic 21: Secure File Uploads and Downloads

File endpoints must prevent oversized uploads, malicious content, path traversal, unauthorized access, and unsafe execution.

## 2. Basic File Upload

```python name=app/routers/files.py
from fastapi import APIRouter, UploadFile, status

router = APIRouter(prefix="/files", tags=["Files"])


@router.post("", status_code=status.HTTP_201_CREATED)
async def upload_file(file: UploadFile) -> dict[str, str | None]:
    return {
        "file_name": file.filename,
        "content_type": file.content_type,
    }
```

`UploadFile` avoids loading the complete file into memory immediately. The filename and content type are untrusted client input.

## 3. Limit File Size

Read the file in chunks instead of loading an unrestricted file into memory.

```python name=app/services/file_reader.py
from fastapi import HTTPException, UploadFile, status

MAX_FILE_SIZE = 2 * 1024 * 1024
CHUNK_SIZE = 64 * 1024


async def read_limited_file(file: UploadFile) -> bytes:
    content = bytearray()

    while chunk := await file.read(CHUNK_SIZE):
        content.extend(chunk)

        if len(content) > MAX_FILE_SIZE:
            raise HTTPException(
                status_code=status.HTTP_413_CONTENT_TOO_LARGE,
                detail="File exceeds the 2 MB limit",
            )

    return bytes(content)
```

Size limits protect memory, disk space, and service availability. Also enforce limits at the reverse proxy or API gateway.

## 4. Validate the Actual File Type

Do not trust only the filename extension or `Content-Type`.

```python name=app/security/file_types.py
ALLOWED_SIGNATURES: dict[bytes, tuple[str, str]] = {
    b"\x89PNG\r\n\x1a\n": ("image/png", ".png"),
    b"\xff\xd8\xff": ("image/jpeg", ".jpg"),
}


def detect_file_type(content: bytes) -> tuple[str, str]:
    for signature, file_type in ALLOWED_SIGNATURES.items():
        if content.startswith(signature):
            return file_type

    raise ValueError("Unsupported file type")
```

File signatures—also called magic bytes—provide stronger validation than extensions alone.

For production, use a maintained file-identification library and fully parse the expected format where possible.

## 5. Generate a Safe Filename

```python name=app/security/file_names.py
from uuid import uuid4


def generate_file_name(extension: str) -> str:
    allowed_extensions = {".png", ".jpg"}

    if extension not in allowed_extensions:
        raise ValueError("Extension is not allowed")

    return f"{uuid4()}{extension}"
```

Generate filenames on the server. Never use the original filename as a storage path.

## 6. Prevent Path Traversal

```python name=app/services/file_paths.py
from pathlib import Path

UPLOAD_DIRECTORY = Path("private_uploads").resolve()
UPLOAD_DIRECTORY.mkdir(parents=True, exist_ok=True)


def create_safe_path(file_name: str) -> Path:
    if Path(file_name).name != file_name:
        raise ValueError("Invalid file name")

    destination = (UPLOAD_DIRECTORY / file_name).resolve()

    if not destination.is_relative_to(UPLOAD_DIRECTORY):
        raise ValueError("Invalid file path")

    return destination
```

This prevents inputs such as `../../secret.txt` from escaping the allowed directory.

## 7. Complete Secure Upload Endpoint

```python name=app/routers/files.py
from fastapi import APIRouter, HTTPException, UploadFile, status

from app.security.file_names import generate_file_name
from app.security.file_types import detect_file_type
from app.services.file_paths import create_safe_path
from app.services.file_reader import read_limited_file

router = APIRouter(prefix="/files", tags=["Files"])


@router.post("", status_code=status.HTTP_201_CREATED)
async def upload_file(file: UploadFile) -> dict[str, str]:
    content = await read_limited_file(file)

    try:
        media_type, extension = detect_file_type(content)
        stored_name = generate_file_name(extension)
        destination = create_safe_path(stored_name)
    except ValueError as error:
        raise HTTPException(
            status_code=status.HTTP_415_UNSUPPORTED_MEDIA_TYPE,
            detail=str(error),
        ) from None

    destination.write_bytes(content)

    return {
        "file_id": stored_name,
        "media_type": media_type,
    }
```

The endpoint limits size, validates content, generates the filename, and uses a controlled directory.

For large files, stream directly to private storage rather than keeping the entire validated file in memory.

## 8. Store File Metadata

```python name=app/models/stored_file.py
from sqlalchemy import ForeignKey, String
from sqlalchemy.orm import Mapped, mapped_column

from app.database import Base


class StoredFile(Base):
    __tablename__ = "stored_files"

    id: Mapped[int] = mapped_column(primary_key=True)
    storage_key: Mapped[str] = mapped_column(
        String(255),
        unique=True,
        nullable=False,
    )
    original_name: Mapped[str] = mapped_column(
        String(255),
        nullable=False,
    )
    media_type: Mapped[str] = mapped_column(
        String(100),
        nullable=False,
    )
    owner_id: Mapped[int] = mapped_column(
        ForeignKey("users.id", ondelete="CASCADE"),
        index=True,
    )
```

Store ownership and metadata in the database. Keep the storage key separate from the original display name.

Do not expose internal storage paths to clients.

## 9. Sanitize the Display Filename

```python name=app/security/file_names.py
from pathlib import Path


def sanitize_display_name(original_name: str | None) -> str:
    if not original_name:
        return "upload"

    name = Path(original_name).name
    cleaned = "".join(
        character
        for character in name
        if character.isalnum() or character in {" ", ".", "-", "_"}
    ).strip()

    return cleaned[:100] or "upload"
```

The original name should be used only as display metadata, never as a trusted storage path.

## 10. Scan Files for Malware

```python name=app/services/malware_scanner.py
class MalwareDetectedError(Exception):
    pass


async def scan_file(content: bytes) -> None:
    # Send the file to an approved malware-scanning service.
    is_safe = True

    if not is_safe:
        raise MalwareDetectedError("Unsafe file detected")
```

In production:

1. Upload into a private quarantine area.
2. Scan the file.
3. Mark it safe only after scanning succeeds.
4. Prevent downloads while scanning is pending.

Never execute, import, or render uploaded files directly.

## 11. Authorize File Downloads

```python name=app/repositories/file_repository.py
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.stored_file import StoredFile


def get_owned_file(
    db: Session,
    file_id: int,
    owner_id: int,
) -> StoredFile | None:
    return db.scalar(
        select(StoredFile).where(
            StoredFile.id == file_id,
            StoredFile.owner_id == owner_id,
        )
    )
```

Include the authenticated owner or tenant in the query. Knowing a file ID must not be enough to download it.

## 12. Secure File Download

```python name=app/routers/files.py
from fastapi import HTTPException, status
from fastapi.responses import FileResponse

from app.dependencies import DatabaseSession
from app.dependencies.auth import CurrentUser
from app.repositories.file_repository import get_owned_file
from app.services.file_paths import create_safe_path


@router.get("/{file_id}")
def download_file(
    file_id: int,
    current_user: CurrentUser,
    db: DatabaseSession,
) -> FileResponse:
    stored_file = get_owned_file(db, file_id, current_user.id)

    if stored_file is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="File not found",
        )

    file_path = create_safe_path(stored_file.storage_key)

    if not file_path.is_file():
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="File not found",
        )

    return FileResponse(
        path=file_path,
        media_type=stored_file.media_type,
        filename=stored_file.original_name,
        content_disposition_type="attachment",
    )
```

`attachment` asks the browser to download the file instead of rendering it inline. Authorization is checked before the file is returned.

## 13. Add Safe Download Headers

```python name=app/routers/files.py
response = FileResponse(
    path=file_path,
    media_type="application/octet-stream",
    filename=stored_file.original_name,
    content_disposition_type="attachment",
)

response.headers["X-Content-Type-Options"] = "nosniff"
response.headers["Cache-Control"] = "private, no-store"

return response
```

- `nosniff`: Prevents browsers from guessing another content type.
- `private, no-store`: Prevents sensitive files from being stored in shared or browser caches.

Use the validated media type only when inline rendering is intentionally allowed.

## 14. Delete a File Safely

```python name=app/services/file_service.py
from sqlalchemy.orm import Session

from app.models.stored_file import StoredFile
from app.services.file_paths import create_safe_path


def delete_file(
    db: Session,
    stored_file: StoredFile,
) -> None:
    file_path = create_safe_path(stored_file.storage_key)

    db.delete(stored_file)
    db.commit()

    file_path.unlink(missing_ok=True)
```

Verify ownership or deletion permission before calling this function.

For stronger consistency, use a background cleanup job if database and storage operations cannot be completed atomically.

## 15. Object Storage

Production systems commonly store files in private object storage instead of the application container.

```text name=object-storage-flow.txt
Client → FastAPI authorization check
       → Private object storage
       → Short-lived download URL
```

Recommended controls:

- Keep the storage bucket private.
- Use short-lived signed URLs.
- Restrict URL method and expiration.
- Validate ownership before generating a URL.
- Disable public listing.
- Encrypt stored files.
- Record security-sensitive downloads in audit logs.

## Key Security Rules

- Restrict file size and allowed types.
- Validate actual content, not only extension or `Content-Type`.
- Generate storage filenames on the server.
- Prevent path traversal with resolved-path checks.
- Store files outside publicly executable directories.
- Scan uploads for malware.
- Keep files private by default.
- Check ownership or permission for every download and deletion.
- Use safe download headers.
- Encrypt sensitive files at rest.
- Audit access to highly sensitive files.
